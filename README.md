# TableMax

**电脑当牌桌，浏览器当手牌。**

一台 Windows 电脑，几部手机，就能和朋友开一桌。TableMax 把公开牌桌放到电脑或电视上，把手牌、身份和个人操作留在每位玩家自己的浏览器里。

从四色接龙到拍卖经营，再到秘密身份推理，程序负责执行规则、计分与保存，你们负责讨论、选择和享受聚会。玩家无需安装手机应用，也无需注册在线账号。

## 下载

公开版本沿用 **v1.0.6**；本地维护构建使用四位版本，当前为 **1.0.6.10**。当前源码仅提供 **预装全部游戏的完整 Windows EXE**，不加类型后缀。取消仅盒子版及独立游戏下载／导入，更新程序即可获得新游戏与版本。本轮尚未发布，下面下载链接仍指向此前线上程序，内容以原发布说明为准。实际本地文件与验证见[当前验收](docs/reference/acceptance.md)。

**只需在负责开桌的 Windows 电脑上下载程序。朋友的手机和其他玩家电脑使用浏览器加入。**

### 下载并打开

1. 点击 **[下载 Windows 版 v1.0.6](https://github.com/anApalpitate/TableMax/releases/download/v1.0.6/TableMax-1.0.6-win-x64.exe)**，下载开桌程序。
2. 下载完成后，在浏览器的“下载”列表中找到它，点击“在文件夹中显示”；也可以打开电脑的“下载”文件夹。
3. 建议在桌面新建一个“桌游”文件夹，把下载的文件放进去，再双击打开。第一次启动会自动在程序旁边创建 `TableMax` 文件夹，用来保存游戏资源、存档和设置。
4. 如果程序提示缺少运行组件，按提示完成安装，再重新打开 TableMax。准备完成后，就可以按下方的“快速开始”和朋友入座。

**想查看其他版本？** 打开 [官方下载页](https://github.com/anApalpitate/TableMax/releases/latest)，找到 **Assets（资源／附件）**，选择 Windows EXE。后续只提供完整 Windows EXE；`-source.zip` 和 **Source code** 是供开发者使用的源代码。

**版本说明：** 已发布的 v1.0.6 与历史游戏包分发记录继续保留；本轮不修改线上附件或站点。

### 开始前准备什么

| 设备     | 准备                                                     |
| -------- | -------------------------------------------------------- |
| 开桌电脑 | Windows 11 64 位（x64），对局期间保持开机并运行 TableMax |
| 玩家设备 | 每位真人一部手机，或一台有浏览器的电脑                   |
| 网络     | 电脑与玩家设备连接同一个可互相访问的 Wi-Fi 或局域网      |
| 大屏     | 可选：连接电脑的电视或第二块显示器                       |

完整程序包含运行所需的 Node.js 和全部正式游戏、规则图与音效；缺少 Microsoft Edge WebView2 时按提示准备。准备好运行组件后，即使断网也可选择预装游戏并开局。手机及其他玩家电脑只使用浏览器加入。新游戏和游戏版本更新随完整 EXE 提供；更新时保留程序旁的 `TableMax/` 数据目录，原存档与已安装旧游戏继续保留。

## 游戏与玩法

| 游戏                       | 人数    | 聚会体验                                                 |
| -------------------------- | ------- | -------------------------------------------------------- |
| 宝可梦奇遇：皮卡丘和朋友们 | 2–6 人  | 翻牌、换牌与精灵能力，争取更低分；支持原版与九宫格扩展   |
| 现代艺术                   | 3–5 人  | 买卖画作、判断行情，在五种拍卖中竞价，四轮后比拼资金     |
| 电力公司                   | 2–6 人  | 竞拍电厂、采购燃料、连接城市并发电，使用经典德国地图     |
| UNO                        | 2–6 人  | 经典四色接龙、功能牌与 UNO 抓漏，累计 500 分获胜         |
| 阿瓦隆                     | 5–10 人 | 隐藏身份、组队投票与匿名任务；三次任务成功后进行梅林刺杀 |
| 拉密                       | 2–4 人  | 经典版；本地整理牌架与整回合桌面重组                     |

阿瓦隆采用 2012 经典版。现行源码的新局使用唯一人数配置，包含梅林、派西维尔，并按人数加入莫德雷德或奥伯伦等原版角色；旧配置仅用于恢复原局。该更新尚未发布，线上旧包的角色组合以其实际规则为准，配置及本地交付状态见[阿瓦隆规格](docs/games/avalon/spec.md)和[当前验收](docs/reference/acceptance.md)。宝可梦扩展加入九宫格、本人缓冲、17项研究及六类随机事件；Mega和羁绊保留无独立效果的主题占位，旧局固定原发行。图文规则可随时打开查看，新手引导按需开启。

游戏库为每款游戏标注分类，支持名称／玩法搜索、分类与人数筛选。切换游戏时保留兼容的玩家身份和座位，进行中的对局需要确认结束。

## 快速开始

1. **电脑开桌。** 双击程序，在游戏库选择预装游戏和玩法。
2. **朋友入座。** 让大家连接同一个 Wi-Fi 或局域网，用手机扫码进入；也可以在浏览器输入程序显示的加入网址，或点击电脑页面二维码下方的网址按钮。填写昵称、选择头像后加入牌桌。
3. **准备开局。** 玩家点击准备；管理员按需添加人机，全员准备后开始游戏。也可指定一位真人玩家担任房主，由其控制开局、暂停或继续。
4. **一起看牌桌。** 有电视或第二块屏幕时，打开独立公共屏窗口展示公开局势；各位玩家继续用自己的设备操作。

电脑主机在对局期间保持运行。玩家刷新页面或短暂断网后，程序会尝试恢复连接；已入座玩家使用原设备、原浏览器和原网址重新进入，可继续自己的座位。

## 常见问题

**旧对局无法恢复？**

请按提示查看所需游戏和规则版本。本机保留的原游戏可继续旧局，页面会显示“正在继续旧版本对局”；旧局内部的下一轮继续使用原版本，结束后的“再玩一局”使用当前版本。如果原版本已经丢失，请使用包含它且支持该存档格式的旧完整 EXE。保留原数据目录，不要用新版规则替换旧存档。新局使用当前完整 EXE 的游戏版本。

**下载后找不到程序？**

打开浏览器的“下载”列表，找到下载的 TableMax Windows EXE（当前发布文件为 `TableMax-1.0.6-win-x64.exe`），选择“在文件夹中显示”，然后双击打开。如果下载的是 `-source.zip` 或 Source code，请回到下载章选择 Windows EXE 程序。

**手机连接不上？**

先确认电脑和手机连接同一网络，再打开盒子的“连接帮助”，选择正在使用的 Wi-Fi 或以太网地址。访客 Wi-Fi 可能禁止设备互相访问。按照程序提示允许所需的专用网络访问，无需关闭防火墙。

**关掉程序后还能继续吗？**

可以。已确认的操作会自动保存，重新打开程序后恢复对局并暂停。玩家用原设备、原浏览器和原网址进入即可接续；更换设备时，在新页面选择“换手机进入”，申请原座位并由管理员核对、批准。

**更新时怎样保留存档？**

先退出 TableMax，备份程序旁边的 `TableMax` 文件夹，再把新版本 EXE 放回原来的位置启动。默认存档、设置与缓存保存在该文件夹中，请保留它。已自行更改存储位置的用户应同时备份自己选择的目录，详细方法见 [存储与运行说明](docs/reference/development.md#v103-便携存储与启动迁移2026-10-06)。

**如何远程联机？**

可以通过内网穿透，让不同地方的朋友使用浏览器加入。由开桌电脑的管理员按以下流程配置：

1. **先启动 TableMax。** 打开盒子的“连接帮助”，记下当前局域网加入网址中的 IP 和端口，并先确认该网址能在本地打开。
2. **准备内网穿透。** 在开桌电脑安装并登录所选穿透服务的客户端；自行搭建 FRP 时，还需准备公网服务器和对应的服务端。TableMax 本身不提供穿透服务。
3. **创建并启动隧道。** 将本地目标设置为第 1 步的网址对应的 IP 和端口。使用 HTTP／HTTPS 网站映射，或支持浏览器 HTTP 访问的 TCP 映射；完整转发网站根路径，包括页面、资源、`/api` 和 `/socket.io`，并支持 HTTP polling 与 WebSocket。不要只映射 `/player`，也不要添加 `/tablemax` 等路径前缀。
4. **测试公网入口。** 取得穿透服务提供的域名或公网地址，用手机移动网络打开完整网址，确认能进入玩家页面并入座。例如 `https://你的域名`，或 `http://你的域名:公网端口`；协议和公网端口以穿透服务实际配置为准。
5. **更新加入地址。** 在电脑管理员的“连接帮助”中，将完整公网根网址填入“外部入口网址”，点击“保存外部入口”。必须写明 `http://` 或 `https://`；保存后，加入二维码和“打开网址”按钮会同步更新。保存网址只更新邀请入口，隧道仍需单独保持运行。
6. **邀请朋友入座。** 将更新后的二维码或网址发给朋友。对局期间，开桌电脑、TableMax 和穿透客户端都要保持运行；需要共同观看公开牌桌时，可另行共享公共屏画面。

若页面能打开但无法入座或持续断线，检查隧道是否完整转发 `/api`、`/socket.io`，以及 polling／WebSocket 是否受限。公网域名、协议或端口改变后，原浏览器身份不会自动转移到新网址；需要接续原座位时，使用“换手机进入”并由管理员批准。更多边界见 [连接与换机说明](docs/reference/phase-02-platform-spec.md#浏览器入座换机与外部连接2026-10-07)。
