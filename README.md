# TableMax

**电脑当牌桌，手机当手牌。**

TableMax 是为朋友线下聚会开发的数字桌游平台。用一台 Windows 电脑运行牌桌，每位玩家拿出手机扫码加入；公开局势放在电脑或电视上，个人信息和操作留在自己的手机里。

规则执行、计分和保存由程序完成。电脑与手机连接同一局域网后，即可使用包内游戏和资源游玩，无需在线账号。

## 三款桌游，一张牌桌

| 游戏                       | 人数   | 玩法                                                 |
| -------------------------- | ------ | ---------------------------------------------------- |
| 宝可梦奇遇：皮卡丘和朋友们 | 2–6 人 | 翻牌、换牌与精灵能力，争取更低分并赢得三场胜利       |
| 现代艺术                   | 3–5 人 | 买卖画作、判断行情，在五种拍卖中竞价，四轮后比拼资金 |
| 电力公司                   | 2–6 人 | 竞拍电厂、采购燃料、连接城市并发电，使用经典德国地图 |

可以全部真人入座，也可以加入“默认／豆包／绝悟”三档本地人机。人机使用游戏内策略，不调用在线 AI 服务。游戏中均有图文规则；宝可梦还可按需开启新手引导，默认关闭。

宝可梦在大厅或结束后可切换原版与自制扩展版。扩展采用九宫格、双弃牌、30项研究和完整特殊能力，配有角色关节动作与本地声音；存档支持完整历史回退与旧库兼容。当前源码已完成卡面、手机单一操作牌阵和结算重设计，研究配有独立插画与精确图示；角色、研究及牌堆使用独立配置。实现与真人验收待测项见[扩展任务](docs/tasks/pokemon-encounters-expansion.md#ui重设计2026-10-06)。

本地v1.0.3的宝可梦与电力公司维护分别使用独立验收包，具体交付路径、哈希及源码合并状态见[验收记录](docs/reference/acceptance.md#当前源码与本地交付)。GitHub可下载版本以Releases为准。

## 为什么用 TableMax

- **各自操作，公共观看。** 手机查看自己的牌和信息，电脑或电视展示公开牌桌；管理员不占玩家座位。
- **把精力留给决策。** 合法动作、能力处理、拍卖和计分由程序执行，秘密信息只发给有权查看的玩家。
- **随时暂停，接着玩。** 已确认动作自动保存，支持决策点回退和重启恢复；可授权一位手机房主管理对局节奏。
- **适合一起玩。** 自定义昵称与头像，真人与人机混合入座，连续对局或切换游戏时保留兼容的身份和座位。
- **资源留在本地。** 游戏图片、规则图解和音效随程序提供，正式对局不依赖互联网。

## 快速开始

1. 双击本地导出的 `TableMax-1.0.3-win-x64.exe`（GitHub 已发布包以 [Releases](https://github.com/anApalpitate/TableMax/releases/latest) 为准）。首次启动会在 EXE 旁新建的 `TableMax/app` 解压运行资源，之后复用已校验的文件。
2. 电脑和玩家手机连接同一个可互相访问的 Wi-Fi 或局域网。
3. 在电脑上选择游戏。玩家用各自手机扫码，填写昵称、选择头像并入座准备。
4. 管理员按需加入人机；全员准备后开始游戏。连接电视或第二块屏幕时，可打开独立公共屏窗口。

电脑主机须在对局期间保持运行。手机只需浏览器，不必安装应用。管理员可指定手机房主，由其开局、推进下一轮、暂停或恢复。

## 运行要求

| 设备   | 要求                                                    |
| ------ | ------------------------------------------------------- |
| 主机   | Windows 11 x64，系统共享 Microsoft Edge WebView2 运行时 |
| 玩家端 | 每位真人一部可使用浏览器的手机                          |
| 网络   | 电脑与手机在同一局域网，设备之间可互相访问              |
| 大屏   | 可选：连接电脑的电视或第二块显示器                      |

启动包已包含 Node.js 和三款游戏。缺少 WebView2 时，程序会提供安装入口；准备好运行环境后，游玩无需互联网。下载文件和实际运行资源均控制在 100,000,000 字节以内。

## 常见问题

**手机连接不上？**

先确认电脑和手机使用同一网络，再打开程序的“连接帮助”选择正确的 Wi-Fi 或以太网地址。访客网络的设备隔离可能阻止连接。按程序提示允许所需的专用网络访问，无须关闭防火墙。

**关掉程序后还能继续吗？**

可以。界面显示已保存后，重启会恢复对局并暂停。手机使用原设备、原浏览器和原地址重新进入，可以恢复身份。

**新版会覆盖存档吗？**

单EXE首次启动在旁边新建 `TableMax/`，运行资源在 `TableMax/app`，配置、存档、设置及缓存默认在 `TableMax/`。ZIP解压版直接使用解压目录。更新前先关闭正在运行的 TableMax；启动包使用暂存与回滚保护更新程序。备份方法见 [开发与运行说明](docs/reference/development.md)。

**支持在线联机或更多游戏吗？**

当前面向同一地点的局域网聚会，内置三款游戏及宝可梦自制扩展版。游戏按需下载安装仍在规划中，见 [后续计划](docs/tasks/README.md)。

## 开发与反馈

前端使用 React／TypeScript，服务使用 Node.js／SQLite，Windows 外壳使用 C#／WebView2。平台与各游戏支持独立增量构建；游戏通过版本清单接入，共享授权网页宿主与本地运行时。

```powershell
pnpm install --frozen-lockfile
pnpm setup:desktop
pnpm build
pnpm start
```

工具版本、环境准备与完整检查见 [开发说明](docs/reference/development.md)。新增游戏从 [游戏开发指南](docs/game-development/README.md) 开始。

当前本地版本为 **v1.0.3**。单EXE的配置位于旁边新建的 `TableMax/TableMax.config.json`；ZIP解压版配置直接位于解压目录。配置默认写入 `dataDirectory: "."`，相对配置所在目录解析；存档、日志、显示设置和浏览器缓存默认与配置放在同一目录。按 Alt 打开“程序 → 存储设置”可指定其他目录，重启后生效。旧 C 盘数据不会自动搬移或删除；续局前将完整旧数据复制到所选目录。目录不可写时明确报错，不回退到 C 盘。
