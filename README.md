# TableMax

**电脑当牌桌，浏览器当手牌。**

一台 Windows 电脑，几部手机，就能和朋友开一桌。TableMax 把公开牌桌放到电脑或电视上，把手牌、身份和个人操作留在每位玩家自己的浏览器里。

从四色接龙到拍卖经营，再到秘密身份推理，程序负责执行规则、计分与保存，你们负责讨论、选择和享受聚会。玩家无需安装手机应用，也无需注册在线账号。

## 下载

**只需在负责开桌的 Windows 电脑上下载程序。朋友的手机和其他玩家电脑使用浏览器加入。**

### 下载并打开

1. 点击 **[直接下载 TableMax v1.0.5 Windows 版](https://github.com/anApalpitate/TableMax/releases/download/v1.0.5/TableMax-1.0.5-win-x64.exe)**，下载文件 `TableMax-1.0.5-win-x64.exe`。
2. 下载完成后，在浏览器的“下载”列表中找到它，点击“在文件夹中显示”；也可以打开电脑的“下载”文件夹。
3. 建议在桌面新建一个“桌游”文件夹，把下载的文件放进去，再双击打开。第一次启动会自动在程序旁边创建 `TableMax` 文件夹，用来保存游戏资源、存档和设置。
4. 如果程序提示缺少运行组件，按提示完成安装，再重新打开 TableMax。准备完成后，就可以按下方的“快速开始”和朋友入座。

**想查看其他版本？** 打开 [官方下载页](https://github.com/anApalpitate/TableMax/releases/latest)，找到 **Assets（资源／附件）**，点击名称以 `-win-x64.exe` 结尾的文件。`-source.zip` 和 **Source code** 是供开发者使用的源代码；游玩请选择 EXE 程序。

**版本说明：** 截至 2026-10-10，GitHub 公开下载为 **v1.0.5**。当前项目与本地交付已更新至 **v1.0.6**，包含阿瓦隆、新版游戏库等新增功能，尚未发布到官方下载页。下方介绍按当前 v1.0.6 整理；下载版的实际内容请查看对应 [更新说明](https://github.com/anApalpitate/TableMax/releases)。

### 开始前准备什么

| 设备     | 准备                                                     |
| -------- | -------------------------------------------------------- |
| 开桌电脑 | Windows 11 64 位（x64），对局期间保持开机并运行 TableMax |
| 玩家设备 | 每位真人一部手机，或一台有浏览器的电脑                   |
| 网络     | 电脑与玩家设备连接同一个可互相访问的 Wi-Fi 或局域网      |
| 大屏     | 可选：连接电脑的电视或第二块显示器                       |

程序包含游戏资源和所需的 Node.js；缺少 Microsoft Edge WebView2 时会提供安装入口。首次准备运行环境可能需要联网，准备好后，同一局域网内的游戏、规则图和音效都可以离线使用。

## 游戏与玩法

| 游戏                       | 人数   | 聚会体验                                                 |
| -------------------------- | ------ | -------------------------------------------------------- |
| 宝可梦奇遇：皮卡丘和朋友们 | 2–6 人 | 翻牌、换牌与精灵能力，争取更低分；支持原版与九宫格扩展   |
| 现代艺术                   | 3–5 人 | 买卖画作、判断行情，在五种拍卖中竞价，四轮后比拼资金     |
| 电力公司                   | 2–6 人 | 竞拍电厂、采购燃料、连接城市并发电，使用经典德国地图     |
| UNO                        | 2–6 人 | 经典四色接龙、功能牌与 UNO 抓漏，累计 500 分获胜         |
| 阿瓦隆                     | 5–6 人 | 隐藏身份、组队投票与匿名任务；三次任务成功后进行梅林刺杀 |
| 拉密                       | 2–4 人 | 开发中，暂不开放选择；采用经典版                         |

阿瓦隆采用 2012 经典版，提供基础角色和加入派西维尔／莫甘娜的角色组合。宝可梦扩展加入九宫格、公开缓冲和研究玩法；图文规则可随时打开查看，新手引导按需开启。

游戏库为每款游戏标注分类，支持名称／玩法搜索、分类与人数筛选。切换游戏时保留兼容的玩家身份和座位，进行中的对局需要确认结束。

## 为聚会准备的功能

- **各自操作，公共观看。** 玩家查看自己的手牌和秘密身份，电脑主机或电视展示公开局势；管理员不占玩家座位。
- **人数不齐，也能开桌。** 真人与人机可混合入座，提供“默认／豆包／绝悟”三档本地策略，无需调用在线 AI 服务。
- **规则与记分交给程序。** 动作按规则校验，计分自动完成，个人秘密只展示给有权查看的玩家。
- **暂停之后，继续这一局。** 已确认动作自动保存，支持暂停、决策点回退和重启恢复；换设备时可申请接续原座位，由电脑管理员批准。
- **让每一局都有桌游氛围。** 各游戏拥有自己的牌面、桌面、图文规则、动画和本地音效；互动球提供表情与固定语音，各端可独立屏蔽。
- **屏幕大小，按你的习惯。** 主机和公共屏可分别调整显示大小；电脑浏览器玩家可切换横竖屏，手机保持触控布局。
- **反馈清楚，操作连贯。** 入座失败等短提示以可关闭、自动淡出的弹窗显示，连接恢复与待确认操作保留持续提示和重试入口。

## 快速开始

1. **电脑开桌。** 双击下载的程序，在盒子里选择游戏。
2. **朋友入座。** 让大家连接同一个 Wi-Fi 或局域网，用手机扫码进入；也可以在浏览器输入程序显示的加入网址，或点击电脑页面二维码下方的网址按钮。填写昵称、选择头像后加入牌桌。
3. **准备开局。** 玩家点击准备；管理员按需添加人机，全员准备后开始游戏。也可指定一位真人玩家担任房主，由其控制开局、暂停或继续。
4. **一起看牌桌。** 有电视或第二块屏幕时，打开独立公共屏窗口展示公开局势；各位玩家继续用自己的设备操作。

电脑主机在对局期间保持运行。玩家刷新页面或短暂断网后，程序会尝试恢复连接；已入座玩家使用原设备、原浏览器和原网址重新进入，可继续自己的座位。

## 常见问题

**下载后找不到程序？**

打开浏览器的“下载”列表，找到 `TableMax-1.0.5-win-x64.exe`，选择“在文件夹中显示”，然后双击打开。如果下载的是 `-source.zip` 或 Source code，请回到下载章选择 Windows EXE 程序。

**手机连接不上？**

先确认电脑和手机连接同一网络，再打开盒子的“连接帮助”，选择正在使用的 Wi-Fi 或以太网地址。访客 Wi-Fi 可能禁止设备互相访问。按照程序提示允许所需的专用网络访问，无需关闭防火墙。

**关掉程序后还能继续吗？**

可以。已确认的操作会自动保存，重新打开程序后恢复对局并暂停。玩家用原设备、原浏览器和原网址进入即可接续；更换设备时，在新页面选择“换手机进入”，申请原座位并由管理员核对、批准。

**更新时怎样保留存档？**

先退出 TableMax，备份程序旁边的 `TableMax` 文件夹，再把新版本 EXE 放回原来的位置启动。默认存档、设置与缓存保存在该文件夹中，请保留它。已自行更改存储位置的用户应同时备份自己选择的目录，详细方法见 [存储与运行说明](docs/reference/development.md#v103-便携存储与启动迁移2026-10-06)。

**朋友不在同一个地方，也能加入吗？**

支持手动配置外部入口：使用 FRP 等工具把运行中的电脑映射为可访问的网址，再在“连接帮助”保存完整的 HTTP／HTTPS 网站根地址，二维码会随之更新。这一步需要额外配置；日常同网络聚会直接扫码即可。配置方法见 [连接与换机说明](docs/reference/phase-02-platform-spec.md#浏览器入座换机与外部连接2026-10-07)。
