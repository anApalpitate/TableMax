# 008：共享 WebView2 与小体积桌面交付

日期：2026-10-03。状态：已采用并通过最终便携验证；实际交付与范围见 [验收记录](../reference/acceptance.md#100原生桌面与小体积交付2026-10-03)。ZIP 35,442,208 字节，实际解压 90,979,966 字节。

## 问题与目标

精简语言后的 Electron 便携 ZIP 为 144,416,191 字节，解压程序为 342,736,317 字节，其中主程序单独为 245,726,720 字节。首版游戏素材约 2 MiB，单纯拆资源或提高压缩率不能解决解压体积要求。

用户确认：新增游戏前，Windows x64 便携 ZIP 及解压后全部交付文件都严格小于 100,000,000 字节；允许共享 WebView2，不将系统共享运行时、用户存档及缓存算入交付目录。缺运行时可提示安装，完成安装后正式对局仍完全离线。

## 采用方案

采用 C# WinForms／.NET Framework 4.8 原生窗口与共享 Evergreen WebView2，内置官方 Node 22.14.0 x64 提供现有服务／SQLite／Worker；保留 React 页面、规则、策略、局域网通信与秘密投影。Windows 11 内置兼容的 .NET Framework；不发布现代 .NET 自包含运行时或 WebView2 Fixed Version。

开发 SDK 固定 9.0.102，WebView2 SDK 固定 1.0.4258.31，引用程序集仅供编译。Node 下载与官方 SHA-256 清单核验；发布只保留 node.exe、许可证、x64 WebView2 必需库及应用模块／资源。包和目录都执行严格体积门禁，以 95 MB 以下作为工程预算。

独立服务启动改用父子进程私有重定向管道，管理员凭证只在该通道交接，再通过主机页面 fragment 初始化；普通独立服务不会输出凭证。网页显示／音频桥接口保持，原生端验证顶层来源、窗口角色与参数，不新增公开特权 HTTP 接口。单实例、双窗口、独立缩放、单声源、防休眠与退出清理在原生壳实现；游戏协议和存档格式不变。

## 后果与验证责任

- 免安装应用目录仍可移动，电脑需要已有 WebView2；缺失时明确提示官方安装入口和取消，不静默安装或附带大体积运行时。
- 共享浏览器运行时由系统维护，不再由应用捆绑固定 Chromium；验收记录保存实际版本，重大变化按影响复验。
- WebView2 的后台渲染和截图不能直接视为 Electron offscreen 等价。使用屏幕外、不激活但保持合成器渲染的真实原生窗口，先验证 CDP、桥接和进程退出，再迁移完整验证；正式启动不开 CDP。
- SQLite 从 Electron 内置 Node 24.21.0／SQLite 3.53.4 切到 Node 22.14.0；必须从真实旧文件复制到隔离目录，验证读取、权限身份、继续保存与重启恢复，不用仅新建存档证明兼容。
- 显示、音频、身份／管道越权、窗口与进程故障、完整便携局及互联网断开场景均按现有要求验证。原包和历史证据保留，新包以实际哈希重新验收。

选择此方案是为了同时满足解压体积与独立桌面体验。更换压缩格式只缩小下载，不满足解压要求；使用系统浏览器难以等价保留桌面窗口／显示／声音控制。多游戏按需安装维持 [未来计划](../tasks/README.md#多游戏按需安装未来计划未实现)，本轮不实施。

官方依据：[WebView2 分发](https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution)、[.NET Framework 系统要求](https://learn.microsoft.com/en-us/dotnet/framework/get-started/system-requirements)、[WebView2 SDK](https://www.nuget.org/packages/Microsoft.Web.WebView2/1.0.4258.31)。
