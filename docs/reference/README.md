# 参考索引

这里维护当前跨游戏知识；按任务直接选唯一正文，已完成过程从 [归档索引](../archive/README.md)追溯。

当前 Windows 交付为预装全部正式游戏及玩法的完整 EXE。游戏模块独立维护，新局使用本EXE当前发行，旧局按原发行恢复；已退役的双版本EXE、下载及导入流程只作为历史记录。版本、恢复、验收和瘦身结论分别从下表进入对应正文。

设计前必须查询 [用户美术偏好](art-preferences.md)，适当参考其中与当前任务有关的审美倾向、细节及来源；按场景使用，不机械套用。原始证据仅取用户请求，实施判断另列。

实际本地交付、安装证明、历史候选与线上发布边界统一见[验收](acceptance.md#当前源码与本地交付)；目录及事务契约见[构建与运行](build-and-run.md#windows-安装与整个程序更新)。

范围选择、证据复用与失败预算见[验证](validation.md#按变更范围选择检查)；完整安装、程序更新与原EXE直接启动的证明层次见[安装验收](installation-validation.md)。资料来源变化与小批迁移见[维护规则](maintenance.md#来源身份与变化复核)。
