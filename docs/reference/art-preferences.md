## 使用与审查

这是根据用户反馈整理的执行方法，不是新增产品验收或改造授权。

1. 主体与操作：辨认当前玩家、牌／阶段、主要合法动作，确认必要说明可读。
2. 布局与状态：检查相应人数与短屏，排查空白、重叠、重复内容、小字、点号长串、控件对齐及近似颜色；圆圈数字与图标须看实际渲染。
3. 主题与素材：角色实际可见大小、头像／图标缩小辨识度、游戏主题及后加组件一致性。
4. 完整过程：覆盖选择、执行、等待、能力与结算；动效实际运行检查，不能由静态截图、容器尺寸或自动检查通过代替审美结论。

独立逐图审查按原授权不继承对话、源码或他人结论，仅共享偏好基线和必要身份／尺寸／权限输入。视觉建议与实施授权分开；例如用户只要求分析廉价感时，不据此修改UI。验证方法及实际交付边界查[通用视觉](visual-design.md)和[验收](acceptance.md)。
