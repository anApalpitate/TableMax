# 用户美术偏好

本页是 TableMax 的长期设计依据。盒子、游戏界面、图标、头像、插画、布局与动效设计，以及视觉审查，必须先查阅本页，再结合当次用户反馈和对应游戏规格作判断。最新明确反馈优先；本页不覆盖游戏规则、秘密权限、操作可读性和可访问性。

2026-10-04 整理。依据可访问聊天中的真实用户消息、用户明确要求实施的方案、当前与归档文档；来源和覆盖边界见下文。聊天标题与摘要仅用于定位，assistant 的建议、自动接续提示和既有实现不自动成为用户偏好。

## 最新反馈及范围

2026-10-04 现代艺术追加反馈：制定并遵守信息文字最小标准；画作类型不能仅依赖浅边框，要加强边框并提供额外视觉标记；音效要有艺术感；收紧艺术市场上下留白，四人／五人也要美观；画作同类默认靠拢，手机看本人、电脑看公开全局。由此优先采用足够大的文字、画家分组与独立类型符号，以及贴合画廊／拍卖的短声音。20 秒可调整倒计时是共用产品功能，工作目录压缩是工程要求，不将两者推成装饰风格。来源为本聊天本次用户消息与其艺术市场截图，新的实施数值仍归平台及现代艺术规格。

2026-10-04 的盒子反馈（S09）明确要求：玩家可选择至少 20 个 imagegen 预设头像，风格与现有头像相似；先到先得，已被选择的头像不能重复选择，要标记占用。这同时包含美术偏好与产品功能要求，实际并发、保存和身份规则由平台规格维护，不能只画一个看似可用的选择器。

游戏介绍要概述所选游戏的主要玩法，使人一眼知道大概怎么玩。当前附件中关于“自己的手机操作、电脑管理员／公共展示、加入人机”的通用设备介绍没有回答玩法问题。介绍应以该游戏的目标、核心回合行为和胜负方式为主，使用简洁、清楚的文本层级；这不扩大为主动新增对局内教程，线下教学约定仍有效（S03）。

上一轮 13 条逐图批注（S08）还明确了白色斜纹矩形进度条、紧凑行动横条、未取牌区域观感、牌堆区分、六人间隙、手机对比与上下空间、目标按钮居中、减少中点和小字、放大两人结果卡牌，以及分析后补充特效。这些是已观察场景的具体要求；提炼为上表的层级、空间和状态原则后，其他场景仍需按用途判断。

## 使用与审查

设计前通过本页定向查询相关偏好，记录适用的来源编号和当前反馈；素材任务把这些约束连同用途、参考图、禁止内容和目标尺寸放入提示词。实施选择与用户原话分开，例如“白色斜纹”是具体反馈，“蓝牌库／琥珀弃牌”是实现选择，不能写成用户固定配色偏好。

设计和审查按下列顺序判断：

1. 先辨认主体与主要动作：玩家、卡牌、阶段／暂持和当前操作是否清楚，必要说明是否可读。
2. 再检查空间与层级：是否存在过大空白、过长横条、细小副标题、点号串联、控件不对齐或相近背景。
3. 检查主题与素材：不同游戏是否各有辨识度，头像／图标缩小后是否一致且清楚。
4. 实际观察动效：是否贴合已经保存的结果、增加辨识度，是否遮挡卡牌、按钮或泄露私密信息。尊重减少动态和测试模式，不从静态截图断言动画合格。

这套顺序是依据用户反馈整理的执行判断，不是用户逐条口授的通用验收公式。出现新反馈时修订相应条目与来源；被替代的具体方案进入历史说明，保留原始证据，不重新覆盖归档记录。独立逐图审查仍不继承对话、源码或别人的结论，只共享本页这份用户偏好基线和必要的身份／尺寸／权限输入。
