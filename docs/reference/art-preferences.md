用户原话：“仍然存在需要滑动条页面过多、重点不够突出、布局丑陋的问题，手机端可以尝试左右滑动切换页面”。据此优先减少重复信息、突出当前行动，手机左右滑动记为可尝试方向，同时保留明确可点击入口；不能据此认定所有游戏都必须分页。电力公司本轮采用“行动／市场／地图／公司”四页及阶段主区，属于明确实施方案，具体手势阈值、停靠栏和排版参数维护在 [游戏交互](../games/power-grid/interaction.md)。

2026-10-04 现代艺术追加反馈：制定并遵守信息文字最小标准；画作类型不能仅依赖浅边框，要加强边框并提供额外视觉标记；音效要有艺术感；收紧艺术市场上下留白，四人／五人也要美观；画作同类默认靠拢，手机看本人、电脑看公开全局。由此优先采用足够大的文字、画家分组与独立类型符号，以及贴合画廊／拍卖的短声音。20 秒可调整倒计时是共用产品功能，工作目录压缩是工程要求，不将两者推成装饰风格。来源为本聊天本次用户消息与其艺术市场截图，新的实施数值仍归平台及现代艺术规格。

## 使用与审查

设计前必须查询本页，并适当参考与本次用途有关的偏好；结合设备、人数、游戏主题与最新反馈选择适用条目，不机械套用。记录适用的来源编号和当前反馈；素材任务把这些约束连同用途、参考图、禁止内容和目标尺寸放入提示词。实施选择与用户原话分开，例如“白色斜纹”是具体反馈，“蓝牌库／琥珀弃牌”是实现选择，不能写成用户固定配色偏好。

设计和审查按下列顺序判断：

1. 先辨认主体与主要动作：玩家、卡牌、阶段／暂持和当前操作是否清楚，必要说明是否可读。
2. 再检查空间与层级：是否存在过大空白、过长横条、细小副标题、点号串联、控件不对齐或相近背景。
3. 检查主题与素材：不同游戏是否各有辨识度，头像／图标缩小后是否一致且清楚。
4. 实际观察动效：是否贴合已经保存的结果、增加辨识度，是否遮挡卡牌、按钮或泄露私密信息。尊重减少动态和测试模式，不从静态截图断言动画合格。

这套顺序是依据用户反馈整理的执行判断，不是用户逐条口授的通用验收公式。出现新反馈时修订相应条目与来源；被替代的具体方案进入历史说明，保留原始证据，不重新覆盖归档记录。独立逐图审查仍不继承对话、源码或别人的结论，只共享本页这份用户偏好基线和必要的身份／尺寸／权限输入。
