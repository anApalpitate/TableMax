## 后续值得做、但需具体证据的部分

- 样式中仍有跨层覆盖。下次具体组件调整时，以对应状态矩阵证明无效规则再删除；不把“文件合并”当作加载速度提升，也不凭选择器未命中一次就删掉恢复／等待分支。
- RoomCoordinator仍保留命令分发、授权和事务协调。继续提取需能减少重复不变量，并证明不会形成第二个提交路径；本轮不重写数据库、协议、安装事务或规则引擎。
- 资源runtimePolicy已可复用，其他素材组应先补真实来源、尺寸和预算，再逐组启用。不能按现存最大文件自动抬高预算或生成虚假来源记录。
- 公共几何锚点、通用布局容器仍需第二类真实消费者。当前演出时钟和牌阵语义留在宝可梦；不为未来用途创建共享空层或统一所有游戏的状态机。
- 实体手机、真实Windows DPI、电视、网络持久化和安装器分别验收；未测性能不宣称帧率、内存或构建耗时提高。

后续沿用[范围验证](validation.md)和[界面复用](ui-composition.md)，不另建重复架构清单或文档索引系统。
