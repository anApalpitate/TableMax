# 盒子视觉与交互呈现

本页维护盒子大厅、游戏库、头像、连接与设置的现行视觉正文；跨游戏字号、三类布局、声画及任务交付见[通用视觉](visual-design.md)。身份、授权、换机、开局、恢复与持久化仍归[平台规格](phase-02-platform-spec.md)。[用户偏好](art-preferences.md)保存用户原话与覆盖关系；本页尺寸、颜色、时长和布局参数属于实施选择，不反写为用户偏好。

以下区分有效要求与既有实施参数；当前源码、本地包及实际通过范围只以[当前验收](acceptance.md#当前源码与本地交付)为准。三类布局是后续改造规范，不能因本页整理就宣称旧页面已全部符合。整理前的原文、旧方案、失败和证据完整保存在[历史原文](../archive/visual-design-before-consolidation-2026-10-23.md)。

## 角色与布局

2026-10-24已确认仅保留管理兼展示与玩家，各自有盒子／游戏页面，按[三类布局](visual-design.md#三类布局与宽高比适配)组织；当前源码已实施，实际通过范围见[验收](acceptance.md#当前源码与本地交付)。取消独立公共页、公共屏开窗、专用布局及显示设置，不因设备或IP提升权限。管理界面不占真人座位，房主参赛按普通玩家身份加入；SDK public公开投影、旧ABI和原报告仍保留，入口410与配置迁移见[平台契约](phase-02-platform-spec.md#管理兼展示与公共屏退役2026-10-24)。未来客户端玩家模式按需求实施，不以视觉整理提前实现。

主体是游戏、席位与主要操作，次要管理按需打开。横屏保持桌面意象，玩家竖屏采用紧凑席位组织；布局切换、旋转及窗口变化保留连接、身份、未提交草稿、输入焦点与存续组件。信息≥16、主要操作／关键状态≥18、电脑标题≥20 CSS px，触控至少44px；局部约定48px的入口继续满足48px。短屏先重排，不缩字或裁切必要操作。

## 大厅座位与本人操作

有效要求：空座与有人座位切换时保持稳定卡槽与座位DOM，座号、头像、完整昵称、本人标记、真人在线／离线及准备状态、人机等级清楚可见；最长合法昵称自然换行，不能挤压邻座。不同端使用同一稳定座位顺序，空座仅展示，不新增点选入座。按游戏容量显示，兼容至12席不代表每款游戏可玩12人；六席以内保留围桌意象，7–12席用网格，短屏可纵向浏览。

既有实现：空座与已入座共享头像、姓名、身份与准备四行槽位；六席及以下在主机／公共屏／宽屏玩家端以纵向名片围绕椭圆桌，主区域在窗口内伸展，宽屏上限1160 CSS px并垂直居中。宽屏玩家左右分栏，中等宽度本人操作区移到牌桌上方。边界尺寸仍须按实际内容验证，不能把该上限推广为所有游戏的画布尺寸。

7–12席扩展网格撑满所属容器，卡槽取消额外宽度上限并横向拉伸；列数依据`room-seats`容器内容宽度，默认两列，249px及以下一列，520／720／900px起依次三／四／五列。网格行高取176px与当前座位高度变量中的较大值，座位填满轨道且至少176px，避免短屏轨道低于卡片最小高度时上下相叠；长昵称仍自然换行，短屏保留纵向浏览。该调整限扩展网格，六席围桌布局及座位／加入／准备权限不变。

加入与本人操作使用同一区域，避免前后高度跳动。当前共同最小高度156 CSS px，头像56px；未入座时头像／标题在上，昵称与加入按钮紧凑同排，保留可访问标签。入座后头像、姓名与座号紧邻，下方48px整行准备按钮，已准备为浅色状态；无弹性空行撑高，异常信息可自然增高。头像角标与提示表达编辑入口。头像占用、昵称校验、待确认、换机、局中锁定、准备／取消准备及角色权限不变。

进入牌桌操作与封面、游戏名、版本／玩法入口整合，不另占继续游戏横条；原显示条件与跳转权限不变。管理员操作并入牌桌标题区，清桌等暂不可用动作保留稳定操作槽位，避免出现时换行推挤。座位设置为椅子图标及短名入口，等级、排序等进对应座位浮窗；不把菜单常驻叠在桌上。换手机入口在加入区后独立居中，既有180×48px、上下12px与接续图标作为实施参数，申请／禁用状态原位呈现。

结束状态显示“恢复加入”，仅管理员及已授权真人房主按平台规格保留原班身份回到开放大厅；不把展示动作扩展为普通玩家管理权。原班回大厅后才允许重新配置人机等级，局中禁改；电脑不替真人准备或行动，人机授权输入与能力归[人机规格](bot-players.md#三档智能与配置)。

扫码／网址下方空白是用户为未来服务端玩家输入网址加入区域保留的空间。当前不实现输入区，不添加占位文案或装饰填充；该留白不能作为压缩其它必要内容的理由。

## 游戏库与玩法入口

仅选择完整EXE预装的正式游戏／玩法，不显示游戏下载、安装、ZIP导入或独立包管理。未选游戏仍展示大厅并提示“请在游戏库选择游戏”；默认首次选择、已存大厅和旧局按平台规格处理，不以视觉占位改变对局。旧局提示“正在继续旧版本对局”。

封面卡片显示游戏名、人数、分类、开发／当前状态和选择动作；正式、开发中、待开发卡片均不显示简介短句或玩法名称串。关键词仍可用于检索。电脑按行网格，从左到右再从上到下，视觉、DOM和键盘顺序一致；封面在上、信息与操作在下，自然卡高、圆角、轻阴影与明确已选标记。手机和狭窄玩家窗口保持紧凑单列，不用不确定顺序的瀑布排布。

分类、名称／玩法关键词、人数筛选可组合，人数选项依目录最高人数生成，最多12；不硬编码旧目录最高6人。匹配数实时显示，无结果可重置。筛选只改变本地展示，不改目录、身份或座位；开发中、当前选中、人数不兼容的条目依原条件禁选，局中切换保留结束确认。全目录人数提醒在标题下，开发中条目不参与。分类及别名归各游戏`game-module.json`中的`library.tags`、`library.searchTerms`。

玩法选择浮窗用奶油／浅绿卡片分层呈现名称、必要说明、当前玩法和动作，不与游戏库卡片移除简介的要求混淆。玩法说明入口用浅绿底展开书页与书签细节，48px触控区按可见轮廓居中；可访问名称、悬停／聚焦提示为“玩法说明”，直接打开既有介绍，不增加中间步骤或影响版本选择。

介绍浮窗按封面／人数、短概述、三步图解和胜负条件组织，电脑三列步骤、窄屏整行正文，图片等比、内容自然增高。外壳、固定标题和关闭由浮窗负责，介绍布局归`box-overlays.css`；选择器及runtime加载顺序不得恢复旧横向flex覆盖。图像路径遵循现有简介白名单，加载失败仍有回退；验收必须检查实际主题图加载成功，不能把通用回退算作成功。

各游戏简介用对应题材和核验组件，不拿包装图冒充操作图，不用金币图暗示无关积分。德国小强三图表达声明、判断／秘密查看转传分支、公开收牌风险，保留双人例外。三张`introduction-*-v1.svg`、元数据、来源及SHA归对应游戏和资源清单，不扩大共享资源白名单。原卡面嵌入SVG，文字、数字、箭头及状态由代码绘制，不重绘商业牌面，不改变规则。

封面使用已核验的发行方包装图并本地打包；缺失／加载失败保留SVG回退，待开发游戏版次及人数仍须规则研究确认。[封面清单](../../assets/platform/library-covers/manifest.json)维护来源、用途、机械处理与SHA。左上角TableMax是唯一仓库入口，保留新窗口、原生可信顶层点击在系统浏览器打开与失败提示；玩家用普通浏览器链接，不恢复页脚GitHub图标。

## 顶栏与浮窗

顶栏按品牌／连接状态、设置入口和保存反馈分区，设置控件自然文字宽、同高、窄屏整体换行；不为隐藏提示保留行或宽高。各角色只显示有权限的入口。

盒子通过局部`BoxPanelScope`统一顶层和二级浮窗，浅绿圆角标题、14px标题内边距、44px关闭按钮，固定标题与单一内部纵向滚动容器；盒子局部外壳裁切圆角，不改共享游戏浮窗。连接帮助、头像、介绍、设置、昵称／座位与嵌套确认沿用外观。色框、网格和操作区允许收缩、换行及自然增高；长状态、错误、未确认与更新进度须在所属背景内完整可读。外壳与内滚动槽合并留白，不叠无意义右边距；滚动条保持圆角框内可辨。

既有共享滚动条约10px、奶油轨道、圆角滑块及悬停，各游戏可用自身颜色；Chromium/WebView2样式与标准回退分别处理，触摸主导及强制高对比保留系统行为。浮窗独立滚动并阻止穿透；介绍／头像宽度选择器要胜过通用外框。模糊放在backdrop，不改变内部固定通知定位范围；玻璃材质仅作用于适用面板。

## 头像选择与裁剪

头像页由独立上传区和大图预设画廊构成，当前头像用勾选／描边识别，已占用头像锁定并显示占用者，省略重复“可选”；说明用全行宽自然换行。头像身份使用稳定`avatarId`及服务端唯一占用，不恢复旧原型按座号分配头像。文件校验、取消与提交条件不变；既有玩家选择等待服务端确认，入座前只改变草稿。

裁剪保留拖动和缩放，选图后收起预设列表；按视窗高度调整预览，取消／确定紧接缩放条，短屏首屏可操作。裁剪展示不能改变上传、占用、保存失败及重试语义。

## 网址与连接帮助

现行绿色入口文案为“打开网址”，当前完整网址在帮助中换行、可复制；不恢复直接把长网址放在按钮或旧“使用网址”／“打开网站”文案。按钮保持外链含义、与二维码同一当前地址、48px最小高度、至少18px信息与可见焦点。标题沿用“扫码或使用网址”；本节以[网址按钮最新确认](art-preferences.md#盒子最新直接要求2026-10-09至11)为依据，旧文案只在历史原文追溯。

连接帮助按连接方式、电脑地址和当前网址分组，地址刷新44px图标按钮，排查按需展开。标签提供悬停、聚焦、触屏点按说明；手机外部网址标签独立一行，前缀与输入同排。当前网址、仅本机警告、配置错误和保存反馈保持可读，面板打开时保存反馈在内部，关闭后才用页面浮层，不能遮住标题。

外部前缀按“无前缀→http://→https://→无前缀”循环，协议与输入体拆分，完整粘贴不重复前缀。输入类型URL，示例`https://example.com:12345`；完整网址保存、裸地址和空前缀的合法性以[平台连接契约](phase-02-platform-spec.md#浏览器入座换机与外部连接2026-10-07)为准，视觉不能扩大协议白名单。连接样式由`invite-friends.css`负责，移除旧覆盖需先核实实际使用。

## 设置与管理面板

盒子和全部正式游戏／玩法在管理与玩家端从既有游戏设置调节当前设备声音，无倒计时权限也不隐藏入口；视频设置保留。声音统一记忆并同步同源页面，静音停止游戏／互动声音但保留互动视觉，重新开启不补播；电脑声音由管理窗口承担，不再使用公共屏优先，手机范围与手势限制仍按平台／游戏权限。原生电脑提供适配与窗口模式，手机至少保留全屏选项，不支持时明确不可用及原因，不增加手机分辨率选择。

配置标签与开关／选择器同排，滑条为标签、滑条、当前值一行；不保留大号数值区、常驻长说明及重复嵌套标题。详细效果放标签悬停、键盘焦点、手机点按提示，进入顶层且可读，Escape先关说明。错误、待确认、全屏不可用原因直接展示。UNO原0–5秒、0.1秒精度及0.5秒标记保留，不恢复快捷按钮。

管理设置同样紧凑分行：手机房主、换机申请、决策点回退各自同排呈现标签与选择／状态／入口，移除公共屏分组和开窗动作。无换机申请只显示单行状态，有申请完整显示姓名、核对码及批准／拒绝；后果与安全确认即时可见。共享完整管理组件沿用，暂停／结束等权限和确认不变。房主说明包含修改玩家名称，不能只写人机。

视频设置容纳显示模式、互动特效和电脑适配，真人另有“射击按钮”开关；隐藏射击入口与屏蔽接收特效独立，关闭后可恢复。全屏入口在视频设置，F11固定切换但不显示快捷键提示；从无边框／全屏返回有边框，从有边框进入全屏，显式模式选择与Escape恢复原模式保留，普通浏览器与原生能力按平台规格判断。

## 提交与保存反馈

普通提交及成功回执使用独立页头浮层，与“已连接”结构解绑；横屏优先品牌右侧空白，窄屏使用安全锚点，不覆盖品牌、设置、连接状态。锚点绝对定位、零尺寸且不参与flex／grid，不增加专用行、内边距或隐藏占位；出现前后其它组件几何、用户滚动与存续席位DOM不变。

仅新的权威成功确认显示“✓ 已保存”，1500ms后320ms淡出，连续成功重置计时、不堆叠；减少动态直接切换。挂载、心跳、普通重绘、恢复页面及旧状态重连不重播；未确认或失败不得显示成功。失联、入座待确认、保存未确认、失败与重试继续保持可恢复的持续入口，不能随成功浮层消失。成功提示不抢焦点、不接管指针，低于原生详情浮窗；浮窗内部反馈按所属面板处理。

其余短时通知复用`NotificationCenter`：当前普通停留1500ms、离场320ms，不恢复旧5.5／8.5秒参数。默认最多3条（含离场），超限移除最早，相同内容和类别合并续时；可关闭，悬停／焦点／页面隐藏暂停，减少动态不模糊或位移，文字18px、关闭44px，短屏可滚动。通知不加遮罩或抢焦点，原生modal打开时挂入当前浮窗，关闭后回页面并释放暂停；头像面板不重复显示会话回执。组件仅盒子挂载，其它游戏不因本页整理新增重复通知。

提示文案归[`feedback.zh-CN.json`](../../apps/web/src/content/feedback.zh-CN.json)，按用途分组；`messageKind`按稳定文案键分类，改文字不能改变进行中、保存回执、成功、连接状态的语义。完整帮助、控件名称、游戏规则及系统提示仍按各自主题维护。

## 验证与证据
