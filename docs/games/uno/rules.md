# 经典 UNO 规则

版本依据为 [U01：Mattel G7942](sources.md)。本项目支持 2–6 人，使用经典 108 牌，以先到 500 分为整场赢家。

## 牌组与准备

红、黄、绿、蓝各 25 张：每色数字 0 一张，1–9 各两张，跳过、反转、+2 各两张；另有 4 张变色 Wild 和 4 张 Wild +4。每张实体牌有唯一编号。

每人抽一张比较数字，行动牌计 0，最高者成为发牌者。洗回全部牌后，从发牌者左边顺时针逐张发牌，每人 7 张。其余为牌库，翻顶牌作为弃牌。

开局数字牌由发牌者左手边玩家先行动。开局跳过会跳过此人；开局 +2 让此人摸两张并跳过；开局反转改为发牌者先行动，之后逆时针。开局普通 Wild 由首位玩家选颜色，并继续由他行动。开局 Wild +4 返回牌库，另翻开局牌。

## 回合与五种行动牌

自己的回合出一张匹配当前颜色、数字或符号的牌，也可出 Wild。可以有牌却自愿摸一张；摸牌后这一回合只能出刚摸到的牌，不能再打旧手牌。刚摸牌能出时可以立即出或保留；不能出时自动交棒。

| 牌      | 出牌条件与效果                                                                    |
| ------- | --------------------------------------------------------------------------------- |
| 数字    | 同色或同数字；正常交给下一位                                                      |
| 跳过    | 同色或同符号；下一位失去回合                                                      |
| 反转    | 同色或同符号；改变行进方向                                                        |
| +2      | 同色或同符号；下一位摸 2 张并失去回合，不能用 +2／+4 挡罚                         |
| Wild    | 任何回合均可出，选择红／黄／绿／蓝，可选原颜色                                    |
| Wild +4 | 只有没有当前颜色牌才合规；可有同数字或其他同符号牌。选颜色，下一位接受罚 4 或质疑 |

经典玩法每次只出一张；不启用罚牌叠加、相同牌抢出、7–0 换牌、补到有牌或手牌交换。

## +4 诈唬与质疑

U01 明确允许有当前颜色牌时诈唬出 +4。只有被要求摸牌的下一位可以质疑。判断使用 +4 提交当时的手牌与**变色前**当前颜色，其他数字或符号不构成同色违规。

- 接受：受罚者摸 4 张并跳过。
- 质疑成功：出 +4 者有旧当前颜色牌，由他摸 4 张；质疑者免罚并正常行动。
- 质疑失败：出 +4 者没有旧当前颜色牌，质疑者摸 6 张并跳过。

被质疑者的当时手牌证据只给质疑者看；公共屏、管理员与其他玩家只看结果和摸牌数量。抓漏 UNO 的追加摸牌不会改写先前 +4 合规性证据。

## UNO 宣告与抓漏

打出倒数第二张时需喊 UNO。数字界面可将“同时喊 UNO”与出牌一同保存。忘记时，本人可以补喊；其他玩家可以抓漏，让漏喊者摸 2 张。补喊或抓漏哪项先成功保存，哪项生效；不能对尚未打出的牌提前抓漏。

U01 的结束边界是下一玩家开始从牌库取牌或从手中取牌去出。数字平台以实际保存的下一回合动作关闭窗口，具体自动步骤适配见下文。没有秒数倒计时、自动罚漏喊或强制等待；动画播放、网络重连、暂停及恢复不改变窗口。

## 两人、小局结束与整场计分

两人时，跳过与反转都让出牌者立即继续；反转同时改变方向。+2／+4 在对方受罚并失去回合后，也回到出牌者。质疑成功时仍由质疑者正常行动。

先清空手牌者赢得小局。若末张是 +2，先罚摸两张再计分；若是 +4，先处理受罚者接受或质疑，再计分。罚摸得到的牌计入剩余手牌。

数字牌按面值，跳过／反转／+2 每张 20 分，Wild／Wild +4 每张 50 分。小局赢家获得其他玩家剩余牌总点数；其余人累计分不变。未到 500 时，由管理员或授权真人房主开始下一小局；有人累计达到或超过 500 时整场结束。

牌库耗尽而未结束时保留最新弃牌，将旧弃牌洗成新牌库继续。服务端一次处理整个罚摸与结算，不等待声画完成。

## 数字平台解释

以下为项目实施选择，与上述官方明文分开维护。

1. 人数采用原版 2–10 范围中的平台上限 2–6。初始化比较数字由可恢复随机源代抽；最高同点者重新比较，最多 8 次后仍同点按稳定座位序取首位，避免异常随机源造成无限初始化。下一小局发牌者顺时针轮换。
2. 翻到开局 +4 时先暂放一边，找到非 +4 后把这些牌洗回牌库；等价保留牌组且最多暂放 4 张，避免重复返回同牌导致无限翻牌。
3. +2 自动罚摸与出牌原子保存，因此抓漏窗口保留到下一名需要行动的玩家主动出牌／摸牌、接受或质疑 +4 的保存动作开始；系统自动罚摸不单独截断窗口。这给行动牌后的漏喊保留可操作机会。跳过／两人反转后，本人下一次主动行动也关闭旧窗口。
4. 官方没有单独举例末张 +4 质疑。本项目先完成原文质疑权，再结束小局：接受罚 4；失败质疑罚 6 后计分。末张 +4 不可能有其他同色手牌，因此一定合规；不会在已经结束后忽略质疑。
5. 若牌库与可重洗的旧弃牌都为空，摸牌只取得实际可用数量；普通摸牌取不到牌则结束回合。不复制实体牌，也不伪造无限牌库。
6. +4 证据取出牌后、罚牌前的完整手牌快照；敏感证据在本小局保留给挑战者，下一小局清除。存档恢复核验完整证据，不允许删除同色牌来洗白。
