# UNO 界面与声画

视觉采用经典四色牌、白纸边、斜椭圆与实体卡牌符号，背景为明亮奶油织垫和木边。此方案依据本次用户的“桌游特质、精美自然、动效音频吸睛”与[美术偏好](../../reference/art-preferences.md) G01／G02／G04／G09／G10／G11／G13／G14／G18；具体材质、色值、布局及动效时长是实现选择。

## 三端与操作

2026-10-24已确认[管理兼展示与公共屏退役](../../reference/phase-02-platform-spec.md#管理兼展示与公共屏退役2026-10-24)，当前源码已落实，实际验证与旧包边界见[验收](../../reference/acceptance.md#当前源码与本地交付)。管理界面继续使用本游戏相同的`public`公开投影，玩家权限及操作不变；下文旧public界面参数、三端截图与报告仅在原实现及输入范围内适用。

- 管理兼展示界面保留中央牌库、弃牌堆、当前颜色及行牌方向，公开座位沿桌边排列，展示头像、昵称、剩余张数、累计分与 UNO 状态。管理员没有手牌；不再另设独立公共屏。
- 玩家手机把围桌摘要、中央牌堆和本人手牌重新分区。手牌仅在本人浏览器本地排列，手机适度叠放并横向浏览，每张暴露区域至少 44px；多人或密集手牌不会压缩文字。宽屏玩家将桌面与本人操作并排，权限沿用本人身份。
- 合法普通牌亮边并可直接点出；万能牌点选后在手牌区选择颜色并提交，取消只撤销本地选择。摸后只能出刚摸到的牌，或“保留，过牌”。
- 不再提供“出牌时喊出”开关，倒数第二张牌保存后开放独立喊牌与漏喊质疑。漏喊者补喊与其他人的抓漏由合法决策直接呈现，不能因本人不是普通回合行动者而隐藏。
- +4 的指定受罚者可“接受，摸 4 张”或“质疑 +4”。本人新保存的+4质疑结果会自动在结果附近显示可关闭、横向浏览的证据行，不再增加“查看你的质疑证据”按钮；管理员、公共屏及其他玩家不收到手牌证据，首次同步／恢复不补弹。
- 小局与整场结算分别展示累计分、剩牌点数、本局实际得分和赢局数。只有管理员或授权房主能开始下一局、恢复与再玩一场。下一局与管理面板使用平台生命周期动作。

规则入口位于顶栏，三端均可打开顶层原创图文规则。卡牌、数字、四色标记与逻辑图解由代码绘制，不把游戏截图当作规则依据；查看、关闭和章节跳转不改变对局。规则采用来源与边界见[规则](rules.md)。

## 已保存结果反馈

最新行动区独立展示行动者昵称与动作，牌、选色、处罚和公开目标来自权威最新记录；“已保存”只对应服务器成功提交。UI 不预演尚未保存的牌面或牌库结果。

新保存结果使用本局独立序号及平台实例／分支／修订去重。普通牌以纸牌落桌和局部圆环表现；反转用旋转符号，跳过用禁止符号，+2／+4 用醒目数字；万能变色、UNO 与胜局增加四色纸屑。反馈层不接受指针输入，不阻挡下一位合法行动。减少动态隐藏飞牌、圆环和纸屑，保留短静态符号；测试模式不播放装饰声画。

声音是本项目原创、可复现的离线立体声 PCM，合成脚本为 [prepare-uno-audio.mjs](../../../tools/assets/games/uno/prepare-uno-audio.mjs)。当前采用13项v2分层合成音效，生产文件为无损FLAC，解码PCM与合成WAV逐字节一致；原WAV保存在 `artifacts/uno/audio/source-originals/`，时长、峰值、版本与文件哈希见[v2音频清单](../../../assets/games/uno/audio/manifest-v2.json)。纸张瞬态、温暖敲击与短旋律分别表达落牌、摸牌、反转、跳过、+2、+4、变色、UNO、+4 质疑、独立漏喊质疑与获胜。v2为跳过、反转、+2、变色、+4、UNO、抓漏、+4质疑成功／失败及接受等提供独立节奏和分层音色；动效同步使用各自公开结果图案，累计处罚展示实际补牌数。事件优先级仍为结算、质疑、UNO、功能牌、普通落牌；音频仅随新保存反馈播放。完整同步、刷新、重连与回退不会补播历史声音。

提示音沿用平台静音偏好。主机与公共窗口通过 native claim 去重；玩家须手势解锁，仅播放本人已保存行动。暂停、断连、切后台、实例／分支切换及卸载会停止播放，并撤销待完成的媒体或 native claim。浏览器拒绝播放只改变提示音按钮状态，不影响规则与保存。自动验证默认静音，音频解码／播放事件观测不等于真人听感验收。

## 显示与验证边界

信息文字至少 16 CSS px，主要动作与关键状态至少 18px，电脑分区标题至少 20px；牌背小字与纸屑仅为装饰。触控按钮至少 44px，手牌与颜色按钮保留键盘焦点。正文、规则、证据和结算可自然滚动，公开牌桌保持稳定。

源码入口为 [web/index.tsx](../../../games/uno/web/index.tsx)、[ui](../../../games/uno/ui/)、[样式](../../../games/uno/ui/style.css)。实际三端截图、密集手牌、短屏、普通节奏、减少动态与同包声画检查由本轮统一验收记录说明；模拟手机与隐藏原生窗口不代表实体设备或人耳听感通过。

2026-10-10 实际隐藏 Native 普通模式检查完成：320×568 短屏上移完整保存结果并精简桌面，保留可操作手牌与摸牌入口；最终 844×390 横屏预留互动浮球空间，颜色与动作不被覆盖，密集手牌首末可滚动并命中。完整 108 牌 fixture 经生产校验加载；顶层图文规则只读可关闭。实际阶段、尺寸、声画与包哈希边界见 [当前验收](../../reference/acceptance.md#105经典-uno-完整本地交付2026-10-10) 和 [当前包横屏](../../../artifacts/uno/validation/portable-landscape-6-02/results.json)，旧失败与旧图继续保留。

## 本地手牌整理（v1.0.6）

默认可打牌前置，并按红、黄、绿、蓝、万能及数字升序排列；单个排序图标切换颜色／数字，数字模式先 0–9，再功能牌，同值按颜色稳定排列。长按约 320ms 后拖动调位，短按仍走合法出牌，移动超过 8px 的快速横滑只浏览；不可出的牌也可整理，边缘可滚动，Alt＋左右键可调整焦点牌的位置。

手动调位后保持该顺序，合法性变化只更新亮边，新牌追加；点击排序图标才恢复自动整理。顺序按实例、本人座位、小局保存在 sessionStorage，仅存本人牌 ID 与排列模式；同标签刷新恢复，新小局、设备及标签采用默认顺序。服务器手牌、动作、计时、存档及声音不因整理改变。暂停、断连、决策分支变化与牌消失取消未完成手势。

排行榜图标打开公开累计积分榜，积分降序、同分并列，座位顺序稳定。玩家最新保存条仅保留一份，放在手牌上方，保留行动者、具体动作与保存状态。手牌容器不再按决策 ID 重建，纸牌倾角按牌 ID 固定；多人桌面座位向外推并限制在容器内。密度、44px 暴露区域与手势时长属于本次批准的实现参数，不另作长期个人偏好。

## 右侧边界修复（2026-10-11）

玩家页自行承担纵向滚动，根节点不再重复预留滚动条槽；手牌区去掉旧浮球的60px右侧空位，保留旋转末牌的内侧留白与本地滚动。竖屏将64px底部空间留给互动浮球，新默认位置置底，已保存的拖动位置继续恢复；手牌区延伸至页面内容右侧。共享互动层仅读取游戏可选的默认位置CSS变量，其他游戏默认高度仍为67%，规则、动作和声音未改。

## 手机紧凑布局与设置（2026-10-20）

手机围桌摘要改为自然高度的姓名／牌数行，牌堆、当前颜色及方向组合排布；排序图标与“手牌／张数”同行，不再独占操作行。主要操作保留18px、信息至少16px和44px触控，密集手牌保留48px可操作露出与本地横向滚动，通过重排减少总纵向空间，不压缩必要内容。长昵称和结果说明可换行，手牌保留本地排序与按当前决策取消失效手势。

手牌横向滚动区上沿为旋转、可出牌抬起、悬停及键盘聚焦预留空间，完整容纳牌面与合法牌轮廓，避免在“手牌／张数”行下方切边；保留原有滚动裁切边界，不靠提高牌面层级覆盖操作行。

现有游戏设置中增加UNO专属开局配置：传递开关及0–5秒抓漏宽限滑条；每项一行，抓漏为标签、滑条、当前值，保留0.1秒精度与0.5秒标记，不提供独立快捷按钮。详细效果移到标签的悬停／聚焦／点按说明中，去掉重复标题和嵌套卡片；局中显示本场只读值。抓漏按钮显示权威剩余宽限，只有抓漏受限，本人喊UNO及普通回合不被计时组件拦截。经典／传递的累计接受、质疑失败数量与规则图文均按实际设置呈现。设置保存权限和时间事实见[信息与决策](information-and-decisions.md)。

共享页面与本游戏的无溢出滚动区不再为稳定滚动槽预留空白；实际滚动轨道和角落使用透明或主题色，触屏保留系统滚动操作。界面证据分别记录源码模拟尺寸、当前视口总高度与设备边界，不将源码检查写成实体手机听感或全屏通过。

开启补牌传递时，+4响应区在本人有合法出牌动作时提示可从手牌继续出+4；手牌选色沿用既有流程，累计处罚、接受与质疑同屏保留。连续传递只保留最新+4出牌者的质疑依据，不提供回头质疑入口；未开启传递或末张+4不显示继续传递提示。
