# UNO 界面与声画

视觉采用经典四色牌、白纸边、斜椭圆与实体卡牌符号，背景为明亮奶油织垫和木边。此方案依据本次用户的“桌游特质、精美自然、动效音频吸睛”与[美术偏好](../../reference/art-preferences.md) G01／G02／G04／G09／G10／G11／G13／G14／G18；具体材质、色值、布局及动效时长是实现选择。

## 三端与操作

- 主机与公共屏保留中央牌库、弃牌堆、当前颜色及行牌方向，公开座位沿桌边排列，展示头像、昵称、剩余张数、累计分与 UNO 状态。管理员没有手牌；公共屏只读。
- 玩家手机把围桌摘要、中央牌堆和本人手牌重新分区。手牌按原投影顺序横向浏览，每张牌保留完整可触达按钮；多人或密集手牌不会压缩文字。宽屏玩家将桌面与本人操作并排，权限沿用本人身份。
- 合法普通牌亮边并可直接点出；万能牌点选后在手牌区选择颜色并提交，取消只撤销本地选择。摸后只能出刚摸到的牌，或“保留，过牌”。
- 手里两张时有“出牌时喊出”开关，出牌可同时喊 UNO。漏喊者补喊与其他人的抓漏由合法决策直接呈现，不能因本人不是普通回合行动者而隐藏。
- +4 的指定受罚者可“接受，摸 4 张”或“质疑 +4”。质疑结果只有获授权的本人能打开手牌证据，不发送给管理员、公共屏或其他玩家。
- 小局与整场结算分别展示累计分、剩牌点数、本局实际得分和赢局数。只有管理员或授权房主能开始下一局、恢复与再玩一场。下一局与管理面板使用平台生命周期动作。

规则入口位于顶栏，三端均可打开顶层原创图文规则。卡牌、数字、四色标记与逻辑图解由代码绘制，不把游戏截图当作规则依据；查看、关闭和章节跳转不改变对局。规则采用来源与边界见[规则](rules.md)。

## 已保存结果反馈

最新行动区独立展示行动者昵称与动作，牌、选色、处罚和公开目标来自权威最新记录；“已保存”只对应服务器成功提交。UI 不预演尚未保存的牌面或牌库结果。

新保存结果使用本局独立序号及平台实例／分支／修订去重。普通牌以纸牌落桌和局部圆环表现；反转用旋转符号，跳过用禁止符号，+2／+4 用醒目数字；万能变色、UNO 与胜局增加四色纸屑。反馈层不接受指针输入，不阻挡下一位合法行动。减少动态隐藏飞牌、圆环和纸屑，保留短静态符号；测试模式不播放装饰声画。

声音是本项目原创、可复现的离线立体声 PCM，合成脚本为 [prepare-uno-audio.mjs](../../../scripts/prepare-uno-audio.mjs)。生产文件采用无损 FLAC，十项解码 PCM 与合成 WAV 逐字节一致；原 WAV 保存在 `artifacts/uno/audio/source-originals/`，时长、峰值、版本与文件哈希见[音频清单](../../../assets/games/uno/audio/manifest.json)。纸张瞬态、温暖敲击与短旋律分别表达落牌、摸牌、反转、跳过、+2、+4、变色、UNO、质疑／抓漏与获胜。事件优先级为结算、质疑、UNO、功能牌、普通落牌；音频仅随新保存反馈播放。完整同步、刷新、重连与回退不会补播历史声音。

提示音沿用平台静音偏好。主机与公共窗口通过 native claim 去重；玩家须手势解锁，仅播放本人已保存行动。暂停、断连、切后台、实例／分支切换及卸载会停止播放，并撤销待完成的媒体或 native claim。浏览器拒绝播放只改变提示音按钮状态，不影响规则与保存。自动验证默认静音，音频解码／播放事件观测不等于真人听感验收。

## 显示与验证边界

信息文字至少 16 CSS px，主要动作与关键状态至少 18px，电脑分区标题至少 20px；牌背小字与纸屑仅为装饰。触控按钮至少 44px，手牌与颜色按钮保留键盘焦点。正文、规则、证据和结算可自然滚动，公开牌桌保持稳定。

源码入口为 [web/index.tsx](../../../games/uno/web/index.tsx)、[ui](../../../games/uno/ui/)、[样式](../../../games/uno/ui/style.css)。实际三端截图、密集手牌、短屏、普通节奏、减少动态与同包声画检查由本轮统一验收记录说明；模拟手机与隐藏原生窗口不代表实体设备或人耳听感通过。
