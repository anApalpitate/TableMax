# UNO 本地三档电脑策略

入口：[bot/index.ts](../../../games/uno/bot/index.ts)。策略 ID `uno-local`，版本 `1.0.0`，适配 `classic-108-g7942-1`；三档为 `default`／`doubao`／`juewu`。名称只是本地等级，不调用云端产品。

## 实际差异

| 等级 | 已实现取舍                                                                                                                               |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 默认 | 优先普通数字，再考虑持有同色数量；无普通牌才用 Wild。覆盖所有节点，避免不合规 +4，倒数第二张总是同时喊 UNO；不记对手具体牌               |
| 豆包 | 比较本方剩余同色数量／点数、甩高分牌、保留 Wild 弹性；下一位只剩 1–2 张时优先跳过、反转回避或罚摸。保留本人质疑获准看到的最多 3 张对手牌 |
| 绝悟 | 在豆包评分上比较下一次可接出的牌、两人连续行动、末张颜色风险与公开对手颜色倾向；保留完整获准证据，并利用已知对手末张避免放行             |

固定局面验证默认与豆包的危机拦截差异，以及豆包多数颜色与绝悟避开已知末张的差异；不以某一场胜负宣称档位一定更强。

## 逐节点覆盖

| 选择           | 三档共同覆盖                               | 档位补充                                               |
| -------------- | ------------------------------------------ | ------------------------------------------------------ |
| 开局选色       | 选本人手牌最多／点数较多的颜色             | 绝悟考虑公开颜色倾向与获准记忆                         |
| 正常出牌       | 比较本人枚举的合法意图，优先出牌而非自愿摸 | 如上表评分差异                                         |
| 没牌可出       | 摸一张                                     | 不读取未来牌序                                         |
| 刚摸牌可出     | 出此牌并在剩一张时喊 UNO                   | 若刚摸到的是不合规 +4，则保留，避免诈唬                |
| 刚摸牌保留     | `pass`                                     | 覆盖唯一合法保留出口                                   |
| +4 响应        | 无确定证据时接受罚 4                       | 豆包／绝悟记得仍在出牌者手里的旧颜色牌时质疑；默认接受 |
| UNO 补喊／抓漏 | 有该动作就优先响应                         | 不绕过窗口，不按时钟猜测                               |
| 小局／整场结束 | 无游戏选择                                 | 等待管理员／房主生命周期动作                           |

全部档位只使用本人的 `UnoView`、服务给定合法动作与相应记忆；不导入规则完整状态、不看牌库、不读取其他座位 hand。+4 的隐藏 guilty 从未进入策略输入；只凭获准旧证据质疑，不把概率猜测写成确定违规。当前策略不主动诈唬，不声称搜索了对手未知牌或整个未来牌序。

## 记忆、预算与恢复

记忆为可序列化版本 1：小局号、最后观察动作序号、各座位获准已知实体牌和公开颜色倾向。只有本人质疑完成的证据会填入对手牌；其后该对手公开出牌时删去对应实体牌。普通牌颜色只是弱倾向，Wild 主动选色的权重更高，不能据此声称对手一定有某色。

默认保留空观察结构；豆包最多记 3 张，绝悟保留全部授权证据。下一小局重置；回退恢复对应 memory。未知版本、未知卡、超过六席、错误颜色或额外字段拒绝恢复。`observe` 为纯观察，只有平台成功保存才提交；重复序号不重复观察。

策略确定性评分且有界，最多评估当前枚举的本人动作，检查取消信号；不使用时钟或 `Math.random`，不消耗规则随机源。平台仍使用既有 32 MiB Worker／2 秒单次预算，等待节奏与测试静音由平台负责。返回意图通过统一规则再校验与保存，bot 不提交房主或管理员命令。
