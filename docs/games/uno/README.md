# UNO 经典版

采用 Mattel G7942 同版 **108 张牌**的经典 UNO，平台支持 **2–6 人**。普通回合、两人特别规则、+4 质疑、UNO 抓漏与累计 500 分分别按出版原文及明确标注的数字适配维护；不混入自定义牌、交换手牌或其他 UNO 版本。
