# 基础人机逐决策规格

第二阶段完成设计；策略实现、真实调度和混合整局产品验收分别属于第三至六阶段。[通用规格](../../reference/bot-players.md) 的 B01 采用独立 TypeScript 模块默认方案，理由是与锁定语言及动作类型兼容、完整覆盖复合选择，无需额外配置解释器；不是声称用户另行选过文件形式。不承诺外部脚本运行、热替换、JSON 策略编辑器或难度 UI。

计划文件 `games/pokemon-encounters/bot/index.ts` 为统一入口，可按节点分小文件；`id=pokemon-encounters/basic`、`version=1`，兼容 `tablemax-cn-s19-v1` 与状态版本 1。输入类型为投影 view、当前 pending 的合法意图、decisionId／branch／revision、该座位可序列化策略数据。只返回其中一个合法意图及更新后的策略数据，平台重新验证／保存；不传 RuleContext 全状态或凭证。

首版基础策略默认无记忆、确定性规则，`memory=null`、不消耗策略随机源；选择排序仅按公开 source／seatOrder／slot。未来随机策略需平台独立 RNG 数据并版本声明，不能调用时钟／Math.random 或改变游戏 RNG。临时查看授权仍按该座位规则清除；本无记忆策略可不利用 peek 得到的记忆，避免撤销分支知识外泄。

| 节点／对应决策 | 授权输入与合法参数 | 简单选择方案 | 无目标／恢复／场景 |
| --- | --- | --- | --- |
| 初始翻牌 D01 | 自己六个背面格号，initial-flip | 选最小合法格号，不读暗牌值 | 全员选择独立提交；V01 |
| 抽取 D02 | 牌库数量、弃顶、合法 deck／discard | 优先牌库，空牌库仍按规则重洗；只有合法 discard 时取顶 | 不读取牌序；V02、V09 |
| 普通处理 D03 | 公开新牌、自己明牌／背面、合法 replace／discard | 若能替换优先最小合法暗格，否则替换公开最高固定值（百变怪未知值置最后），全明稳定状态不会进入新回合；合法弃为备选 | 来源弃牌不返回 discard；V02 |
| 梦幻他人 D04 | 对手可选座位／格号、公共牌 | 按顺时针座位后最小合法暗格，否则最小格号 | 不试探未知类别；V03 |
| 梦幻己方 D05 | 公开转移牌、本人可选格 | 最小合法暗格优先，否则公开最高数值格 | 移动来的能力不连锁；V03 |
| 火箭队喵喵 D06 | 固定币面、本人合法格号 | 最小合法暗格，否则公开最高数值格 | 不决定币面，不重投；V04 |
| 火箭队皮卡丘 D07 | 固定币面、本人合法格号／公共布局 | 选最小合法暗格，否则最小格号 | 全员补位由引擎自动，不额外调度 bot；V05 |
| 闪电鸟首次 D08 | 公开新牌、本人合法格 | 按 D03 的暗格优先方案 | 传递队列不改变正常回合；V06 |
| 闪电鸟被动 D09 | 自己为当前 recipient、公开 held、合法格 | 最小合法暗格，否则公开最高数值格 | 真人接牌需等待真人，bot 不接管；V06、V14 |
| 卡比兽 D10 | 合法 swap／decline | 选择 decline（合法完成可选节点）；专项 fixture 另验证 swap 意图可由替换策略返回 | 可选不发动也覆盖节点；V07、V17 |
| 喷火龙 D11 | 仅本人合法暗格、peek／decline | 有 peek 则最小合法格，否则 decline；无目标由规则跳过 | 不读其他人的暗牌；V08、V18 |
| 关闭查看 D12 | 该座位临时合法查看阶段 | close-peek | 保存后清理临时授权；V08 |
| 新小局 D13 | 非策略游戏节点 | 由房主管理开始，bot 不调用管理动作 | 结果／下一局首位由规则负责；V11 |

所有排序在 legalOptions 内完成，不通过给非法格号看错误来筛选。基础策略不必最优；专项覆盖必须验证参数和可选发动分支，不能以默认 decline 推断 swap／peek 的规则验证通过。

策略任务键 `gameInstance/decisionId/seat/branch/revision/strategyVersion`；初始 choicesBySeat 可包含多个电脑，逐座位调度；同键只调度一次，结果进入统一去重事务。暂停／回退／结束取消旧任务，迟到结果按键拒绝。输入只有该座位投影，日志仅节点／结果状态，禁打印视图中的秘密字段。缺少策略、异常或非法返回：停止推进、显示电脑决策失败、保留待选，不无限重试／偷偷 fallback；房主可暂停、结束或恢复，不默认改真人控制。

存档包含 strategyId／version／memory、未来策略 RNG；同 checkpoint 恢复同策略输入与数据。版本不兼容保留原文件并拒绝加载；更换策略在新大局、重新构建注册并检查兼容，不能在恢复中默默改变版本。第四阶段模板接入“合法首选”和“非法／延迟／异常”测试策略，验证同链路，不为真实策略放宽授权。

验证 V16 至 V20 对应 AC-19 至 AC-23；包括每节点参数、固定种子混合整局、全 bot 整局、真人等待、非法输出、旧结果、恢复与版本替换。输入结构审查必须证明没有 deck／暗牌值／调试数据；真实命令由实现阶段补，当前只交付覆盖及预期。
