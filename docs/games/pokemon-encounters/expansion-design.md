# 宝可梦奇遇扩展版设计基线

本方案是 TableMax 的自制扩展，支持 2–6 人。在原版“取牌、换牌、降低场地分数”的基础上，加入九宫格、横纵复制、更多干扰能力和全桌共同研究任务。原版仍独立保留，不采用本页的扩展规则。

原版与扩展从同一个游戏入口选择，新房间默认原版，再玩保留所选版本。两版均可搭配“默认／豆包／绝悟”三档电脑玩家；电脑玩家只使用本人有权知道的信息，不替掉线真人行动。

本文按现行方案说明玩法，包含 2026-10-08 确定的单弃牌来源、公开缓冲区及全部研究奖惩重设计。扩展实现与适用技术验收已完成；真人设备、听感、时长及平衡体验仍有待验证，见[真人验收接续](../../tasks/pokemon-encounters-expansion.md)。本方案不代表出版方的官方扩展规则。

**2026-10-11 设计更新：** 后续将共同机制分为“开局研究任务、局内特殊事件、羁绊事件”三类。研究投票保留，内容与收益等待进一步优化；特殊事件新增随机触发思路；丰缘齐聚改为独立羁绊事件，取消追加专属研究。以下明确区分当前实现与后续设计，本次仅更新文档，不改动游戏实现。新事件的具体效果均留空。

**牌组更新（2026-10-11）：** 采用下文重设计牌表作为后续目标；当前程序仍使用旧牌组。总量与角色集合不变，巨金怪改为 5 分，并调整部分角色数量以配合事件与羁绊。本次只更新设计文档。

## 设计目标与整体结构

扩展继续以低分获胜、先获三胜结束大局。九宫格让玩家同时考虑行、列和对角线；研究任务则增加“为了奖励保留高分牌、维持特定阵形或延后翻明”的选择。干扰能力可以改变他人的阵形与公开信息，缓冲区提供一次公开留牌的机会。

一小局的流程是：**投票选研究 → 发牌与初始翻牌 → 轮流取牌或调位 → 任意玩家全明后完成当前能力 → 结算分数与研究 → 记录胜局**。若尚无人累计三胜，继续下一小局。

| 项目       | 现行方案                                                     |
| ---------- | ------------------------------------------------------------ |
| 人数与场地 | 2–6 人，每人 3×3 九宫格                                      |
| 牌组       | 34 类角色；2–3 人用 112 张，4–6 人用 144 张                  |
| 归零方式   | 三行、三列、两条主对角线，共八条三格直线                     |
| 取牌来源   | 牌库顶、弃牌顶一张、本人缓冲牌                               |
| 缓冲区     | 每人一格，公开，不计入场地                                   |
| 研究任务   | 开局投票选一项；现行实现仍有丰缘追加研究，后续取消该追加机制 |
| 胜负       | 最低最终分可共同获胜；先获三胜，可共同赢得大局               |

希望扩展一小局在相同条件下达到原版约 2–3 倍时长。这仍是待测的体验目标，不能靠延长动画或自动化运行耗时认定达成。新增数值、牌数与研究奖励允许在实测后微调；原版固定数值保持不变。

## 开局、取牌与结束

### 开局准备

1. 发牌前，从开局研究池抽出三个任务，全员投票确定本小局的共同研究。
2. 暂时取出全部超梦与唯一一张阿尔宙斯，将其余牌洗牌，每人发九张暗牌。新牌组精简取出 2＋1 张，标准取出 3＋1 张；当前实现的两套旧牌组均为 2＋1 张。
3. 将取出的牌洗回剩余牌库，翻明牌库顶部一张作为初始弃牌。
4. 每名玩家自行选择本人一格翻明；全员完成后开始普通回合。

初始翻牌和初始弃牌都不发动能力。初始翻牌可以满足丰缘三神齐聚的追加研究条件。未结束的大局中，下一小局先手从上一小局赢家中随机选一人。

### 普通回合：取牌或调位

玩家在取牌前作出选择：**取一张牌处理，或者交换本人两张场地牌并结束回合。** 不能先看牌库顶，再改为调位。

取牌可以来自牌库顶、弃牌顶部一张或本人缓冲区。取得的牌向全桌公开；普通换入朝上，换出的牌公开进入弃牌顶。取得弃牌或缓冲牌必须使用，不能再次弃掉。尚未消耗能力的梦幻、火箭队、闪电鸟按各自强制流程处理，不能直接弃掉或存入缓冲来绕过能力。

从牌库取得原本允许弃掉的牌时，可以换入场地、直接弃掉，或存入空缓冲区。能力处理完毕后才进入下一位玩家的回合。

### 公开缓冲区

每人最多保留一张缓冲牌。存入缓冲即结束本回合；后续本人普通取牌阶段可以取出，但必须换入场地，不能再弃掉或存回。

缓冲牌始终公开，不参与九格计分、归零或研究条件，也不参与弃牌回洗。牌的能力使用状态随牌保留。下一小局重新洗牌时清空缓冲区。

### 普通调位

交换本人场地两个不同位置，牌的明暗随牌移动，随后结束整个回合。调位不附带翻牌、私看、弃牌或能力发动；能力子步骤与路卡利欧的额外取牌也不附送普通调位。

### 弃牌与回洗

弃牌只有顶部一张可取。例如从顶到底为 A、B、C、D，只能取 A；弃掉 X 后变为 X、A、B、C、D。不另设市场，也不从牌库补充展示牌。特殊能力要求弃底时，仍放到弃牌底。

牌库耗尽时，保留弃牌顶部一张，其余弃牌洗回牌库。普通回合无牌可回洗时，仍可选择合法的弃牌、缓冲或调位。

### 小局何时结束

任意玩家九格全部朝上，就在**当前行动与整条能力流程完成后**结算，不给其他玩家额外的最后回合。多步能力途中即使出现全明，也必须完成交换、接力、补位和待处理选择。

当前实现的结算顺序为：公布当前行动触发的追加研究 → 记录最后明暗状态 → 揭示剩余暗牌 → 解析复制与归零 → 计算研究调整和最终分 → 判定赢家与胜局。强制揭牌不发动能力，也不触发三神齐聚。后续取消丰缘追加研究；独立事件如何进入行动与结算流程，待事件效果确定后补充。

## 棋盘与计分

### 九宫格与归零

行号从本人场地上方向下为第一、第二、第三行；画面旋转不改变规则坐标。中央参与四条线，四角各参与三条线，四边中各参与两条线。短斜线和两张同分都不构成归零线。

先确定每张牌的有效值，再判断八条合法直线。完整三格有效值相同，该线上的牌都贡献 0 分；角色不同也可以成线。交叉位置只归零一次，负数线也归零。归零不会移除牌或补牌。

例如一行为 8、8、8，该行贡献 0；一行为 −2、−2、−2，也贡献 0，而非 −6。这里归零的是计分贡献，牌的有效值仍是 8 或 −2，可继续用于研究判定。

### 两种复制牌与统一解

百变怪只复制左右紧邻牌，索罗亚只复制上下紧邻牌。复制可沿混合链传递，但每一步都须遵守对应方向，最终到达有固定数字的牌；不能跨格、斜向或复制他人的场地。没有固定数字来源的循环不能凭空指定数值。

每张复制牌在一次结算中只使用一个有效值。程序为整块场地联合选择方案，先让**归零后的基础分最低**；若多个方案基础分相同，再让研究调整后的最终分最低；仍相同时按行优先的有效值与复制方向固定顺序裁定。两项研究共用同一个方案，不能分别挑选有利解，也不能为了研究选择基础分更高的解。

### 研究调整与胜局

本节说明当前实现。后续取消羁绊追加的专属研究，以下双研究叠加及 H05 的规则不再作为新机制的设计要求；研究内容与收益本次保持原样，事件对计分和胜局的影响尚未确定。

基础分是归零后九格贡献之和。研究条件使用复制后、归零前的有效值；涉及明暗的条件使用强制揭牌前的状态。缓冲牌不计入。两项研究分别基于同一份场地结果计算，再将各自分数调整相加，奖励不会互相放大。

例如基础分为 40，两项研究都奖励“正基础分折半”，各自减 20，最终分为 0；不会先折到 20，再折到 10。

最低最终分的玩家都是小局赢家。普通赢家获得一胜；研究可以使赢家本局获得零、一或两胜。额外一胜必须同时满足“任务达成”和“本人赢得小局”，即使达成两项额外胜局任务，也最多多得一胜。累计最多记到三胜，同时达到三胜可共同赢得大局。

任务中的“累计最多达到两胜”只限制本局新增胜局，不扣除此前胜局；H05 失败会让小局赢家本局获得零胜，但仍按赢家身份参与下一小局先手抽选。存在两项研究时，授胜限制采用较严格者。

### 组成原则

- 保留 34 类角色与两种总量：2–3 人使用 112 张，4–6 人使用 144 张。不新增角色，也不以增加神兽数量提高羁绊频率。

- 两套牌组的 10 分牌都占 12.5%，降低该档过度集中，增加中分牌的布局选择；保留足够高分牌，让归零、天气与 Mega 仍有价值。

- 阿尔宙斯与丰缘三神仍各一张。丰缘齐聚定位为罕见组合事件；其具体效果另行设计。
- 两套牌组按游戏作用调整数量，不机械按人数倍增。事件标记附着在现有牌实例上，不额外增加牌数。

### 与天气、Mega 和羁绊的配合

天气的角色归属和数值调整不变。按基线列出的角色，雨天受益水系有 **22／29 张**，晴天受益火系或草系有 **17／23 张**，沙暴受益岩石、地面或钢系有 **17／21 张**；双属性在同一种天气下只计一次。天气不要求覆盖同样数量的牌，后续应比较改变归零与留牌选择的实际价值。

### 落地与试玩边界

实施时同时更新牌组与分值，不能只改一部分。开局仍排除全部超梦和阿尔宙斯：精简取出 2＋1 张，标准取出 3＋1 张，发牌后再洗回剩余牌库。进行中的旧小局保留原牌组与分值，不能把场内巨金怪从 10 静默改成 5；新牌组的规则配置与旧存档接续在实施时配套处理。

现有研究条件、奖惩及羁绊条件本次不改。涉及高分、10 分线、角色组合的研究要在新牌组下重新检查可达性与收益；先记录差异，后续结合用户手写研究再优化，不能沿用旧牌组证据宣称新牌组已通过。

试玩优先比较：10 分线与其他归零线占比、复制参与率、2–6 人各人数下的羁绊出现率、收局回合数、额外摸牌与盖牌频率、天气拆线／成线以及 Mega 改变赢家的比例。标准增加复制与盖牌角色可能延长或缩短小局，效果不能仅由平均分推断。两套牌组保持同一设计方向，实测后再微调。

### 开局投票与任务池

开局池共 24 项。发牌前等概率抽出三个不同任务，每名玩家一票，提交后锁定；管理员和公共屏不投票。投票期间只公开谁已完成，本人只知道自己的选择。全员完成后公开票数，最高票任务当选；最高票并列时只在这些任务中等概率抽选。

### 任务条件与奖励的阅读约定

- “有效值”指复制后的数值；“角色”指牌本身的身份。复制出相同数字不等于变成同一角色。
- “归零线”只指八条合法三格直线。“归零外”或“未归零牌”指未参加任何归零线的位置。
- “四边中”指上、右、下、左边的中央位置；“跨度”指该列最大有效值与最小有效值之差。行合计按归零前有效值计算。
- 奖励中的“正基础分”只对大于 0 的基础分生效；折半、取三分之一按向下取整处理。“负数计 3 倍”只调整未归零负数牌。
- “牌计为某分值”是本项研究的计分调整，不改变其他研究的条件或重新生成归零线。“最多减 N 分”限制该项所写的减分部分。

每人每项只在结算时领取一次，无抢先奖励。局中不展示可能泄露暗牌的达成进度。条件、奖励和失败风险在投票前均可查看；插画与主题名称不增加正文以外的角色限制。以下沿用已确认任务名称，其中“裂空座”是任务标题用字，对应角色烈空坐。

## 局内特殊事件（后续设计）

### 随机触发思路

触发条件倾向于随机。建议在牌堆中随机选取 **X 张现有卡牌**，在牌上加一个特殊事件记号，X 默认值为 **1**。带记号的牌被抽出后，立即触发特殊事件。记号附着在卡牌上，这个思路不要求另加事件牌数量。

## 首轮试玩检查

真人试玩重点判断玩法选择是否有价值、研究是否过度主导胜负，以及延长的小局是否保持节奏。

| 关注点         | 需要观察的结果                                                       |
| -------------- | -------------------------------------------------------------------- |
| 时长与收局     | 同人数、同节奏对比原版的小局时长和回合数；记录首条归零线与全明时点   |
| 布局与缓冲     | 调位占比、缓冲留牌与取回频率；是否出现长期拖延而收益有限的回合       |
| 研究风险与回报 | 候选选择、任务达成率、奖惩改写赢家与第三胜的频率                     |
| 干扰能力       | 三神追加频率、行交换的针对性、盖牌循环；阿尔宙斯发动与未发动分别观察 |
| 理解成本       | 玩家能否分清有效值与计分贡献、复制与角色、全明与完整能力结束         |

规则检查继续关注混合复制、双任务共用结果、投票平票、三神途中与末步触发、阿尔宙斯随机与次数、超梦放弃、能力消耗与回洗、缓冲牌守恒。技术检查与真人体验分别记录，具体场景见[专项验证](validation-scenarios.md#扩展版专项场景2026-10-05)。

以上为当前实现的试玩与检查范围。后续研究优化和两类事件的体验检查，等待具体效果确定后补充；当前双研究与三神追加研究的证据不能证明新事件已经完成。

## 界面与声画表达

界面服务于当前决策：玩家应能看清牌源、暂持牌、目标、确认动作，以及当前研究的完整条件与风险。手机围绕本人操作组织；主机和公共屏展示全桌。研究详情查看不提交投票，不公开他人的暗牌、私看内容或秘密选择。

规则说明以九宫格、八条线、横纵复制、能力分支和研究实例为重点；原版与扩展分别讲解。配图表达主题，位置、数字和箭头准确呈现，不读取实时秘密信息，不增加强制教程。

声画只表达已保存的公开结果。特殊能力可有全屏登场，交换、盖回与接力按实际步骤表现；阿尔宙斯不画洗牌或重发，忍蛙只盖回时不画交换。多步结果按能力、追加研究、结算的顺序表达，但动画不延迟规则推进。减少动态保留文字和静态强调，恢复不补播历史事件；手机保持静音。

布局、姿态、声音来源与制作参数分别见[交互规格](interaction.md#扩展版交互与演出规格2026-10-05)和[资源记录](assets.md#扩展版多姿态资源规格2026-10-05)。
