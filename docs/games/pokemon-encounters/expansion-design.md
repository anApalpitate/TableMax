# 宝可梦奇遇扩展版设计基线

TableMax 自制扩展，支持 2–6 人。在原版取牌、换牌、降低场地分数的基础上，加入九宫格、横纵复制、干扰能力、研究任务和局内事件。

原版与扩展在同一个游戏入口选择，新房间默认原版，再玩保留选择。电脑玩家有“默认／豆包／绝悟”三档，只使用本人有权知道的信息。

本页说明设计方案。统一牌组、新研究池与新增事件尚待落地，当前交付和试玩进度见[验收接续](../../tasks/pokemon-encounters-expansion.md)。

## 设计目标与整体结构

扩展继续以低分获胜、先获三胜结束大局。九宫格让玩家同时考虑行、列和对角线；研究任务则增加“为了奖励保留高分牌、维持特定阵形或延后翻明”的选择。干扰能力可以改变他人的阵形与公开信息，缓冲区提供一次公开留牌的机会。

一小局的流程是：**投票选研究 → 发牌与初始翻牌 → 轮流取牌或调位 → 任意玩家全明后完成当前能力 → 结算分数与研究 → 记录胜局**。若尚无人累计三胜，继续下一小局。

| 项目       | 现行方案                                       |
| ---------- | ---------------------------------------------- |
| 人数与场地 | 2–6 人，每人 3×3 九宫格                        |
| 牌组       | 34 类角色、144 张，2–6 人统一使用              |
| 归零方式   | 三行、三列、两条主对角线，共八条三格直线       |
| 取牌来源   | 牌库顶、弃牌顶一张、本人缓冲牌                 |
| 缓冲区     | 每人一格，公开，不计入场地                     |
| 研究任务   | 开局投票选一项，达成减分，未达成不处罚         |
| 胜负       | 最低最终分可共同获胜；先获三胜，可共同赢得大局 |

希望一小局达到同条件原版约 2–3 倍时长，通过真人试玩观察决策与回合节奏。除固定四张复制牌外，其余张数与扩展数值可根据试玩微调。

## 开局、取牌与结束

### 开局准备

1. 发牌前，从开局研究池抽出三个任务，全员投票确定本小局的共同研究。
2. 暂时取出三张超梦与一张阿尔宙斯，将其余牌洗牌，每人发九张暗牌。
3. 将取出的牌洗回剩余牌库，翻明牌库顶部一张作为初始弃牌。
4. 每名玩家自行选择本人一格翻明；全员完成后开始普通回合。

初始翻牌和初始弃牌都不发动能力。初始翻牌可以满足丰缘三神齐聚的羁绊条件。未结束的大局中，下一小局先手从上一小局赢家中随机选一人。

### 普通回合：取牌或调位

玩家在取牌前作出选择：**取一张牌处理，或者交换本人两张场地牌并结束回合。** 不能先看牌库顶，再改为调位。

取牌可以来自牌库顶、弃牌顶部一张或本人缓冲区。取得的牌向全桌公开；普通换入朝上，换出的牌公开进入弃牌顶。取得弃牌或缓冲牌必须使用，不能再次弃掉。尚未消耗能力的梦幻、火箭队、闪电鸟按各自强制流程处理，不能直接弃掉或存入缓冲来绕过能力。

从牌库取得原本允许弃掉的牌时，可以换入场地、直接弃掉，或存入空缓冲区。能力处理完毕后才进入下一位玩家的回合。

### 公开缓冲区

每人最多保留一张缓冲牌。存入缓冲即结束本回合；后续本人普通取牌阶段可以取出，但必须换入场地，不能再弃掉或存回。

缓冲牌始终公开，不参与九格计分、归零或研究条件，也不参与弃牌回洗。牌的能力使用状态随牌保留。下一小局重新洗牌时清空缓冲区。

### 普通调位

交换本人场地两个不同位置，牌的明暗随牌移动，随后结束整个回合。调位不附带翻牌、私看、弃牌或能力发动；能力子步骤与路卡利欧的额外取牌也不附送普通调位。

### 弃牌与回洗

弃牌只有顶部一张可取。例如从顶到底为 A、B、C、D，只能取 A；弃掉 X 后变为 X、A、B、C、D。不另设市场，也不从牌库补充展示牌。特殊能力要求弃底时，仍放到弃牌底。

牌库耗尽时，保留弃牌顶部一张，其余弃牌洗回牌库。普通回合无牌可回洗时，仍可选择合法的弃牌、缓冲或调位。

### 小局何时结束

任意玩家九格全部朝上，就在**当前行动与整条能力流程完成后**结算，不给其他玩家额外的最后回合。多步能力途中即使出现全明，也必须完成交换、接力、补位和待处理选择。

结算顺序为：记录最后明暗状态 → 揭示剩余暗牌 → 解析复制与归零 → 计算研究奖励与最终分 → 判定赢家与胜局。强制揭牌不发动能力，也不触发三神齐聚。独立事件的行动与结算时序随其效果补充。

## 棋盘与计分

### 九宫格与归零

行号从本人场地上方向下为第一、第二、第三行；画面旋转不改变规则坐标。中央参与四条线，四角各参与三条线，四边中各参与两条线。短斜线和两张同分都不构成归零线。

先确定每张牌的有效值，再判断八条合法直线。完整三格有效值相同，该线上的牌都贡献 0 分；角色不同也可以成线。交叉位置只归零一次，负数线也归零。归零不会移除牌或补牌。

例如一行为 8、8、8，该行贡献 0；一行为 −2、−2、−2，也贡献 0，而非 −6。这里归零的是计分贡献，牌的有效值仍是 8 或 −2，可继续用于研究判定。

### 两种复制牌与统一解

百变怪只复制左右紧邻牌，索罗亚只复制上下紧邻牌。复制可沿混合链传递，但每一步都须遵守对应方向，最终到达有固定数字的牌；不能跨格、斜向或复制他人的场地。没有固定数字来源的循环不能凭空指定数值。

每张复制牌在一次结算中只使用一个有效值。程序为整块场地联合选择方案，先让**归零后的基础分最低**；若多个方案基础分相同，再让研究调整后的最终分最低；仍相同时按行优先的有效值与复制方向固定顺序裁定。研究沿用同一个解析方案，不为奖励选择基础分更高的解。

### 研究调整与胜局

基础分是归零后九格贡献之和。结算时检查开局选出的共同研究：固定减分任务达成者减去任务写明的 3、5 或 8 分；R23 将基础分直接除以 2；R24 调整符合条件的整行中各张牌的计分贡献。未达成者保持基础分。每人只应用一次当选研究效果；R24 同时覆盖所有符合条件的行，不对同一张牌重复折半。

固定减分任务的**最终分＝基础分−研究奖励**；R23 达成时**最终分＝基础分÷2**，未指定取整，保留可能的半分；R24 达成时将符合条件的牌逐张按**向下取整（归零后计分贡献÷2）**计分，其余牌贡献不变，再求和得到最终分。逐张取整是本次对“暗置行所有牌……分数/2”的计分解释，例如 5 分变为 2 分，−1 分仍为 −1 分，已归零牌仍为 0 分。

研究效果不修改牌值或重新判断归零，也不增加胜局。最低最终分的玩家都是小局赢家，各得一胜；先累计三胜结束大局，同时达标可共同获胜。

### 统一牌组

2–6 人共用一套 **144 张、34 类角色**的牌组。人数只改变初始场地占用，不改变牌组组成。

**百变怪固定两张，索罗亚固定两张。** 这四张复制牌的数量不随人数或平衡调整改变。阿尔宙斯、固拉多、盖欧卡、烈空坐各一张。

144 张可容纳六人的 54 张初始场地，发牌并翻出初始弃牌后，牌库仍有 89 张。两人时牌库为 125 张，稀有角色和标记事件通常需要更多摸牌才会出现；小人数试玩重点观察这一节奏差异。

### 分配思路

巨金怪为 **5 分**，与六尾一起补充中分档。10 分牌共有 **18 张，占 12.5%**，既保留高分归零的吸引力，也避免多个能力角色都挤在同一分值上。原版角色的固定分值保持。

六尾八张、木木枭七张，使火系和草系在天气中有足够存在感。水系仍有二十九张，但鲤鱼王控制在五张；高分的烈咬陆鲨也为五张。

卡比兽和路卡利欧各四张，超梦和甲贺忍蛙各三张。保留这些能力与羁绊的获取机会，控制交换、额外摸牌与盖牌流程的密度。复制搭档和丰缘三神维持稀有，其羁绊收益按组合难度设计。

### 与事件和羁绊的关系

按目前列出的角色归属，雨天受益水系 **29 张**，晴天受益火系或草系 **25 张**，沙暴受益岩石、地面或钢系 **21 张**。巨金怪在沙暴下为 3 分，在雪天下仍为 5 分；无天气时可与六尾组成 5 分线。

## 特殊能力

### 能力如何触发

主动能力只在符合正常取牌与换入流程时发动。初始翻牌、已有场地牌转移、火箭队补牌和路卡利欧额外牌不连锁发动主动能力。百变怪、索罗亚的被动复制不受此限制。

### 原有能力的扩展版边界

| 角色   | 扩展版能力流程                                                                                                                                                                   |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 梦幻   | 未消耗的梦幻新取得时必须使用：换走对手任意一格，再将取得的牌换入本人场地，己方换出牌弃掉。两次选位都由行动者决定。                                                               |
| 火箭队 | 未消耗的新取得火箭队必须先掷币。喵喵面换入己方一格；皮卡丘面选择己方一格，将该牌、火箭队及其他玩家同位置牌弃底，再从本人开始顺时针摸牌朝上补空位。只处理一个位置，不扩大到整行。 |
| 闪电鸟 | 未消耗的新取得闪电鸟必须换入本人场地；行动者选择顺时针或逆时针，将换出牌依次传给每个其他玩家。接牌者自行决定换入格，最后换出牌弃底，不传回起点。                                 |
| 喷火龙 | 换入后可私看本人一张暗牌，也可放弃；无暗牌则跳过。看完仍原位朝下，不向其他人公开位置或牌值。                                                                                     |
| 卡比兽 | 换入后可交换本人两个不同牌位，也可放弃。明暗随牌移动，可包含刚换入的卡比兽。                                                                                                     |

### 超梦：精神侦察

先私看同一对手两个不同位置，再选择其中一张作梦幻式交换，或放弃交换。确认交换后必须将取得的牌换入本人场地，不能返回重新选私看目标。未发动时按普通 8 分牌处理。

私看只让操作者知道内容；公开交换不额外揭示未选中的暗牌。已合法知道的信息允许记忆。

### 阿尔宙斯：返璞归真

换入后可将全桌场地全部盖回，包括阿尔宙斯自身；随后为每人从其九格中均匀随机翻明一格。**牌与位置不变，不洗牌、不重发；牌库、弃牌、研究和胜局全部保留。** 已知牌的信息也不会被抹除。

每小局全桌最多发动一次，换走、弃掉或再取得都不能恢复这一次数。下一小局才恢复。恢复对局不会重新抽取已经确定的翻牌结果。

### 甲贺忍蛙：影分身

选择任意一名玩家的两个不同位置，将两张牌盖回，或盖回并公开交换位置。目标不限原先明暗，但发动者不会因此获得私看权。已知信息允许保留，公开移位后记忆跟随牌的位置更新。

“小智忍蛙”只用于演出形态，不增加能力、属性或次数。

### 路卡利欧：波导连击

换入后可再从牌库摸一张，也可放弃；允许正常回洗，没有牌可摸时不能发动。额外牌可换入或弃掉，不能从弃牌或缓冲取牌，也不能改为普通调位。额外特殊牌不发动主动能力，复制仍有效。完整连击结束后才检查全明收局。

### 陆海空三神：行交换

| 角色   | 与指定对手交换的行 |
| ------ | ------------------ |
| 固拉多 | 第三行（底行）     |
| 盖欧卡 | 第二行（中行）     |
| 烈空坐 | 第一行（顶行）     |

对应列的三对牌直接互换，行内顺序和明暗随牌保留，可以包含刚换入的神兽。移入牌不发动能力，也不附带私看。双方都按各自场地的行号执行。

### 主动能力使用状态（2026-10-07项目约定）

每张实体牌的主动能力在成功执行第一个实际效果后消耗，本小局再次取得时作为普通数值牌处理。未执行就放弃不消耗；超梦已私看后再放弃交换，仍算使用。已经开始的多步能力要继续完成。

消耗状态随牌移动、盖回、转交、弃掉或存入缓冲保留。只有实际洗回牌库的牌恢复能力；保留在弃牌顶、场地、暂持或缓冲中的牌不恢复。下一小局全部恢复。阿尔宙斯还须遵守全桌每小局一次的额外限制。

公开牌和依法私看的牌可以显示是否已使用，未知暗牌不能借标记泄露信息。百变怪、索罗亚的复制能力不消耗。

## 特殊研究任务

研究给全桌一个共同的可选目标。玩家可以主动追求奖励，也可以专心降低基础分；未达成没有罚分。

### 三类机制的分工

| 机制         | 产生方式         | 作用                         |
| ------------ | ---------------- | ---------------------------- |

### 奖励尺度

固定减分奖励分为 **3、5、8 分**。简单布阵或本来就有低分、归零收益的目标通常减 3 分；需要收集或重排的目标减 5 分；需要精确阵形或保留高分角色的目标减 8 分。按2026-10-12手写修订，R23 改为总分折半，R24 改为符合条件的整行逐牌折半并向下取整，覆盖此前“不使用折半”的限制。所有效果只应用一次，不增加额外胜局；具体计算见[研究调整与胜局](#研究调整与胜局)。

任务名取自宝可梦冒险、角色习性和熟悉的梗，再写成与条件有关的原创事件。真新镇、大木博士、小刚与小霞等情境参考[官方中文游戏介绍](https://tw.portal-pokemon.com/special/pika_vee/sc/20180712/)。后续手写任务可以在这套简洁条件与奖励尺度上调整。

### 开局投票与任务池

开局池共 17 项。2026-10-12按用户手写要求删除 R04、R07、R09、R10、R12、R20、R21；其余保留原编号，不重新连续编号。发牌前等概率抽出三个不同任务，每名玩家一票，提交后锁定；管理员和公共屏不投票。投票期间只公开谁已完成，本人只知道自己的选择。全员完成后公开票数，最高票任务当选；最高票并列时只在这些任务中等概率抽选。

掉线真人等待，不代投，倒计时也不自动选择。重连不会重新抽候选或裁决。已当选的任务在同一大局暂时排除，未当选候选回池；可选任务不足三项时重置开局池。不按任务类型轮换。

### 判定约定

- 全部任务只检查本人九格，缓冲与暂持牌不算；在结算时判定，不记录曾经达成。除暗牌条件外，检查揭牌后的完整场地；角色组合研究与局中明置触发的羁绊分别判定。
- 数字条件看 Mega、天气与复制处理后的最终有效值，归零前判定；归零不把有效值改为 0。
- 角色条件看原角色身份，Mega 形态仍算同一种角色，复制牌不变成来源角色。
- 普通牌、主动能力牌按牌表分类，能力已用过也不改变类别。属性条件沿用天气的角色归属，Mega 的形态属性在名单确定后统一。
- 暗牌条件使用强制揭牌前的明暗状态，之后揭牌仍能判定达成。
- 任务名中的角色只提供主题；只有条件明确要求角色时才必须持有。局中不显示会透露暗牌的任务进度。

## 局内特殊事件

### 随机触发思路

触发条件倾向于随机。建议在牌堆中随机选取 **X 张现有卡牌**，在牌上加一个特殊事件记号，X 默认值为 **1**。带记号的牌被抽出后，立即触发特殊事件。记号附着在卡牌上，这个思路不要求另加事件牌数量。

**特殊事件标记牌不会出现在前两轮全桌轮转中，即每位玩家各完成两次正常回合之前。** 能力中的额外摸牌、补牌和子步骤不另计回合，保护期也覆盖这些取牌流程。通过动态控制未公开牌库实现这一保护期，而非先抽出标记牌再延迟事件；不能因路卡利欧额外摸牌、火箭队补牌等能力取牌而提前抽出标记牌。

建议的控堆方式是：保护期内将标记牌暂时排除在可抽范围外，正常随机抽取其余牌；保护期结束后，将尚未抽出的标记牌随机混入剩余牌库，不保证紧接着触发。只调整未公开牌库，保留卡牌总数和实例，不改动已经公开的牌或已确定的抽牌结果。具体控堆算法留待实施。

标记在发牌前还是发牌后设置、哪些取牌流程算“抽出”、弃牌再取与回洗是否重复触发、事件种类如何选择，以及与卡牌能力的执行先后，均留待后续设计。各事件的持续与叠加规则按下文已确定部分执行，其余边界仍待补充。

### Mega 事件效果

事件触发时，只影响**当时全桌玩家场地中明置、且能够 Mega 进化的牌**。这些牌的贴图全部换成对应的 Mega 版贴图；场地暗牌、牌库、缓冲区、弃牌堆、暂持牌等均不受影响。

同一宝可梦有多个 Mega 形态时，对每张受影响牌随机选取一个形态，例如喷火龙、超梦、路卡利欧、烈咬陆鲨等。最终可选形态名单在实施前逐项核对，不将普通进化或其他特殊形态自动算作 Mega。

每张受影响牌的数值随机变为 **−5 至 12（含两端）的一个整数**，共 18 个可能值。数值分配以均匀概率为目标，每个值的理论概率为 **1／18**，长期统计概率应尽量相同，不偏向某些数值。小样本不要求各值出现次数完全一致；具体随机分配方法留待实施时确定。

待补充：持续时间，移位、盖回、离场后的效果保留，以及重复触发与能力叠加。

### 四种天气效果

天气采用可预期的数值调整，改变留牌、换牌与归零选择，不修改特殊能力本身。以下是本项目采用的桌游效果，不直接套用电子游戏的伤害或属性倍率。

| 天气 | 数值效果                                         | 当前牌组中的主要受益角色                         |
| ---- | ------------------------------------------------ | ------------------------------------------------ |
| 雨天 | 水系牌 −2；火系牌 ＋2                            | 杰尼龟、鲤鱼王、波加曼、可达鸭、甲贺忍蛙、盖欧卡 |
| 晴天 | 火系或草系牌 −2；水系牌 ＋2                      | 喷火龙、六尾、妙蛙种子、木木枭                   |
| 沙暴 | 岩石、地面或钢系牌 −2；其余有固定数值的牌 ＋1    | 大岩蛇、烈咬陆鲨、固拉多、巨金怪、路卡利欧       |
| 雪天 | 天气调整前数值 ≥8 的牌 −2；≤3 的牌 ＋1；4–7 不变 | 依据数值判定，不限定角色                         |

同一张双属性牌在一种天气下只调整一次，不因同时属于两个受益属性而重复减分。雪天按原始或 Mega 后、尚未加入天气调整的数值判断档位；调整后不再次判断档位，避免循环加减。

全桌同时只有一种天气，持续到下一次天气事件或小局结束，新天气替换旧天气。天气仅对场地中当前明置的牌持续生效：之后翻明或换入的牌也受到影响，盖回或离开场地后停止受到天气调整；牌库、弃牌、缓冲与暂持牌不受影响。

每次以原始数值或已经确定的 Mega 数值为基础，应用当前天气，不累计之前天气的加减。例如水系牌的 Mega 数值为 5，雨天后为 3；切换晴天后为 7，而不是在 3 上再加 2。

百变怪、索罗亚复制邻牌经过天气调整后的数值，自身不再额外接受天气加减。调整后的有效值用于归零与研究判定：天气可以拆散原有归零线，也可以形成新线。

雨晴形成相反的角色价值，沙暴使耐沙角色更值得保留，雪天压低高分牌并削弱低分及负分牌优势。天气与 Mega 联动所需的角色、形态属性对应关系在实施前逐项核对；不因天气而自动重新随机 Mega 数值。

| 研究难度与回报 | 候选选择、任务达成率、奖励改写赢家的频率                             |
| 干扰能力       | 三神追加频率、行交换的针对性、盖牌循环；阿尔宙斯发动与未发动分别观察 |
| 理解成本       | 玩家能否分清有效值与计分贡献、复制与角色、全明与完整能力结束         |

规则检查继续关注混合复制、研究奖励只领一次、投票平票、羁绊途中与末步触发、阿尔宙斯随机与次数、超梦放弃、能力消耗与回洗、缓冲牌守恒。技术检查与真人体验分别记录，具体场景见[专项验证](validation-scenarios.md#扩展版专项场景2026-10-05)。

新牌组、研究与事件的试玩重点是节奏、组合机会和收益平衡。

## 界面与声画表达

界面服务于当前决策：玩家应能看清牌源、暂持牌、目标、确认动作，以及当前研究的条件与奖励。手机围绕本人操作组织；主机和公共屏展示全桌。研究详情查看不提交投票，不公开他人的暗牌、私看内容或秘密选择。

规则说明以九宫格、八条线、横纵复制、能力分支和研究实例为重点；原版与扩展分别讲解。配图表达主题，位置、数字和箭头准确呈现，不读取实时秘密信息，不增加强制教程。

声画只表达已保存的公开结果。特殊能力可有全屏登场，交换、盖回与接力按实际步骤表现；阿尔宙斯不画洗牌或重发，忍蛙只盖回时不画交换。多步结果按能力、事件公布、结算的顺序表达，但动画不延迟规则推进。减少动态保留文字和静态强调，恢复不补播历史事件；手机保持静音。

布局、姿态、声音来源与制作参数分别见[交互规格](interaction.md#扩展版交互与演出规格2026-10-05)和[资源记录](assets.md#扩展版多姿态资源规格2026-10-05)。
