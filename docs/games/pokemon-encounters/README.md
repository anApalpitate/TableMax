## 对局内规则说明

用户 2026-10-05 要求参考另外两个游戏重做规则页，图片重新 imagegen。主机、公共屏和手机工具栏均有“规则”，以顶层图文卡片展示；八章分别讲目标开局、取牌换入、梦幻、火箭队、闪电鸟、交换私看、计分百变怪、结束三胜。按钮至少 44 px，正文 18 px、说明 16 px、标题至少 20 px。规则文字按本目录采用版本维护，不把未认证出版事实写成官方规则；关闭或 Escape 恢复到原入口，不暂停、替代或提交游戏动作。

内容与主题样式维护于 [规则界面](../../../games/pokemon-encounters/ui/RulesGuide.tsx)、[代码图解](../../../games/pokemon-encounters/ui/RuleDiagrams.tsx) 与同目录 `rules-guide.css`；平台只共用章节导航和文字排版。九张全新 imagegen 场景在 `rules/illustrations-v1/`，位置、箭头、分值和胜局由代码排版，百变怪图例与真实计分核验；不读取任何实时玩家牌面。旧三张界面截图及原 PNG 保留，退出当前资源导入。角色请求被工具拒绝后采用无角色主题场景，来源、提示词与原图见 [资源](assets.md)，实际三端与最终包见 [验收](../../reference/acceptance.md)。

扩展规则页独立说明九格八线、双可选弃牌、调位替代回合、完整能力与两项研究；30 项固定图示与正式判定验证，主题角色不额外增加条件。2026-10-06 深度 UI 已同步任务新名称、公开来源／暂持及各牌真实顺序的阶段表达，保留先能力的特殊分支；手机投票仍只显示名称／奖励／锁定，完整条件从公屏或规则查看。玩法细节统一见 [扩展设计](expansion-design.md#特殊研究任务)，新正式包适用技术验收已完成。
