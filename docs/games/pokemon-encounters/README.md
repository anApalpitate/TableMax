# 宝可梦奇遇：皮卡丘和朋友们

游戏标识 `pokemon-encounters`，采用规则版本 `tablemax-cn-s19-v1`，状态规格版本 1。当前简体中文、2–6 人、公共屏横屏、手机竖屏；六人是 2026-10-02 用户明确要求的项目扩展，非出版原文认证。名称使用用户确认的完整游戏名；实体版出版信息／印次／勘误未认证，不从普通 Paper Safari 或其他语言版本替换。

本目录维护当前采用规格与来源。正式模块已位于 [games/pokemon-encounters](../../../games/pokemon-encounters/index.ts)，实现 16 类／56 张、全部能力、独立计分与授权投影、三胜完整大局、三档本地人机和公共／本人 UI。当前 v1.0.0 保留原 1.6.0 的行动进度、待处理牌、能力声画与零分列见 [当前交互](interaction.md#160行动面板与声画反馈)，交付证据见 [本轮验收](../../reference/acceptance.md#160盒子对局体验与可靠性)。当前能力完整结算后检查结束，没有其他玩家最后回合。开发应固定本采用版本，不把未取得原文变成继续向用户提问的前提。
