# 宝可梦奇遇：皮卡丘和朋友们

游戏标识 `pokemon-encounters`，采用规则版本 `tablemax-cn-s19-v1`，状态规格版本 1。首版简体中文、2–5 人、公共屏横屏、手机竖屏。名称使用用户确认的完整游戏名；实体版出版信息／印次／勘误未认证，不从普通 Paper Safari 或其他语言版本替换。

本目录是第二阶段供第三至五阶段实现的**规格交付**，含用户认可的 16 类／56 张牌和明确项目方案；不是正式可注册游戏、规则引擎、SDK 或产品验收结果。当前能力完整结算后检查结束，没有其他玩家最后回合。开发应固定本采用版本，不把未取得原文变成继续向用户提问的前提。
