# 资源、卡牌映射与声音

当前素材方案供第五阶段制作／整合，正式资源必须本地打包。规则文字与数字由 HTML／可访问文本排版，与位图美术分离；卡面不能承载唯一规则数据。本目录 cards.json 每类别有 `assetId`，实例数量不是需要生成的图片数量。原图 S14 只作规则证据，不把其截图裁剪当已授权正式卡面。

已准备候选：[自然背景清单](../../../apps/web/src/prototype/assets/theme-preparation/manifest.json)；平台 16 个 WebP 的来源／尺寸／透明度在 [平台素材清单](../../../apps/web/src/prototype/assets/manifest.json)。均随原型本地引用，无 CDN。原始 imagegen PNG、S14 图片及检查留在 `artifacts/phase-02/`，忽略 Git 但文件树可见，不删除。新增位图委派 imagegen 子 agent，角色说明与制作记录按项目维护规则执行。

生产清单至少含 assetId、类别／规则对应、用途、数量、来源 URL／本地原件、取得日期、生成提示词／版本、宽高／alpha、压缩字节／哈希、状态及使用限制；不能含本局秘密实例到卡位映射。动态图所需卡面和卡背为独立元素，翻转边界不先加载未知类别图片；透明切图留安全裁切边，保持文字及数字对比度。

公共主机经用户手势激活后播放，允许静音，手机不发声；重连、回退、恢复或只打开帮助不重放历史音。播放失败只提示声音不可用，规则继续；新保存动作事件同 ID 最多一次，快速连续效果短音合并，避免多手机重复发声。提示音不表示保存成功，成功来源只有权威确认。

本阶段完成资源盘点与映射，不要求全部最终主题美术和录制音频。16 正式卡面、卡背／封面、币面、声音及自然背景压缩接入明确交给第五阶段；第六阶段检查离线包、本地加载、清晰度及实机声音。能力文字已可复查，不能把来源文字缺口藏到美术待办。
