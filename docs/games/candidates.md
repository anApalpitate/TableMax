# 桌游候选与接入评估

本页维护未接入游戏的候选池、来源、接入价值与成本估计，不代表开发排期。现代艺术、电力公司和拉密已接入，不再列为备选；当前规格从[游戏索引](README.md)进入。2026-10-10按用户要求明确排除三国杀，并补充经典小游戏评估。

## 人气证据与检索边界

既有候选来自2026-10-03中文网页调研；经典小游戏于2026-10-10补查发布方规则及数字平台资料。中文渠道活动、教学与数字版页面只作筛选线索，不构成国内人气排名，也不替代最终采用版本的完整规则核验。

## 评估依据

适配与难度为项目判断，综合手机操作、公共屏观察、自动结算收益、秘密信息、三档本地 bot 及保存／回退／恢复成本。平台目前最多六席，各游戏仍按采用版本限制人数；依赖自由讨论或主持裁量的作品须另定范围。

## 已移出与明确排除

## 经典小游戏：接入价值与相对成本

### 估算口径

以**宝可梦奇遇原版完整游戏模块的开发工作量＝100%**，比较在当前成熟平台上新增一个游戏的边际工作量，不含最初建设桌面外壳、联机、存档与通用框架，也不拿扩展版九宫格／研究重设计作为基准。基准范围包括原版完整规则、多步能力与秘密投影、默认／豆包／绝悟三档本地bot、手机／电脑玩家／主机公共展示、主题美术和声画、图文规则、回退／恢复及实际包验证，见[原版规则](pokemon-encounters/rules.md)与[游戏接入要求](../reference/game-development.md)。

下表为工程类比的**初步人力范围**，不是实测工时比例、包体积、运行性能或承诺工期。用相同交付质量估算；简单规则仍有模块接入、三端表现与恢复验证的固定成本。范围下沿假设单一规则版本、代码绘制主要卡牌／棋盘及适量声画，上沿覆盖规则例外、触控返修与三档策略调优。强AI竞赛水平、多套家规、联网匹配和排行榜均不在范围；不能把只做可点击原型的成本当完整交付成本。

**项目建议：**若新增一款亲友熟悉的多人小游戏，先考虑UNO；若希望四人随机竞速与家庭体验，再考虑飞行棋。若目标是最少投入扩充双人玩法，四子棋更合适；五子棋按实际兴趣决定，井字棋暂不占正式开发优先级。小游戏不必一次全部纳入，朋友实际愿意反复玩比候选数量更重要。

### 规则来源与待定范围

- [Mattel UNO W2085官方规则](https://service.mattel.com/instruction_sheets/W2085.pdf)：核对108牌、2–10人、功能牌、UNO宣告、+4挑战及多轮计分。此处选定的是估算参考版，不宣称所有UNO版次相同；挑战中查看手牌须依该版授权投影，不能全局公开或自动消除原玩法的挑战决策。数字宣告／响应边界在接入时单独设计。
- [游戏茶苑飞行棋规则](https://www.gametea.net/ask/201811/7782.html)：数字实现方的版本参考，**不是统一官方标准**。当前只估单一规则集，不把起飞点数、连续六点、叠子及飞跃细节拼成所谓通用官方规则；选定实体出版版本后按其原文核验，版本差异是当前估算不确定项。
- [Hasbro经典四子棋官方说明](https://www.hasbro.com/common/documents/dad2614d1c4311ddbd0b0800200c9a66/DE3C8F8050569047F5AA9FBB9F16909B.pdf)：双人交替从顶部落子，横／竖／斜四连获胜；不混入其他同品牌玩法。
- [BGA五子棋页面](https://en.boardgamearena.com/gamepanel?game=gomoku)：仅作15×15／自由规则数字版本参考；自由五子棋与连珠规则分别处理。井字棋按普通3×3范围估算，接入前仍须补齐明确规则及和局／起始约定。

以上来源支持玩法范围；**百分比和优先级均为本项目工程判断，来源没有给出开发成本**。正式选定后再按规则、三端UI、资源、bot、恢复／故障与同包验证拆分估算；同一平台连续开发可复用组件，但不能将各游戏成本直接相加后当作排期。

## 高评分重策的纳入边界

工业革命伯明翰、方舟动物园、沙丘帝国、重塑火星、幽港迷城保留为重策略／战役观察池（[中文资料库](https://www.zhuoyouku.com/boardgame)）；手机信息密度、卡池、战役状态与 bot 成本较高，待用户选定后深入。即时抢拍与手部技巧类暂不优先，触控／网络延迟及实体触感损失会影响体验。

## 接入前的平台工作与验证
