## P01：本项目适配与原文缺口

2026-10-09用户选择经典2–4人，完整数字实现不混入XP、六人版或其他新版百搭限制。平台倒计时只提醒：不采用S01第4页自动超时摸一张，也不把非法草稿提交等同官方未完成重组摸三张；草稿可撤销，服务器只接受合法整回合。

以下是明确项目裁定，不声称官方规则：先手最高数字同点的玩家重抽，百搭重抽（实现用只含数字牌的等价抽样）；默认一轮、局数等于人数；各局重新按准备步骤决定先手；堵局最低点数并列共同获胜，并等分赢家正额、不舍入；有限牌池摸牌按实际可用张数，牌池空不能虚构牌；计分同赢局数与累计分仍相同则共同赢大局。

S01未给无牌可出的数字证明算法。项目穷尽本人牌架＋公开桌面的合法完整组合及百搭释放路径；只有完成穷尽且无解才允许空池跳过。一圈全部为这种强制跳过才堵局，不把主动不出、计算超时或节点预算耗尽当作无解。算法最坏成本与实际测量分开，当前样本不能证明所有局面都有固定毫秒上限。

规划局部百搭证明缓存只复用完整成功或完整真实无解，不缓存取消或预算中断；它是性能实现选择，不属于S01规则，不改变服务端独立动作校验或空池真实合法性判定。边界与实际证据见[验证](validation-scenarios.md#规划证明缓存风险)。
