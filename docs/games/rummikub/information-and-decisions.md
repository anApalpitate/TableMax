# 拉密权限、决策与恢复

## 状态与投影

[权威状态](../../../games/rummikub/rules/state.ts)保存106牌的牌池／各牌架／完整桌面唯一物理分区、稳定座位顺序、先手、回合、首出、强制跳过、赢局数、计分和小局结果。不存在客户端草稿或身份凭证字段。规则随机使用平台可恢复随机源。

[公共投影](../../../games/rummikub/rules/project.ts)只含已保存桌面、各家牌架数量、首出状态、公开回合与计分、已结束小局结果及安全最新动作。本人投影额外含本人完整牌架；公共、管理员和其他玩家不能取得牌池次序、对手牌面或未提交重组。摸牌反馈不带摸到的实例ID，最新出牌只引用公开桌面牌。

GameHost负责凭证、同步、信封和授权；电脑浏览器玩家、真人房主和bot都沿用本人投影。玩家UI与bot只引用公开目录、[类型](../../../games/rummikub/types.ts)及共享纯组合函数，不能导入权威状态访问对手秘密。

## 决策

| ID／动作                                       | 合法身份与边界                                             |
| ---------------------------------------------- | ---------------------------------------------------------- |
| `rummikub:<小局>:<回合>:<seat>`／`submit-turn` | 唯一行动座位；首出或任意合法整桌重组，一笔保存全部变化     |
| 同ID／`draw`                                   | 唯一行动座位；池有牌时可主动摸牌，保存后立刻换人           |
| 同ID／`pass`                                   | 池空、真实穷尽无合法出牌的唯一座位；无自愿跳过             |
| `next-game`生命周期                            | 小局结果阶段的管理员或已授权真人房主；新局重新抽先手及发牌 |
| 原班再玩                                       | 终局采用平台`replay`，新实例沿用当前身份与座位             |

不声明并发组；全桌重组彼此冲突。`legalActions`给有界建议，声明的`isLegalAction`验证参数化完整动作，不靠穷举全部意图或匹配建议列表授予权限。空池建议须完整证明；预算用完只标不完整，不能据此允许pass。

## before checkpoint与恢复

每次摸牌、整回合或无牌跳过都返回before标签；摸牌／出牌提示有信息揭示。确定性计分、终局、顺序变化全部在同一次apply内完成，动画不驱动规则。生命周期同样有before边界。

保存失败不会部分移动牌。丢确认重发原信封，旧实例／分支／回合拒绝，回退与重启由平台恢复状态／随机／bot记忆并先暂停。草稿与完整同步后的桌面核对；失效分支不得重发旧草稿。身份、房主管理授权及换机授权由平台单独管理，不随checkpoint倒退。

validateState核对稳定座位、规则／状态版本、106实例唯一分区、完整组合、阶段与行动者、小局编号／结果、累计分和赢局数；已保存forced-pass声明另做真实合法性复核，不接受伪造堵局。
