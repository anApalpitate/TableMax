# 拉密：经典数字采用规则

采用[来源S01](sources.md)经典2–4人版；牌目录为[106个唯一实例](../../../games/rummikub/data/catalog.ts)，四色1–13各两份及两张百搭。项目适配P01与原文区分记录，不采用同PDF的XP段落。

## 准备与完整大局

每局随机抽数字比最高值定先手；最高同点者重新抽，百搭重新抽，随后归还并重洗全部牌。每人十四张秘密牌，剩余为秘密牌池，顺时针行动。每局重新准备，不按席位轮换先手。

当前默认一轮，一轮的小局数等于人数。每小局结束后由管理员或已授权真人房主推进`next-game`，重发十四张并保留赢局数和累计分；大局结束后沿用平台原班再玩。存档预留1–10轮的数据校验与初始化参数，当前产品入口没有轮数配置，不称已支持玩家选择多轮。

## 两类组合与首出

同数组必须三或四张同数字、不同色；顺子至少三张同色连续数字，1只能最低，13不能接1。同一物理牌不能在两个位置出现；两份同色同数字是不同实例，不能放在同一组。

尚未首出的玩家只能打出本人牌组成的一组或多组，代表数字相加至少30点，百搭按其代表数字计点。首出当回合保留全部原桌面组，不能借牌、加牌或拆组；从其后续回合才开放重组。

## 整回合与摸牌

已首出玩家可任意拆分／合并／重排公共牌组，并加入本人牌；回合结束至少打出本人一张，原桌面实例全部仍在桌面，全部最终牌组合法，无散牌。手机可保留临时散牌草稿；它不公开、不保存为权威桌面。最终一次`submit-turn`原子校验、计分、推进和保存，非法则保持原状态，可撤销后重选。

玩家不能出牌或主动不出时摸一张并结束；新摸牌必须等下回合使用。牌池空时只允许真实无合法出牌的玩家跳过。每次这种跳过核验完整重组搜索；同一桌面连续全员强制跳过则堵局。预算中断、离线或自主放弃不构成堵局。

## 百搭

百搭在每个牌组中明确绑定代表色／数字；同数组缺色有多个可能时任选满足合法性的一色。可用本人或桌面牌替代，也可通过合法拆组释放，不锁定含百搭的组。释放后的百搭须在当回合合法新组中重用，不能收回牌架；当回合至少打出本人一张，不额外要求两张本人牌或要求该牌与百搭同组。

整回合可携带最多两份释放证明：合法替代牌组覆盖该百搭原组其余全部实例，只用旧桌面和本回合实际打出的本人牌，不含被释放的百搭。最终完整桌面另行核验。原组保留自然牌锚点、组型及代表数字（顺子同时保留颜色）时视为在原组合上继续重组；同数组三张中百搭缺色的展示变化不算回收。原文的四种释放说明由风险场景覆盖；完整公开桌面组的排列顺序不影响规则。

按2026-10-09用户要求，以S01明文自主处理版本解释：整回合可以同时重组两枚百搭，不额外要求可执行的先后释放顺序。每枚仍须有合法替代、在本回合新组重用并满足全部桌面与本人出牌条件，两份合法替代组合互相使用另一枚百搭不单独导致拒绝。这是依据该版回合末合法与任意替代条文的数字实施解释，官方未专门举出循环互换，见[来源与解释边界](sources.md#p01本项目适配与原文缺口)。

## 计分与胜负

清空牌架立即赢小局。其余玩家牌架数字之和记负，百搭每张30；赢家记全部负额的相反和。牌池空且无人可出时，牌架点数最低者赢；非赢家记`最低值－本人值`，赢家记相反总和。最低值并列的项目裁定为共同赢小局，并平分正額，保留分数值、不取整，以保持总分守恒。

每局赢者增加一胜。完整大局先比赢局数，再比累计分，仍相同共同获胜。规则与计分由[纯函数](../../../games/rummikub/rules/scoring.ts)实现；计时、身份和管理员授权不是规则状态。

计时只提醒，明确覆盖官方一分钟自动处罚的数字适配见[来源P01](sources.md#p01本项目适配与原文缺口)。
