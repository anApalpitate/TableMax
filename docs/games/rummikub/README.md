# 拉密

采用经典版 **2–4人／106张牌**，依据官方2025经典规则；XP／六人版未纳入。牌架整理、整回合提交与短屏操作查[交互](interaction.md)，原构建和历史测量由验证正文保留。

2026-10-29源码采用共享净区测量，场景根始终铺满，内容上限H1920×1080、P宽430、电脑L1440×900；P／L保留现有960px构图分支。管理桌面按牌组真实宽度紧凑换行，保留组界、数字、颜色辅助形状和百搭绑定；收紧座位卡边距并移除管理摘要里的装饰头像，为60牌／15组留出首屏空间。玩家的牌架、暂持、撤销、百搭编辑和草稿scope仍在本游戏维护，工作区切换不复制组件。具体实测与限制见[本轮源码验证](validation-scenarios.md#2026-10-29密集桌面与净区源码验证)，参数不推广为全平台最低尺寸。
