## KN25 规则基准

TE-R1 以 [Fantasy Flight Games 公布的 PDF](https://images-cdn.fantasyflightgames.com/filer_public/bf/e1/bfe1ae7d-d41c-44d4-910b-86cd59324b38/kn25_rulebook_web.pdf) 和 [Z-Man 托管的 PDF](https://images.zmangames.com/filer_public/92/3f/923f8aba-72f1-4aa5-9622-d648ad1a9aa7/kn25_rulebook_web.pdf) 为出版证据。Z-Man 文件已下载并以两次独立取样的 SHA 复核。其主机证书名称不匹配，下载时只对这份公开原件使用兼容读取。FFG 主机在本机返回 503，使用[本地可取得的出版 PDF 镜像](https://cdn.1j1ju.com/medias/04/4a/fe-tigris-euphrates-rulebook.pdf)作视觉与文字交叉核对。二者文件封装不同，分别留存 SHA。[外部资源清单](../../../../TMP/TableMaxMaterial/originals/tigris-euphrates/README.md)

TE-R2 [Chris Lawson 早期 FAQ 转载](https://www.scribd.com/document/873938693/Tigris-Euphrates-Faq-by-Chris-Lawson) 自称经设计师核对，适用 Hans im Glück／早期 Mayfair 语境。它提到右中部细支流格属于陆地、灾难可下在河格、抽取不足仍完成当前回合，以及补手从当前席顺时针。新版坐标与数字收尾仍须绑定 KN25 棋盘和原文，逐项区分旧版澄清与项目解释。尚未发现单独的 KN25 官方勘误。棋盘的 16×11 尺寸也见 [BGG 早期实体配件档](https://boardgamegeek.com/boardgame/42/tigris-and-euphrates)，该档所述早期版细节只作交叉检查。

## 历史与美术资料

- TE-H1 [设计者访谈](https://talkingshelfspace.com/origin-story-tigris-euphrates-an-interview-with-designer-reiner-knizia/) 记录 Knizia 对题材先行、王国共治、争夺与分裂以及宝藏的设计回忆。它是经编辑的访谈，不作为规则勘误使用。
- TE-H2 [The Met 早期城市展览](https://www.metmuseum.org/exhibitions/listings/2003/art-of-the-first-cities) · [Uruk 专文](https://www.metmuseum.org/es/essays/uruk-the-first-city) 支持灌溉、城市形成、贸易、泥砖及彩色陶锥的题材参考。[NYU ISAW 棋盘地理研究](https://isaw.nyu.edu/library/blog/gameboards-and-maps) 的历史地理叠图是已保存的二手棋盘观察，可用于确认游戏地图包含抽象，不能用来单独定案河格和翼兽坐标。
- TE-A1 [The Met 开放政策](https://www.metmuseum.org/policies/image-resources) 适用于公开领域的馆藏照片。已逐项按 API 的 `isPublicDomain` 与图片地址核验并保存文件。[神庙立面滚印 326721](https://www.metmuseum.org/art/collection/search/326721) · [大麦分配泥板 329081](https://www.metmuseum.org/art/collection/search/329081) · [牛人、英雄与狮子滚印 324421](https://www.metmuseum.org/art/collection/search/324421) · [动物与宴饮滚印 327598](https://www.metmuseum.org/art/collection/search/327598) · [吹笛女子镶嵌 325451](https://www.metmuseum.org/art/collection/search/325451)
- TE-A2 [BGG 出版方产品图](https://boardgamegeek.com/image/2338267/tigris-and-euphrates) · [实物配件照](https://boardgamegeek.com/image/2367668/tigris-and-euphrates) · [Wikimedia 2008 实物照](https://commons.wikimedia.org/wiki/File:Deskohran%C3%AD_2008_0109.jpg) 提供实物版次和组件检索入口。照片许可仅涵盖相应照片的授权范围，版图与棋件原画的使用要单独判断。
- TE-A3 [Asmodee North America 社区 IP 指南](https://images-cdn.fantasyflightgames.com/filer_public/51/c8/51c8035b-240e-4a12-8ab6-a7b34b97c819/ip_policy_2024_aug20.pdf) 的第 5–6 节不提供 FFG／Z-Man IP 在软件应用中使用的许可。本轮出版图只存作调查原件。后续若需出版方规则文字、图形、商标或数字授权，可查 [Knizia 出版联系页](https://www.knizia.de/publisher-info/)。原始文物图和最终原创 UI 的来源各自保留。

## 本地原件与导入状态

[外部原件目录](../../../../TMP/TableMaxMaterial/originals/tigris-euphrates/)含两份 KN25 英文规则、作者目录、BGA 目录封面、NYU 地理叠图、五份开放图片和配套元数据。规则关键页渲染与文字抽取在[外部核对目录](../../../../TMP/TableMaxMaterial/work/tigris-euphrates/kn25-2015-rulebook-reference/)，其中两路 p9 可直接交叉查阅。物料路径、来源、大小、SHA-256、图片尺寸与资料用途见[逐文件清单](../../../../TMP/TableMaxMaterial/originals/tigris-euphrates/manifest.json)。

还需核对同版高分辨率标准盘全图或实体、战棋会官方中文规则原件及 25th Century 新版正式型录。首版玩法不依赖生成图像。背景纹理与场景可从已取得的开放图像开始，棋盘的河陆判定、宝藏位置和规则图上的行动必须来自可核对的数据。当前无素材进入运行资产，图片和 PDF 都留在外部素材工作区。
