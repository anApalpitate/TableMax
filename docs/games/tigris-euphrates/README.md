# 两河流域｜背景与接入调查

2026-11-16 用户选定《两河流域》为下一款制作游戏。本轮完成背景、候选规则基准、数字化风险和素材搜集。游戏尚未进入可玩目录。规则定位、版本差异和原件查[来源与核对表](sources.md)。

## 题材与设计脉络

《两河流域》（Tigris & Euphrates，德文 Euphrat & Tigris）由 Reiner Knizia 设计，1997 年由 Hans im Glück 首发。1998 年获 Deutscher Spiele Preis，并进入 Spiel des Jahres 推荐名录。版本经历 Pegasus 2007 年修订、香港战棋会 2009 年简繁中文版、FFG 2015 年版与作者目录所列的 Z-Man 2019 年版。2026 年 25th Century Games 为 Ian O’Toole 重绘版发起众筹。Codito 2011 年 iOS 版、2013 年 Android 版与 2022 年上线的 BGA 版可作为数字化脉络中的独立节点。[出版与数字版证据](sources.md#出版版本与数字版)

底格里斯河与幼发拉底河之间的南部冲积平原为灌溉农业、聚落和城市发展提供了条件。乌鲁克神庙立面的泥砖和彩色陶锥、用于封缄和记账的滚印、记录大麦分配的原始楔形文字泥板，都可以转成易识别的界面图形。地图上的翼兽标记是开局位置的游戏符号。参考现实河谷与考古遗址时，格位、河格和宝藏起点仍以同版游戏棋盘为准。[历史与美术资料](sources.md#历史与美术资料)

Knizia 在访谈中回忆，设计先从美索不达米亚各王国的兴衰出发，再形成棋盘规则。同一王国可以容纳不同王朝的领袖，今天共享得分的玩家可能在下一次并国时交战。战争拆板会重新打开空间，宝藏引导王国向外围扩张，终局比较最弱领域促使玩家维持四类得分的平衡。这三点比按玩家着色的领土占领更能解释本作的体验。[设计者访谈与棋盘研究](sources.md#历史与美术资料)

## 首版研究基准

建议以 **FFG 2015／Z-Man 托管 KN25 规则的金边标准盘、2–4 人基础规则**开展规则规格。该口径有完整规则书、配件清单、双面辨识图和贯穿实例，适合先把多段冲突和秘密验证清楚。蓝边进阶盘、文明建筑、奇观、English Variant 与新版独立规则留待分别核验。香港战棋会实体版可校订中文术语，完整同版简繁规则原件尚待取得。牌件主轴是板块、领袖和纪念碑，资源清单不设玩法卡牌套件。[标准盘规则与变体定位](sources.md#kn25-规则基准)

## 核心规则与实现难点

- **连通和行动。** 板块与领袖的公共连通决定地区和王国，地区有领袖后才叫王国。每回合至多两次行动，可重复，行动为放置／移动／撤回领袖、放文明板块、放灾难板块、换手中板块。领袖只能处于邻接正面神庙的空陆格，不能通过放领袖合并王国。蓝农田限河格，其余文明板块限陆格。灾难是永久断点，拆掉最后一座相邻神庙会撤回领袖。普通文明落板优先给王国内匹配领袖计分，缺同色领袖时由国王代领。连接两个王国的板块本身不给分，单次落板不能合并三个或以上王国。
- **叛乱与战争。** 同王国加入同色领袖引发叛乱，以双方领袖相邻正面神庙作基础兵力。并国产生同色领袖时引发战争，以桥两侧仍各自连通的同色支持板为基础兵力。两者都先攻后守、各提交一次，守方平手胜。叛乱只撤败方领袖且赢家得 1 红分。战争需拆败方领袖与其支持板，祭司战保护带宝藏或邻接其他色领袖的神庙，赢家按实际拆除的支持板加领袖计对应分。手中增援打出后移除，数量不计入战争奖励。
- **多场战争。** 当前回合席决定先处理哪一种颜色，可能由第三方触发双方增援。每场战争后按新棋盘重新计算下一场是否还成立，也重算兵力。两名领袖失去连通可取消余战。临时合并标记、底下的真实文明板块及它两侧的连通需要分开表达。增援少于取胜所需仍可能是主动换掉手牌，不能用界面规则排除。
- **纪念碑与宝藏。** 同色 2×2 由本次落板形成且在战争后仍存在时，当前席可翻置并建兼容的可用双色纪念碑，或跳过。翻面的底座参与连通，但失去原文明支持。每回合末仅当前席得本方匹配领袖连接的每座纪念碑相应分，国王不代领别色。落板／领袖动作后的王国有商人且有多枚宝藏时，该商人必须拿到只剩一枚，先拿有特殊边框的格子，再处理同档次的选择。取宝席可能与当前回合席不同。
- **结束与结算。** 区分回合结束时公共板上只余 1–2 枚宝藏，以及某个实际抽牌请求因袋空无法完成。牌袋为零本身不可触发终局。基础版宝藏以单枚任意分到四个颜色，分配后把各色累计分升序排列，逐项比较，四项相同共享胜利。补牌耗尽、后续玩家补牌次序和终局分配的揭示顺序进入专项验收。

## 数字化适配与验证建议

**公开端。** 管理兼展示以公共棋盘为主，显示河陆、王朝徽记、领域色和形状、当前桥点与已提交的公开冲突信息。同域领袖用颜色与图标识别，王朝用不同轮廓／徽记识别。一个连通王国不着成某一玩家的颜色。显示已存盘的落板、得分事件及撤离变化，累计四域分、已获得宝藏、手牌、牌袋精确数量与弃置详情遵守屏风信息边界。不要用累计事件明细重建本应隐藏的分数。

**玩家端。** 390 CSS px 的屏幕即使全宽铺设 16 列，每格也只有约 24 px。手机竖屏可保留一眼定位的棋盘总览，实际选格在放大的局部棋盘或候选格列表达到 44 CSS px 热区。移动、灾难、桥接与建碑先选具体位置再确认，公共预览只依公开盘面与本人可知信息。手牌和四域分归本人。冲突用独立的先攻／后守操作，并明确当前轮到谁。颜色、符号和文字都须能区分，布局沿用[通用视觉规格](../../reference/visual-design.md)。

**保存与权限。** 将普通行动、战争颜色选择、攻方／守方提交、建碑或跳过、跨席取宝和终局宝藏分配列为待建的决策点。服务端记录当前席与待行动席、回合剩余动作、桥点及被覆盖板块、已提交增援、后续待解事项、手牌分数与牌袋顺序。服务器一次持久化动作及确定的连锁后果，再发授权投影。回退要恢复牌袋状态和冲突阶段，同时保留平台的身份撤销规则。检查双提交、非当前响应席、断线重连、暂停与回退时的秘密泄露。[平台规格](../../reference/phase-02-platform-spec.md)

**三档人机。** 默认档用公开连通和己方手牌的合法启发式补最低领域并覆盖全部响应。豆包档有限枚举第二次行动、建碑收入与切断桥点的效果。绝悟档在同一授权投影上做有界搜索，未知手牌可作独立假设，策略不读取真实对手手牌、袋序或隐藏分数。建议先用固定局面证明三档可区分，混合人机测试覆盖玩家 C 并国触发 A／B 战争、跨席取宝和二次冲突消失。[人机规格](../../reference/bot-players.md)

## 素材搜集与下一步

- **参考原件。** 正式规则书、关键页渲染和 BGA 封面已本地保存。规则书包含两面版图缩图、四色板块／领袖及六种纪念碑配对。已记录更清晰的实体照和中文实物照定位。出版画稿作为核对参考，等实际使用范围明确后才决定能否进入安装器。
- **原创美术素材。** 已取得五份 The Met 开放图片及藏品元数据，分别覆盖神庙仪式、动物与英雄滚印、宴饮、镶嵌人像和大麦账目泥板。可用泥砖浅色和明亮河水建立基调，王朝图案与四色功能图标独立绘制。规则箭头、数值和坐标应由程序绘制。若制作阶段仍缺独立封面场景或纹理，可按这些文物资料生成原创图像。
- **接续顺序。** 先拿到可复核的标准盘全图，逐格交叉确认陆／河、10 个翼兽起点和特殊边框，再冻结地图数据与分歧处的规则口径。随后编写冲突顺序、合法性、秘密和终局分配的可执行用例，最后接入界面与三档人机。把原图、规则书和研究页渲染留在外部素材工作区，可用运行图另行制作并核量。[来源与本地原件](sources.md#本地原件与导入状态)
