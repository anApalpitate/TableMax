# 德国小强

经典基础版 Cockroach Poker / Kakerlakenpoker，Schmidt Spiele 货号40829；2–6人。规则标识 `classic-40829-1`，游戏／策略版本1.0.0，状态版本1。实现入口见[模块清单](../../../games/cockroach-poker/game-module.json)。不混用 Royal。

## 规则与来源

2026-10-21采用经典40829规则。原文定位、原件SHA、核验范围及解释边界统一见[CP-S1来源](sources.md)，下表维护实际采用行为。

| 场景      | 采用规则与位置                                                                           |
| --------- | ---------------------------------------------------------------------------------------- |
| 组件      | 英文页9：64张、8种动物；每种8张。蟑螂、椿象、蝙蝠、蜘蛛、苍蝇、蟾蜍、老鼠、蝎子。        |
| 3–6人准备 | 页10：全部洗混发出。德文页4及法文页16明确允许不平均，轮流发牌保证差不超过1张。           |
| 出牌      | 页11：选任意手牌、任意其他玩家与一种动物声明，声明可以真假。                             |
| 判断      | 页11：接收者相信或质疑；判断正确则最近传牌者收牌，否则判断者收牌。                       |
| 查看转传  | 页12：选择转传后才秘密查看，必须交给尚未看过者，声明可保持或改变。无人可转传时必须判断。 |
| 下一轮    | 页12：收牌者将牌公开放在自己面前，并开始下一轮。                                         |
| 3–6人结束 | 页13：收下第4张同类；或轮到开始新轮却已无手牌。其他人共同获胜。                          |
| 双人      | 页14：洗混后秘密移除10张，各发27张，不可转传；第5张同类或轮到出牌无手牌失败。            |

英文目标概述“run out of cards”比结束章节简写，采用页13明确的“必须开始新轮却无手牌”，不是打出最后一张立即失败。法文有最年轻玩家起手，英文及德文没有可用于平台席位的年龄输入；平台固定第一席起手，属于项目确定性裁定。轮流发牌、不可查看已移除牌、两步承诺转传、同类无分数共同胜利均与原规则一致。

## 状态、动作与秘密

- `rules/state.ts`：64个唯一牌ID分布于各手牌、公开收牌、双人秘密移除及唯一在途牌，严格守恒；校验稳定座位、合法牌、路线无重复、见过者顺序、转传承诺、最近判断与收牌者、共同赢家。
- `offer`：本人从手牌选牌、自由目标与声明。只将公开声明写入反馈；牌ID和真实牌面不进入公开记录。
- `peek`：接收者且存在其他未见者才合法；保存后给予本人牌面，同时进入只能转传的状态，不能撤回改判断。
- `pass`：仅已承诺者可用，目标必须没看过；可改变或沿用声明。
- `judge`：未查看的接收者判断；一次原子保存完成揭晓、收牌、下一轮及终局，不等动效。
- 决策ID `cockroach-<serial>` 每次动作改变；同一决策只有一个行动者，不声明并发。暂停、身份授权、重复／旧动作、保存事务及checkpoint均使用平台既有契约。
- public及管理员只见手牌张数、公开收牌、当前声明／路线、最近已揭晓和结果；player额外见自己手牌，以及当前牌在本人已见列表时的牌面。双人移除牌永不投影。不同身份不从动作列表、日志或反馈取得其他手牌。
- `next-round`仅终局提供，重新洗发；重新开始由平台生命周期权限处理。

## 人机

三档均只接收本人授权投影及合法动作，记忆固定null。默认随机选择完整合法动作；豆包偏好查看与转传，并按公开同类压力选目标；绝悟更重视同类施压、对手手牌数量，以及本人手牌和公开收牌扣除后的剩余声明概率。概率不是对手真实策略模型，强度不作胜率保证。两档均保留随机性，规则随机与策略随机由平台独立维护。不读其他手牌、移除牌或未知在途牌。

## 界面、素材与声画

三端按平台role独立会话：host/public显示公开牌桌；player额外显示本人手牌和当前动作。管理、设置及图文规则由菜单浮窗按需展开，沿用平台管理权限与显示设置。选择牌、对手、声明后按钮明确写出目标与声明；相信／质疑为直接动作，查看按钮明示不可反悔。最后接收者和双人只显示判断按钮。

原创抽象八虫用不同形体、轮廓、颜色及文字共同区分：蟑螂椭圆甲壳、椿象盾形、蝙蝠翼、蜘蛛八足、苍蝇双翅、蟾蜍大眼、老鼠圆耳、蝎子卷尾。资源见[清单](../../../assets/games/cockroach-poker/manifest.json)。11张代码原生SVG（八虫、牌背、封面、流程图）不复制发行方美术；3个WAV是原创程序合成短音，不作实录声明。官方PDF仅保存研究原件，不推定可再分发，也不进入运行资源。

视觉以G01/G02/G04/G05/G07/G08/G17为依据：明亮浅黄与薄荷底、紫色行动边框，牌面和声明为主体，字体信息16px、主要动作18px、电脑标题24px；窄手机横向手牌、短屏重排、4K增大主体，减少动态禁用演出。只有保存成功的新feedback触发450ms动作／揭晓／共同胜利演出及对应声音；初始同步不播放，实例/分支/修订去重，静音、隐藏、暂停、测试模式及卸载停播，音频输出复用平台偏好与声源归属。声画不含未知牌型，声音未作真人试听认可。
