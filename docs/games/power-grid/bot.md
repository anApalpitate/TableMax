# 电力公司：三档电脑策略

独立策略入口为 `games/power-grid/bot/index.ts`，经共享 `BotStrategy` 接收本人安全投影和服务端合法动作。策略只看到本人现金、公开的电厂／仓储／城市／顺序／市场、本人可见建城费用与合法动作；对手现金、牌堆牌号、秘密移除牌号均不提供。记忆为 `null`，不调用其他游戏策略或网络服务。

## 已实现层级

| 决策 | 默认 | 豆包 | 绝悟 |
| --- | --- | --- | --- |
| 选区 | 在连通合法区域组中带种子随机 | 评估区域内低价连线密度 | 更重视网络可扩展度与连线费用 |
| 竞拍 | 简单产能收益，保留基本现金，少量带种子扰动 | 评估升级／替换、燃料成本、扩城预算 | 加入后期公开对手产能、终局紧迫度与升级效率 |
| 拆厂 | 按产能和燃料成本留下更有价值的厂 | 强化产能与经济效率 | 进一步计入旧厂剩余燃料价值 |
| 燃料 | 预备一次满额运行 | 一次运行，预留最便宜建城预算 | 前中期预备最多两次运行，混燃考虑公开对手燃料需求 |
| 建城 | 扩到名义产能，选择便宜起点与费用 | 扩到当前燃料实际可用产能，避开明显输掉的提前终局 | 起网评估后续六城连接，建城加入一步未来成本与拥挤位置，比较额外收入和连接费用 |
| 发电 | 合法最大供电计划 | 同左 | 同左；保留无需燃烧的资源，足够供电后明确结束 |

三档都遵守完整燃料输入、有限仓位、逐份采购、拆厂转存、混燃和终局燃料可用性。购厂报价保留资源／扩城预算；高档不凭空使用隐藏的对手现金，不读取底层状态。终局判断从公开的对手城市、电厂和储存燃料推算其当前可供电城市，而不是把名义总产能当作本轮可供电数。

## 生产计划与动作粒度

生产规划采用最多四座厂的有限资源动态规划：按总煤／油／垃圾／铀用量合并相同状态，保留最高产能，再选达到最大城市数的最少资源方案。混燃厂逐厂枚举合法配方，服务端合法动作仍只有“运行这一厂，用这个配方”，没有把整套电厂组合指数展开成网络动作。

运行前按目标配方逐份转存，双方混燃仓满时可原子交换煤油。运行过的厂不能再运行，后续计划扣除本轮已经生产的电力；环保厂足够供电时不再多烧有料厂。每次策略只返回一个已有合法动作，照常经过统一身份、决策、校验、保存、事件、回退和暂停流程。

## 验证与局限

规则场景测试覆盖第一轮强制购厂／重排、顺时针竞价与两种退出、未购厂清理、拆厂和燃料守恒、全部混燃配方、满仓交换、三个第三步触发与第二步交叉时序、最短路线经过满城、终局燃料证明和三级平局。三档策略还有“更高档保留两轮燃料”“改变所有对手现金仍不改变投影和决策”“免费环保发电后不多烧资源”的具体测试。

带种子的 15 场完整规则对局覆盖 2–6 人分别使用默认／豆包／绝悟，逐动作检验可恢复状态，定期 JSON 往返恢复，逐动作规范形式与平台契约一致，终局验有限资源守恒。电脑 Worker、SQLite 恢复和真人手机完整路径的验证另由平台集成／交付验收承担。

当前策略是三档本地启发式加有限生产规划，不宣称搜索最优或已有统计胜率优势；不读取真实玩家掉线状态代其行动，不以不合法动作试探秘密余额，不枚举未来隐藏牌堆。
