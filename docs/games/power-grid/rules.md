# 电力公司：经典德国地图规则

采用经典《Power Grid / Funkenschlag》基础电厂牌组和修正版德国地图，2–6 人。出版基线为 Rio Grande Games 经典 PDF 的 2009 年规则文本；本页记录服务端实际规则，出版来源、认证边界和项目解释见 [sources.md](sources.md)。实现集中在 `games/power-grid/`，不引用其他游戏的状态、规则、策略或界面。

德国地图有六个区域，每区七城；所选区域必须连成一片，所有玩家都能在所选区域行动。数字版由首位行动者一次选择整组相邻区域。每人起始 50 电币，随机决定第一轮玩家顺序；座位环确定固定的顺时针竞拍次序。

共有 42 张电厂牌：3–40、42、44、46、50，另有第三步牌。将 3–10 按序摆入市场，最小四张为当前市场、最大四张为未来市场；其余牌暂取出 13 和第三步牌，洗牌后按人数秘密移除相应数量，13 放牌堆最上、第三步牌放最下。所有购入电厂的补牌都立即抽出并重新排序。

资源是有限的实体数量：煤 24、油 24、垃圾 24、铀 12。初始市场分别为 24、18、6、2，余量分别为 0、6、18、10。煤、油、垃圾的价位 1–8 各容三份，铀的价位 1、2、3、4、5、6、7、8、10、12、14、16 各容一份；采购从最便宜的现有份额开始。

## 一轮的五阶段

1. **排序**：按已连接城市数从多到少排序；同城数按最大电厂编号从大到小。除第一轮竞拍结束的特殊重排外，同一轮内不因购厂、建城而重排。
2. **竞拍电厂**：按玩家顺序选择当前市场电厂，起价至少等于牌号；其他仍有购买资格的玩家按固定顺时针座位环加价或退出本次竞拍。报价必须有足够现金。退出本次竞拍后不能重新加入该场，但仍可参加之后的竞拍。发起者赢得电厂后轮到下一位有资格者；其他人赢得电厂时，发起者仍可再发起或跳过本轮。
3. **采购资源**：按玩家顺序的逆序，每位玩家完成全部采购后才轮到下一人。只可购买本人电厂能够储存的资源，采购一份即支付对应市价；某资源售罄后当轮不能继续购买。
4. **建设城市**：仍按玩家顺序的逆序，每人完成全部建设后才轮到下一人。逐城支付占位费用和最便宜完整连接路线费用。可选择不建城，包括第一轮不建立网络。
5. **行政结算**：按正序逐人选择运行哪些电厂及混燃配方，然后明确结束供电并指定供电城市数。结算收入后，统一补给资源，再更新电厂市场，自动进入下一轮排序。

每轮最多购买一座电厂，购厂者退出本轮其余竞拍。发起阶段直接“本轮跳过”即失去本轮所有后续竞拍资格。第一轮所有人必须买一厂，不能本轮跳过；第一轮竞拍全部结束后，按最大电厂编号重新排序。后续某轮无人购厂时，竞拍阶段结束才移除市场最小电厂并补一张。

超过持厂上限时必须拆除一座旧厂，不能拆新购厂。旧厂上的燃料可分份转存至保留电厂，或直接弃到供应；官方 FAQ 允许即使有可存位置也选择弃置。拆厂和转存完成前暂停其他竞拍。

## 仓储、混燃与供电

每厂最多储存输入数量的两倍，只储存可用燃料；混燃厂的煤与油共用总仓位。环保厂、50 号核聚变厂不耗料且无仓位。本人资源可在接收厂允许的范围内重新安排，平台在本人各决策窗口提供逐份转存，另提供双方仓位都满时的原子煤油交换。重排本身不耗费电币，不允许向其他玩家转移资源。

运行一座厂必须一次烧掉牌面完整输入，且每厂一轮最多运行一次；不能只烧部分燃料换取少量供电，也不能烧双倍燃料运行两次。混燃可以使用任意煤油组合：输入 2 有 0/2、1/1、2/0 三种；46 号输入 3 有 0/3、1/2、2/1、3/0 四种。环保与核聚变运行不耗料。

可运行任意数量的厂，甚至产生超过城市数的电力；超出的电力作废。明确结束供电时可选择 0 到“本轮已产生电力与本人城市数的较小值”的任何整数。主动少供电不返还已经运行电厂消耗的燃料。所有烧掉和弃掉的燃料回供应，不直接回资源市场。

## 建设与德国地图

只能在所选区域内连接城市，路线也限于所选区域构成的地图。首城连接费为 0，仅支付最便宜空位置的费用；之后每个新城都选择到本人任一已有城市的最便宜完整路线，包括同一建设回合刚连接的城市。可经过空城、其他人的城市或已满城市而不占位；不能借用其他人的网络减免费用，不能因为曾支付一段路线而永久免除其费用。

第一、二、三步分别允许每城最多一、二、三位不同玩家。占位支付最低空位的 10、15、20 电币；即使已进入后续步，空城首位仍只付 10。本人不能在同一城重复放房屋。所选区域和连接图由地图数据独立维护，经典修正版地图的 83 条边费用不受美术画面坐标影响。

每次建城或电厂补牌后，立即移除当前市场内编号不高于任何玩家城市数的电厂并继续补牌，直到不再存在该情况。玩家已拥有的小编号电厂不受影响。

## 三个步与补给

“步”是整局的发展时期，不是轮次，也不是轮内五个阶段。

| 第三步牌抽出时机 | 立即处理 | 第三步生效 |
| --- | --- | --- |
| 竞拍阶段 | 视作最大编号放入未来市场；洗剩余牌堆，继续所有人竞拍机会 | 竞拍全结束时移除第三步牌和最小电厂，不补牌；采购资源阶段开始 |
| 建城阶段补牌 | 移除第三步牌和最小电厂，不补牌；洗剩余牌堆 | 本轮行政结算开始；该轮剩余建城仍用旧步的城市容量 |
| 行政结算市场更新 | 移除第三步牌和最小电厂，不补牌；洗剩余牌堆 | 下一轮排序开始；本次最后采用第二步表，即便此前仍在第一步 |

第二步在全体玩家完成本轮建城后、行政结算前触发；按人数阈值判断，移除最小电厂一次并补一张，然后使用第二步补给表。第二城市位置要到下一次建城才可使用。第三步可先于第二步出现，经典官方 FAQ 要求直接继续第三步；不套用 Recharged 的附加第二步删除。

第二步入场这次补牌恰抽出第三步牌的特殊交叉情况，经典原文未单列。项目将其归入建城结束边界，立即激活第三步，本轮行政结算采用第三步补给；专门场景测试锁定此解释。

第一、二步的行政市场更新：最大电厂放到牌堆最下，然后补一张。第三步市场只有六张，全部可拍；行政结算移除最小厂并补牌。第三步牌堆耗尽后继续对局，市场可逐步缩小直至空，不生成替代电厂。

## 终局、秘密信息与恢复

任一玩家达到人数对应的终局城市阈值后，仍完成所有人的整次建城。然后比较当前城市、电厂和已有燃料能实际供电的最多城市数；不允许继续买资源或电厂。先比供电数，再比剩余现金，再比已连接城市数。

官方 FAQ 要求最终交回供电燃料，并说明最后一次收入对同供电者的现金比较没有影响。数字版自动选取达到最大供电数的最少燃料合法逐厂方案，真实扣燃料回供应，显示运行厂、配方、耗料和最终供电；省略最终收入和无后续意义的市场补给。自动选最少燃料是项目结算方式，出版规则要求的是合法供电。供电、现金、城市数仍全部相同时记共同赢家，这是官方未继续指定的平局情况下的项目采用。

现金采用官方 FAQ 推荐的保密方式：游戏中本人看到自己的现金，对手和公共屏看不到；竞价、资源、电厂、城市、行动顺序公开。终局显示现金。牌堆次序和秘密移除的牌号不投影，只显示牌堆数量；资源公开不意味着对手现金可见。

每个动作都是一个意图，行动编号每次递增；不同竞拍回合或阶段不共享并发声明。资源可选择同一厂、同一燃料的购买数量，每份仍按当时实际价阶计价，整笔一次校验与保存；旧单份动作继续兼容。仓储逐份转存、建城逐城、发电逐厂、供电明确结束。状态是可 JSON 保存的数据，恢复会校验全部 43 张牌分区、有限资源守恒（含拆厂临时资源）、现金总账、仓位、所选区域、城市人数、行动者、阶段索引、竞拍和最终供电证明。决策回退与身份管理由共享平台按 SDK 契约处理，游戏不自行保存身份授权。
