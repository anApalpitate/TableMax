TableMax 第三款独立游戏，采用经典《Power Grid》德国修正版地图，支持 2–6 人。规则版本 `classic-germany-2009-project-1`、状态版本 1、独立本地策略 `power-grid-local`／1.0.1；当前应用为 1.0.2，游戏版本保持。完整混合局、恢复与三端界面已通过；当前紧凑价阶、阶段摘要、双视图地图、收益浮卡及八章六组原创图解见 [本轮验收](../../reference/acceptance.md)；此前横向地图与声画的范围见 [debug 验收](../../reference/acceptance.md#102电力公司-debug横向地图价区与声画2026-10-04)，首次接入见 [历史验收](../../reference/acceptance.md#101电力公司经典德国版2026-10-04)和[接入归档](../../archive/power-grid-2026-10-04.md)。

## 对局内规则说明

主机、公共屏和手机工具栏均提供“规则”顶层卡片，按目标与五阶段、顺序与竞拍、电厂与仓储、燃料价区、建城与路线、三个步、补给与收入、胜负与项目设置八章查阅。规则内容和主题样式独立维护于 [规则界面](../../../games/power-grid/ui/RulesGuide.tsx) 与同目录 `rules-guide.css`；人数阈值和收入直接读取本游戏公开经济表，平台只共用章节导航与顶层浮层，不引入其他游戏玩法。采用经典德国版，明确五阶段与三个步的区别、排名与顺时针报价的区别、第一轮额外排序、逆序完成采购／建城、逐份涨价、每厂两倍仓储、混燃、占位加完整最短路费用，以及终局真实供电；项目自动结算和平局解释与出版规则分开标识。

六组原创图解覆盖五阶段与两种顺序、多价区采购、厂牌与混燃仓储、建城路线、STEP 生效边界、供电收入与胜负。准确数字、价阶、箭头和城位由 HTML／SVG 与现有公开数据绘制；燃料和木屋采用原创透明插画，厂景复用现有图集，新增 WebP 共 223,148 字节。行政阶段抽到第三步牌时，最后一次补给仍采用第二步；项目解释单独标注。旧五张截图、原图与历史证据保留在资源目录和清单中，当前规则不再引用截图。章节按钮至少 44 px、正文 18 px、说明 16 px、标题至少 20 px，窄屏纵向阅读。关闭或 Escape 恢复入口焦点，开关说明不影响合法动作、计时和游戏状态。
