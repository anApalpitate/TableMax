# 电力公司

TableMax 第三款独立游戏，采用经典《Power Grid》德国修正版地图，支持 2–6 人。规则版本 `classic-germany-2009-project-1`、状态版本 1、独立本地策略 `power-grid-local`／1.0.1；当前应用为 1.0.2，游戏版本保持。完整混合局、恢复、三端界面和 1.0.1 同 ZIP 便携验收已通过，范围与模拟边界见 [验收](../../reference/acceptance.md#101电力公司经典德国版2026-10-04)，过程见 [接入归档](../../archive/power-grid-2026-10-04.md)。

地图的城市、区域归属、83 条边及价格由代码维护；参考实物生成的地形和工业插画属于项目美术，不能标作出版原图或像素级复刻。正式游玩资源全部随包提供，不依赖互联网。

## 对局内规则说明

主机、公共屏和手机工具栏均提供“规则”顶层卡片，按五阶段、电厂燃料、路线与 STEP、收入胜负四章查阅。规则内容和主题样式独立维护于 [规则界面](../../../games/power-grid/ui/RulesGuide.tsx) 与同目录 `rules-guide.css`；人数阈值和收入直接读取本游戏公开经济表，平台只共用章节导航及截图／文字排版，不引入其他游戏玩法。采用经典德国版，说明五阶段与三个步的区别、每厂两倍仓储、混燃、占位加完整最短路费用，以及终局真实供电，项目自动结算和平局解释与出版规则分开标识。

配图采集隔离示例对局的公开电厂／资源市场、德国网络与公司牌，放在 `assets/games/power-grid/rules/` 随包提供，不含他人现金或秘密牌序。章节按钮至少 44 px、正文 18 px、说明 16 px、标题至少 20 px，窄屏纵向阅读。关闭或 Escape 恢复入口焦点，开关说明不影响合法动作、计时和游戏状态。
