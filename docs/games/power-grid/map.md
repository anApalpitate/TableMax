# 经典德国地图

采用带 **Torgelow** 的经典修正版德国地图，42 城、六区各 7 城、83 条无向连接。不是 Recharged 的 Stralsund 版本。规则数据与绘图坐标集中在 [germany.ts](../../../games/power-grid/data/germany.ts)，坐标不参与费用或区域计算。

核对首先参考经典实物正面图和无遮挡高清照片，再使用 S.O.B. 德国辅助图逐边检查。另以 [rkdarst 的地图网络数据](https://github.com/rkdarst/board-game-networks/blob/master/data/power-grid/germany.yaml) 自动比对全部 42 城、166 条双向记录和 83 条无向边。该辅助数据的元信息带 Recharged 链接及版本 FIXME，因此只用作第二份图结构对照，不据此改变经典版本。原图、原始 YAML、核对脚本和逐边结果在 `artifacts/maintenance/v1.0.1/power-grid/research/map/`。

三条零费连接为 Duisburg–Essen、Wiesbaden–Frankfurt (Main)、Halle–Leipzig。西南修正版为 Saarbrücken–Mannheim **11**、Mannheim–Stuttgart **6**、Saarbrücken–Stuttgart **17**；早期印刷差异的出版说明见 [来源](sources.md)。区域与经典实物一致，不以生成图片的色块推导规则归属。

开局选择对应人数所需的相邻区域。首城无需管线连接费，仍支付房屋费用；以后从本人任一已有城市计算所选区域内最短路径，再加城市当前空位的 10／15／20。路径可经过尚未建造、满员或对手城市；自己的管线费用不会作为可复用资产存储。最短路使用多源 Dijkstra，拒绝穿越未选区域和不可达目标。

规则数据仍按正面实物的城市布局标定在 900×1200 坐标内。2026-10-04 用户要求横向地图，展示层顺时针旋转 90°，以 1200×900 视窗呈现：地形、区域和管线对应旋转，城市坐标映射到同一位置，城名、价格与房屋保持正向。规则数据、最短路和费用不受旋转影响；指针选择、键盘选择与城市列表使用同一城市 ID。

独立地形位图、代码管线、价格、城名与房屋分层绘制。地图可缩放移动，手机提供城市列表与连接费用预览，复杂连接不靠低清图片识别。生成地形的边界和纹理仍是近似重绘；精确复刻的证明范围是可核对的城市、区域、图结构和费用，不宣称地形像素完全一致。

## 2026-10-05 视觉视图

棋盘／清晰视图共享城市坐标、83 条边及费用；默认棋盘，按本设备浏览器与主机／公共／手机端侧存储选择；窗口跨过手机宽度断点仍保留选择，兼容读取旧分档设置。当时横向裁切视窗为 `36 24 1152 864`；2026-10-06最新相机规格已替代此裁切及阶段不定位行为。区域选择强调轮廓，建城提高城位、节点和费用对比，其他阶段强调公司占用；短屏市场可摘要折叠。

房屋以稳定座号／符号补充公司颜色，城位区分当前 STEP 已开放、已占与未开放，排列不代表历史买入位置。城名与费用采用清楚底片，按实际显示尺度避让密集标注。保留缩放、拖动、城市选择与建设确认；本轮没有新增自动路线、推荐城市、费用排序或服务端字段。

v1.0.3 根据真实试玩与独立短屏审查调整表现：选区时本人未确认草稿只传入本机地图，弱化未选区并标注区域名称；建城全图即使比例较小也按空间显示部分清楚的费用和城名，选中城市相关费用保持可查看。所有道路先绘制，带不透明底片的费用牌随后绘制，避免后绘线路穿过数字；不以缩小字号塞入全部标注，密集处仍需沿用缩放和城市列表。多家公司同城的房屋用轻底座分组，当前公司房屋以下划线强调，选中城市继续使用独立城市高亮框，二者不共用虚线选中语义。数据及路线算法未变。

## 裁切相机（2026-10-06）

最新UI以地图坐标中心管理视角；完整图片边界为 `0 0 1200 900`，最低比例按完整视窗铺满后的1.06倍计算，四向硬边界贴合图片，不露空白。复位恢复默认视角并暂停跟随，保留当前选城。普通滚轮以指针为锚点指数缩放、逐帧平滑，地图文字禁止选中。自动定位考虑左／右边栏和底部玩家抽屉，聚焦当前选区、建设网络与新保存建设；主动拖动／缩放暂停跟随，显式入口恢复。手机仅跟随本人选城，同阶段同步保留相机。刷新、重连及回退不补播动画。城市列表与费用详情始终可查，不能依赖屏幕同时容纳全部城市。此处替代旧“全图复位／阶段不移动”展示约定，经典德国42城、六区、83边及横向变换不变。

### 地图材质与费用字号（2026-10-06）

根据用户要求，现有 `board-v1.webp` 经AI编辑补齐边缘留白、提高地形清晰度和材质细节，当前UI引用 [board-v2.webp](../../../assets/games/power-grid/board-v2.webp)，尺寸1086×1448，保持原900×1200竖图比例；原图与生成PNG保留，来源和导入记录见[资源清单](assets.md)。图像分辨率不参与空间与规则计算：展示仍使用完整1200×900横向逻辑边界，经典42城、六区、83边、城市ID、价格、最短路径及坐标旋转不变。生成地形仍属于近似演绎，不将细节增强称为实物像素复刻。

地图放大时，路线费用按 `16 + 2.5 × log₂(zoom)` CSS px 显示，zoom限制为1–4，即从16px缓增至21px；SVG内的字号再除以实际显示比例，避免与地图倍数等比增长。费用底片与数字同步适配，保留密集标注避让、选中城市相关费用和完整城市列表路径。

侧栏开关及宽窄过渡期间，聚焦避让使用边栏目标模式的最终占位，图片硬边界独立约束；不因动画中间帧的宽度而连续升级收起状态。新手动侧栏选择优先，取消选城恢复原模式。新地形与字号已导入本轮UI，实际渲染、便携包和设备覆盖仍以本轮[验收](../../reference/acceptance.md)记录为准。
