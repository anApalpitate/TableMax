# 《电力公司》界面与保存结果

按 [用户美术偏好](../../reference/art-preferences.md) S06 参考经典德国实物棋盘。地图、工业电厂、木制房屋和燃料颜色构成主视觉，运行图片、原声音效及其来源集中在 `assets/games/power-grid/`。生成地形与电厂插画属于近似／原创演绎，不称为出版扫描或逐张原画复刻；42 城的实际坐标、六区归属、83 条连接与费用来自独立德国数据，规则不用图片判断路径。

## 三端与地图

电脑 host／public 只呈现公共电网、公开电厂与库存、资源市场和行动进度，所有真人意图来自各自手机。公共屏没有游戏选择按钮。管理员管理、显示与公开公司详情按需展开；手机房主使用本人投影，仅通过平台已有权限控制开局、暂停／恢复与原班续局。其他公司的现金在游戏结束前不显示。

德国图由本地地形底图与精确 SVG 城市、连接、房屋叠加，展示层旋转 90° 为横向，城名、线路费用和房屋正向。电脑持续以地图铺底，市场、收益与玩家使用可收起边栏／底部抽屉；具体行为以以下最新规格为准。常驻公司卡保留稳定头像、完整可访问昵称、位次数字、地皮数、带图电厂及燃料合计；放大镜打开综合资料，展示产能、完整城市清单和逐厂库存。同一浮窗使用一个纵向滚动区，长昵称换行或保留完整 `title`，不横向挤出控件。

地图支持按钮放大／缩小、默认清晰视角复位、鼠标／单指拖拽和双指缩放。未选择区域的城市及线路弱化。全图用于辨认地形、城市和房屋；点城或从完整城市列表选择后显示城市与 10／15／20 三个位置的费用和占用。选中城市始终显示城名及其相邻线路费用；全图费用与其他城名按实际地图渲染比例展开，不能仅因窄手机放大到某一倍数就把全部标注挤在小视窗中。标注按实际显示比例保持至少 16px。城市点击按最近的真实节点解析，触控命中至少 44px；城市列表提供不依赖密集地图命中的操作路径。缩放、预览与打开浮窗均不发送游戏动作。

## 地图背景与紧凑公司（2026-10-06）

电脑地图覆盖工具栏下全部牌桌，相机保存地图坐标中心、缩放与跟随状态。使用完整1200×900图片边界，最低比例为铺满视窗后的1.06倍；完整视窗硬边界保证四向极限拖动不露空白。边栏避让与图片边界分开：选区、当前建设网络及新保存城市定位到可见区，选城先在最高四倍内增加缩放，仍遮挡则临时收窄宽市场，再逐步收起遮挡抽屉。取消选城恢复原模式；新的手动开关／宽度操作优先。

地图普通滚轮以指针为锚点，统一单位后指数缩放并逐帧收敛；连续输入更新目标，不排队。拖动、滚轮与双指缩放暂停跟随，“跟随”恢复；复位返回默认清晰视角并暂停跟随，保留选城。普通同步保留视角，刷新、重连与回退不补播历史定位。图形与文字禁止选择。空白、重复点城、外部市场／收益／公司及Escape取消选城；地图工具、城市详情和具体建设确认保留。取消不移动相机。选中与键盘聚焦共用一层框，空城无十字；手机本人身份色、电脑人工选城管理员深青色、保存建设用行动公司的稳定身份色。

左市场共用电厂／燃料标签：选区收起；选厂、竞拍及换厂展开电厂，竞拍包含当前报价；采购展开完整燃料价阶；建城收起。市场收起／窄310px两厂／宽最大900px四厂，宽栏至少留96px地图；独立图标切宽窄，收起重开记忆宽度，新大阶段恢复默认窄栏及阶段开关。右收益仅发电默认展开。图标入口悬停／键盘聚焦有提示及可访问名称，开关和浏览箭头用实心三角。≤1100px或两侧合计空间不足时辅助栏互斥，每栏只有一个纵向滚动区。

底部玩家抽屉默认展开，手动收起同局保留。公司按服务器playerOrder升序，头像、昵称和身份色保持座位身份；排列直接表达位次，不再提供独立“顺序”按钮或重复的正／逆序说明，竞拍报价仍按座位顺时针。左上角色底白字数字徽章保留可访问位次语义。新保存结果变序才执行稳定ID的320ms移动、新位次逐卡错开40ms；减少动态及测试模式直接重排。三至六人一行三张带图厂牌，两人四厂2×2；新购待替换独立带图展示，临时第五厂完整可见。房屋图标加城市数，煤／油／垃圾／铀库存包括零，待安置另列。现金按既有投影：本人手机及终局显示，其他情况无现金区，不推算对手现金。宽度不足仅条带横向滚动并提供左右浏览。

收益约280px宽、随内容收束、标题居中；每档地皮／供电数量与电币金额在同一行，图标、数字与箭头统一对齐。左列从上到下0–9，右列10–19，20+在最后一行横跨两列并居中。复用现有计算，仅燃料可实现供电档标绿，完成后用实际供电；无说明框或第二种高亮。手机收益浮卡同步。

手机保留行动／市场／地图／公司四页和底部确认。公司纵向排列，带图电厂逐厂横条，本人高亮；完整价阶、逐厂行动、具体建设费用保留。地图仅跟随本人选城，其他公司建设不改视角；单指拖动／双指缩放不触发分页。同步保留页面、滚动及合法草稿，新大阶段回行动页，轮到本人只提示。短屏压缩插画和重复标签，信息≥16px、关键状态≥18px、电脑标题≥20px、手机触控≥44px。

### 边栏、地图材质与综合资料细化（2026-10-06）

市场、收益与公司抽屉双向开关采用280ms位移和220ms透明度过渡，市场宽窄切换同步平滑改变宽度。关闭内容保留至过渡结束，立即退出键盘与指针操作；快速反向切换从当前位置继续，不排队。减少动态及测试模式直接切换。地图聚焦避让使用目标模式的最终占位，动画中间尺寸不触发额外收起；原有同阶段记忆、阶段默认和新手动选择优先仍适用。

图标按钮的容器以网格居中，SVG按实际可见轮廓修正内部空白及视觉重心；提示文字、可访问名称、开关状态与44px触控目标保留。市场、收益、宽窄切换、放大镜及实心三角箭头沿用本地SVG。

地形使用AI编辑现有底图后导入的 `board-v2.webp`，补全图片边缘的空白地形并提升纹理清晰度；原图和生成PNG保留。图像只承担地形材质，精确城市、区域、连接及费用仍由原数据与SVG绘制，横向逻辑边界不变。放大地图时通道费用字号小幅增加，增长小于地图倍率，具体尺寸与素材边界见[地图](map.md#地图材质与费用字号2026-10-06)。

“各家”改为放大镜图标，打开全部公司的综合资料；原公司卡也可直接打开单家公司。浮窗最大宽度为 `min(96vw, 1600px)`，内容按可用宽度排列，手机逐家公司纵向阅读，同一浮窗仅一处纵向滚动。公司继续按服务器位次排列，身份色按固定座位；展示完整昵称、行动／本人／冠军状态、已建地皮及完整城市清单、总产能、现有燃料可实现供电、带图逐厂信息与库存仓位、四类库存（含零）、新购待替换与待安置燃料。发电阶段只依据公开 `ran` 标记本轮已运行／未运行。现金仅在授权字段非空时显示，查看不提交动作、不推算对手资金、不新增路线建议。

电脑工具栏在“第几轮／第几步”左侧显示当前阶段及行动公司，以阶段标签、公司身份色标记和清晰姓名分层呈现；长昵称保留完整可访问名称，较窄电脑窗口上下排列。手机继续显示本人轮次提醒，不因他人轮次打断公司或市场阅读。本轮代码、素材与文档已更新；实际渲染、同版本包及安全维护结果另入[验收](../../reference/acceptance.md)，不在此提前宣称通过。

## 手机选择

- 区域：六区选择保持颜色和文字双重标识，只有服务器列出的相邻组合可确认。
- 竞拍：选择电厂、精确整数报价，再明确确认；加减金额向相邻合法整数恢复，小数／越界金额不能提交。退出本次竞拍与本轮不买电厂使用各自动作文字。
- 燃料：在对应电厂选择数量，保留＋1／−1与直接输入，显示跨价阶累计总价，明确确认后一次保存。上限由服务器合法动作同时约束现金、现货与仓储，混燃煤油共享容量；同决策同步保留合法草稿，新保存决策回到一份。厂间转存与满仓煤油交换按需展开，使用具体厂号、资源符号及方向。
- 换代：先明确淘汰旧厂，再把剩余燃料逐份存入合法电厂或明确丢弃；新厂不能误作旧厂选择。
- 建设：地图或城市列表选择后显示城市位置费用、最短连接费用和总价，再点击具体城市的建设动作；不能建设的城市只显示预览状态。
- 发电：逐厂选择启动，混燃厂有多个合法煤／油组合时按需展开，每个组合都可直接确认；已经启动的厂明确标记。选择本轮实际供电城市数及对应收入后确认，支持规则允许的少供电。

手机按当前阶段呈现主要操作，辅助地图、市场和公司通过四页导航查阅；建设阶段行动页保留地图及具体建造确认，完整地图页另供阅读。短屏先减少重复标题和重排，信息至少 16 CSS px、主要动作／状态至少 18px、电脑分区标题至少 20px；触控至少 44px。

## 保存、暂停与声音

游戏适配器仅使用当前授权投影和服务器合法动作。提交走通用会话信封与确认；失去连接、暂停或意图失效时停止标示“行动中”，确认丢失沿用平台原信封重试。当前行动者、座位编号、本人资金与共用提醒倒计时分别呈现，倒计时不会自动竞拍、采购或代真人行动。

白底最新记录与工业局部声画只响应成功保存后的反馈，首次加载、同步、刷新、重连和回退不补播。`savedChanges` 使用本游戏记录 ID，画面短反馈不参与规则推进；测试模式及减少动态设置关闭动画。菜单与公司／地图浮窗显式附带 `pg-screen` 范围，避免切换游戏后已加载的 CSS 相互影响。

六个第二版确定性 WAV 是电报码报价、金属装卸、建设铆钉、电厂启动、发电和终局和弦，无背景音乐或外部录音。电脑公共屏优先，管理员通过平台声音归属承接；保存事件使用实例／分支／修订键统一 `claimEvent` 去重。暂停、断线、静音、失去播放资格或退出组件立即停止；手机没有声音控件。六类专属代码动效表达已保存的竞价、装卸、建造、购厂、供电和终局，同一保存键的普通同步不重启或提前清除效果；静音只影响声音，减少动态保留短暂静态标记。新终局保存允许播放结算，首次进入终局不会补播。音频制作参数、峰值／RMS／哈希位于生成证据，模拟播放调用与真实听感分别表述。

终局按实际供电城市和剩余现金呈现排行与冠军，不把网络城市数误作供电成绩；详细资源／燃耗依据仍由游戏最终结果保存。原班再玩使用平台 replay，保留身份与座位。

具体后台组件矩阵、自然整局、真实服务／便携范围与尚未验证的设备分别进入 [验收记录](../../reference/acceptance.md)，fixture 不替代自然对局或真实手机／电视实测。

## v1.0.3 试玩后的操作优化

普通节奏的两个人类手机身份与默认人机实际走完一轮，逐份跨价采购、具体城市费用确认、发电默认最大合法供电、主动少供电及倒计时仅提醒均正常。采购首个按钮原在 390×844 页面的 1158px，建城结束进入发电仍停在 575px 深滚动；市场存在多个同名入口，选区名称也未与未确认地图联动。真实试玩与独立截图审查的范围分别记录在 [验收](../../reference/acceptance.md)，不由源码推断交互问题。

手机采购将本人厂牌、库存与逐份购买放在完整价阶前；价阶仍按阶段默认展开，市场只保留同一摘要及展开入口。高度不超过 600px 的手机采购画面收起厂景插画，保留厂号、资源、耗料、产能与仓位，其他尺寸保留厂景。顶部品牌／轮次与 STEP 共用一个栏位，主要操作维持 44px；新大阶段、再玩或回退分支回到页面开头，同阶段保存不改变滚动与手动展开，地图内部缩放及拖动不重置。

选区草稿由本人手机本地维护，棋盘／清晰地图均显示候选边界、六区名称和“未确认”摘要，关闭查看保留草稿；只有按现有确认按钮才提交。主机及公共屏不展示本人未提交草稿。当时建城电脑侧栏包含公司摘要与市场；该布局已由2026-10-06地图铺底及独立底部玩家抽屉替代。终局现金保留文字标签，继续按实际供电城市排名。
