# 《电力公司》界面与保存结果

按 [用户美术偏好](../../reference/art-preferences.md) S06 参考经典德国实物棋盘。地图、工业电厂、木制房屋和燃料颜色构成主视觉，运行图片、原声音效及其来源集中在 `assets/games/power-grid/`。生成地形与电厂插画属于近似／原创演绎，不称为出版扫描或逐张原画复刻；42 城的实际坐标、六区归属、83 条连接与费用来自独立德国数据，规则不用图片判断路径。

## 三端与地图

电脑 host／public 只呈现公共电网、公开电厂与库存、资源市场和行动进度，所有真人意图来自各自手机。公共屏没有游戏选择按钮。管理员管理、显示与公开公司详情按需展开；手机房主使用本人投影，仅通过平台已有权限控制开局、暂停／恢复与原班续局。其他公司的现金在游戏结束前不显示。

德国图由本地地形底图与精确 SVG 城市、连接、房屋叠加，展示层旋转 90° 为横向，城名、线路费用和房屋正向。电脑持续以地图铺底，市场、收益与玩家使用可收起边栏／底部抽屉；具体行为以以下最新规格为准。取消逐公司的内层滚动。概览明确标出“网络”和“产能”的城市数，保留座位编号、稳定头像、完整可访问昵称、电厂编号及燃料合计；公司浮窗查看两列纵向排列的逐厂库存。长昵称换行或保留完整 `title`，不横向挤出控件。

地图支持按钮放大／缩小、默认清晰视角复位、鼠标／单指拖拽和双指缩放。未选择区域的城市及线路弱化。全图用于辨认地形、城市和房屋；点城或从完整城市列表选择后显示城市与 10／15／20 三个位置的费用和占用。选中城市始终显示城名及其相邻线路费用；全图费用与其他城名按实际地图渲染比例展开，不能仅因窄手机放大到某一倍数就把全部标注挤在小视窗中。标注按实际显示比例保持至少 16px。城市点击按最近的真实节点解析，触控命中至少 44px；城市列表提供不依赖密集地图命中的操作路径。缩放、预览与打开浮窗均不发送游戏动作。

## 地图背景与紧凑公司（2026-10-06）

按用户确认方案，电脑地图覆盖工具栏下全部牌桌，最低比例铺满并裁切，四向可拖动；相机保存地图坐标中心、缩放与跟随状态。拖动边界依据地图尺寸及未被抽屉遮挡区域计算。选区、当前建设公司的网络、新保存的建设城市自动定位在可见区域；手动拖动／缩放暂停跟随，“跟随”入口恢复。完整城市列表可主动定位并从“城位”打开10／15／20位置费用及占用详情，不提交动作。普通同步保留视角，刷新、重连与回退不补播历史定位动画。

左市场共用电厂／燃料标签：选区收起；选厂、竞拍及换厂展开电厂，竞拍包含当前报价；采购展开完整燃料价阶；建城收起。右收益仅发电默认展开，含完整0–20城收入表。手动开关在同一大阶段保持，新阶段恢复默认；有效宽度≤1100px最多展开一个辅助边栏，各自只有一个纵向滚动区。旧阶段主区与重复公司概览移除，完整详情仍按需浮窗查看。

底部玩家抽屉各阶段默认展开，手动收起在同局保留。固定四格2×2列出厂号、燃料、耗料与供电，无厂景插画；房屋图标加网络城市数，四类能源按煤、油、垃圾、铀显示，包括零库存。库存汇总拥有电厂，待安置燃料另列。四格是展示布局：两人上限四厂，三至六人上限三厂；新购待替换厂单列，临时第五厂不截掉。卡片始终按服务器playerOrder升序，昵称、头像、身份色按稳定座位保持。采购／建城用逆序方向提示，单场报价仍是固定座位顺时针。只在新保存结果改变位次时按稳定玩家ID执行320ms移动、新位次每卡错开40ms；减少动态及测试模式直接重排。宽度不足仅卡片条带水平滚动，左右按钮浏览。

手机保留行动／市场／地图／公司四页及底部确认。公司纵向排列同款紧凑卡，本人高亮，现金仅在本人状态区；完整市场价阶、逐厂行动、具体建设费用不省略。手机地图仅跟随本人选城，其他公司建设不改变视角；地图单指拖动／双指缩放不触发分页。普通同步保留页面、滚动及合法草稿，新大阶段回行动页，轮到本人只提示。短电脑屏重排厂格与房屋／库存行；文字不缩至16px以下，关键状态18px、分区标题20px、手机控件44px。

## 厂牌与经济信息

2026-10-04 按用户最新通用视觉要求调整电力公司，沿用独立工业主题。七类电厂采用深色分类框和位于插画上方的燃料／能源符号：混燃同时显示煤和油，环保使用叶片，聚变使用原子符号，核能保留铀标记；不能只靠浅色边框辨认类型。普通厂牌明确区分编号、类型、耗料与供电，零耗料显示“免燃料”而非可能误解为免费买厂的“免费”；库存区显示资源图标、数量和明确的仓位占用。紧凑公开公司卡省去重复文字，但保留类型符号、耗料、供电、仓位及完整可访问名称，标记不覆盖厂图。

当前市场以“可竞拍电厂”为标题，未来市场明确标出“暂不可拍”。燃料市场展示经典版完整价格区：煤、油、垃圾各有 1–8 的八区，每区三份；铀有 1–8、10、12、14、16 的十二区，每区一份。金额明确为每份电币价格，每档数字表达余量，零库存档弱化但保留，不能把初始空位都称作已售出；箭头和深框指出最低现货价。余量从高价侧连续填满，实际采购从最低现货价逐份取，不新增报价或批量抢购规则。完整阶梯提供当前最低价和总库存，手机市场页保留全部价档；厂旁购买按钮给出本次价格，下一份涨价或售罄时强调变化。

行动顺序以当轮 `playerOrder` 为准，选厂发起／发电正序，采购与建城逆序；显示排名、当前人及已经完成／已购厂／本轮不买等资格。单场竞价另按固定座位顺时针显示，不能把报价顺序当作购厂排名。手机采购／建城默认显示当前人和确定的下一家，完整排序与单场名单按需展开；购厂阶段使用“后续顺位”，不把成交前尚未确定的下次发起者画成确定下一家。手机报价时缩成完整顺序入口，当前报价身份只在主状态显示，金额、确认与退出紧接最高价，名单在主操作之后。短电脑屏从“顺序”浮窗查完整名单。

竞拍区突出当前最高价及领先公司，本人金额标明“现金”；混燃耗料写“共几份”，表示煤油合计。手机选厂列表保留两列，本人采购／发电采用含厂景的紧凑逐厂行，每页单层纵向阅读，避免内层限高裁掉操作按钮。操作与对应厂牌相邻，完成阶段的按钮留在列表外；混燃有多种合法配方时通过“选择燃料”展开，不能机械把复杂金额或地图控件也挤成两列。

## 手机选择

- 区域：六区选择保持颜色和文字双重标识，只有服务器列出的相邻组合可确认。
- 竞拍：选择电厂、精确整数报价，再明确确认；加减金额向相邻合法整数恢复，小数／越界金额不能提交。退出本次竞拍与本轮不买电厂使用各自动作文字。
- 燃料：直接在对应电厂购买一单位，当前价格、仓内资源与容量同时可见；重复购买仍逐次等待保存确认。厂间转存与满仓煤油交换按需展开，使用具体厂号、资源符号及方向。
- 换代：先明确淘汰旧厂，再把剩余燃料逐份存入合法电厂或明确丢弃；新厂不能误作旧厂选择。
- 建设：地图或城市列表选择后显示城市位置费用、最短连接费用和总价，再点击具体城市的建设动作；不能建设的城市只显示预览状态。
- 发电：逐厂选择启动，混燃厂有多个合法煤／油组合时按需展开，每个组合都可直接确认；已经启动的厂明确标记。选择本轮实际供电城市数及对应收入后确认，支持规则允许的少供电。

手机按当前阶段呈现主要操作，辅助地图、市场和公司通过四页导航查阅；建设阶段行动页保留地图及具体建造确认，完整地图页另供阅读。短屏先减少重复标题和重排，信息至少 16 CSS px、主要动作／状态至少 18px、电脑分区标题至少 20px；触控至少 44px。

## 保存、暂停与声音

游戏适配器仅使用当前授权投影和服务器合法动作。提交走通用会话信封与确认；失去连接、暂停或意图失效时停止标示“行动中”，确认丢失沿用平台原信封重试。当前行动者、座位编号、本人资金与共用提醒倒计时分别呈现，倒计时不会自动竞拍、采购或代真人行动。

最新记录与工业短提示只响应成功保存后的反馈，首次加载、同步、刷新、重连和回退不补播。`savedChanges` 使用本游戏记录 ID，画面短反馈不参与规则推进；测试模式及减少动态设置关闭动画。菜单与公司／地图浮窗显式附带 `pg-screen` 范围，避免切换游戏后已加载的 CSS 相互影响。

六个第二版确定性 WAV 是电报码报价、金属装卸、建设铆钉、电厂启动、发电和终局和弦，无背景音乐或外部录音。电脑公共屏优先，管理员通过平台声音归属承接；保存事件使用实例／分支／修订键统一 `claimEvent` 去重。暂停、断线、静音、失去播放资格或退出组件立即停止；手机没有声音控件。六类专属代码动效表达已保存的竞价、装卸、建造、购厂、供电和终局，同一保存键的普通同步不重启或提前清除效果；静音只影响声音，减少动态保留短暂静态标记。新终局保存允许播放结算，首次进入终局不会补播。音频制作参数、峰值／RMS／哈希位于生成证据，模拟播放调用与真实听感分别表述。

终局按实际供电城市和剩余现金呈现排行与冠军，不把网络城市数误作供电成绩；详细资源／燃耗依据仍由游戏最终结果保存。原班再玩使用平台 replay，保留身份与座位。

具体后台组件矩阵、自然整局、真实服务／便携范围与尚未验证的设备分别进入 [验收记录](../../reference/acceptance.md)，fixture 不替代自然对局或真实手机／电视实测。

## 2026-10-05 燃料、阶段摘要与收益卡

燃料市场以四条完整价格阶梯呈现，煤／油／垃圾各八档、铀十二档；每档保留单价与余量，最低有货档以边框与箭头标识，零库存弱化。图标、短名称、最低价与总量只各显示一次。采购仍直接逐份保存；下一份跨档涨价或售罄才强调变化，混燃库存明确共用仓位。

电脑公司卡常驻头像、座号、网络、产能、厂号及燃料合计，逐厂详情按需打开。选厂／竞拍默认展开电厂，采购展开燃料，建城保留地图及确认，换厂与发电突出当前公司。其他关键板块保留摘要及展开入口；大阶段切换恢复默认，同阶段同步不清除手动展开。侧栏仅一处纵向滚动，手机按页面阅读。

收益入口支持电脑悬停、聚焦预览和点击固定；手机点击顶层卡片，关闭／Esc 返回入口焦点。完整收入表为 0 城 10 E 至 20+ 城 150 E。纯计算排除已启动厂的重复运行，合并已产生电力和剩余燃料可产电力并受城市数限制，剩余库存包含所有厂；已完成公司显示实际结果。手机本人供电选择只在本人卡片显示，公共屏不展示未提交选择；查看不发送游戏动作。

规则保留八章导航，采用六组原创图解：阶段与顺序、采购价阶、厂牌仓储、建城路线、STEP 边界、收入胜负。精确数字与图形使用 HTML／SVG，图片只承担燃料、房屋和厂景插画。行政阶段抽到第三步牌，最后一次补给仍采用第二步；项目解释另标注。旧规则截图及原图保留，不再作为当前配图。

## v1.0.3 试玩后的操作优化

普通节奏的两个人类手机身份与默认人机实际走完一轮，逐份跨价采购、具体城市费用确认、发电默认最大合法供电、主动少供电及倒计时仅提醒均正常。采购首个按钮原在 390×844 页面的 1158px，建城结束进入发电仍停在 575px 深滚动；市场存在多个同名入口，选区名称也未与未确认地图联动。真实试玩与独立截图审查的范围分别记录在 [验收](../../reference/acceptance.md)，不由源码推断交互问题。

手机采购将本人厂牌、库存与逐份购买放在完整价阶前；价阶仍按阶段默认展开，市场只保留同一摘要及展开入口。高度不超过 600px 的手机采购画面收起厂景插画，保留厂号、资源、耗料、产能与仓位，其他尺寸保留厂景。顶部品牌／轮次与 STEP 共用一个栏位，主要操作维持 44px；新大阶段、再玩或回退分支回到页面开头，同阶段保存不改变滚动与手动展开，地图内部缩放及拖动不重置。
