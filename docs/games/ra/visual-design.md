# 太阳神｜配色、石板与玩家板

2026-11-17 用户确认配色与玩家板方案，随后在源码接入。电脑端以暖灰石为主，手机竖屏用浅石灰岩。玩家板按普通版第三印的图示关系组织，石板保持无可见牌名。现行数值见[规则与开发规格](spec.md#计分与时代交接)，实体依据见[来源与核对表](sources.md#第三印玩家板)。

## 桌面配色

公共牌桌、槽位和玩家板外框使用同一套石质色阶。电脑端以暖灰石为主，质感来自桌边微弱的石纹和明暗层次。手机端用低彩度浅石灰岩。玩家板的图例内页用暖纸底衬托实物板的紫、青绿与红色标记。保留石板本身的红、蓝、紫和灰沙色。青铜仅标时代、当前焦点和少量轮廓，选中／待弃／不可操作用边框、勾选或弃置符号共同表达。

| 用途 | 电脑管理端 | 手机竖屏玩家端 |
| --- | --- | --- |
| 外围与背景 | 暖炭灰 `#242522` | 浅灰砂岩 `#F0E6D3` |
| 公共桌面与个人板 | 暖灰石 `#36352F` | 浅石灰岩 `#E6DCC6` |
| 拍卖槽与资源槽 | 哑光灰褐 `#4B443A` | 低彩砂灰 `#CFC1AC` |
| 文字与数字 | 暖骨白 `#EEE4CF` | 墨色 `#292823` |
| 时代、选中与行动 | 哑铜 `#DCB56B` | 深青 `#24595C` |

色值是首轮样稿基线。先把尼罗河／洪水、农业／书写及相近纪念物同时放进两端拍卖槽和玩家板，再以实际最小尺寸核对。纹理停在留白和板边，石板不着色，常态与高亮也不盖住边角类别标记。弃置确认状态保留短动作词与选择计数。

## 石板选材与精简

- 以 `work/ra/flat-review-v2/manifest.json` 的 23 个当前条目作逐面底稿。书写、天文、狮身人面像、陵墓、神庙、地震、旱灾优先使用经上一轮核对的 `-hd-v3` 增强图。其他 16 面目前是保真重采样和轻度锐化。资源验收以原画轮廓、角标、色带和最小实际尺寸为准，大文件尺寸本身不算清晰度证据。
- 优先补核农业、圣龛、阶梯金字塔、战争和葬礼的低分辨率原件，并排比对尼罗河和洪水。找到足够清晰的同版来源后优先使用，逐张核对类型、原图和图标。允许每面保留一份最高可用底稿和一份运行导出，所有引用同一面 ID。现有增强图经运行压缩后长边约 400 px，后续按实际显示尺寸、设备像素比和清晰度决定导出规格。
- 运行目录已精简。核对路径、大小、哈希、来源和运行引用后，退役了八张根目录旧占位图 `god.webp`、`nile.webp`、`obelisk.webp`、`pharaoh.webp`、`pyramid.webp`、`relief.webp`、`religion.webp`、`writing.webp` 和旧角饰 `table/player-board.webp`，共 118,052 字节。同步更新运行清单，保留外部底稿和已冻结发行文件。
- 七个旧重采样备选仍被审阅清单的 `previous` 和旧审阅页引用，待迁移引用后再复核可删除的衍生副本。保护出版方原件、馆藏原件、裁切溯源、当前选定底稿、现有审阅记录和旧版发行文件。清理不按目录、扩展名或文件尺寸批量删除。素材入口见[本地原件与审阅](sources.md#本地原件与审阅)。

## 玩家板布局

每席都有自己的玩家板。玩家端以本人板为常驻区域，其他座位的公开信息可按需展开。电脑管理端每席有独立公开板，按人数排布，关键信息与公共拍卖区同屏可见。本人资源格、公共缩略视图和展开态用同一分类。分数、时代计分明细和已用圆盘沿用[现有权限](spec.md#tablemax-的公开与恢复约定)。

| 左侧保留区 | 中轴圆盘 | 右侧时代区 |
| --- | --- | --- |
| 纪念物、法老、尼罗河 | 2／3 人局每席 4 盘，4／5 人局每席 3 盘，区分可用与已用 | 神明、黄金、文明、洪水 |
| ∞ 保留图标，仍受相应灾难影响 | 只在第三时代计分的沙漏标记 | 弯箭头，时代结算后弃置 |

电脑端以实体板的左右关系组织每席，尼罗河与洪水相邻对齐，中间用细连线和洪水门槛图示关联。手机仍保持左保留、右时代两列，把圆盘挪到板上方。每类资源用类别图标、石板图和数量表示，重复板块可叠放，计分展开时看得到对应子型。常驻画面使用必要的图标和短数字。轻触、键盘聚焦或打开图例可以查到简短中文解释，核对时可以展开完整计分表。灾难取得后按现有流程处理，拉板块走公共轨，二者都无常驻资源格。

## 计分图示

保留／清除和计分时机是两套标记。左、右图区头用保留／弃置图标。类别沿用实体板上三种填充形态和配色的小沙漏，三种连排表示每时代计分，单个末时代沙漏表示只在第三时代计分。各档计分沿用实体版的竖向图例，采用类别小石板、叠放的判断徽记和形似记分牌的分值图标。图标及数值由布局绘制，可单独核验。提示属于规则速查，实际得分仍读取权威结算。

| 部位 | 常态图示和展开内容 |
| --- | --- |
| 尼罗河／洪水 | 两种石板各用自身图案。洪水图标 `≥1` 用单向线连接尼罗河，再标每枚 `+1`。无洪水时以空心或中断连线显示未激活，尼罗河仍留在左区。每枚洪水独立 `+1`。旱灾提示放在两个格之间，共用一个灾难标记，箭头指示先洪水后尼罗河。 |
| 法老 | 每时代结算。以同类数量的最高／最低图标配 `+5／−2`，展开说明并列同奖惩，全等为 0。 |
| 神明和黄金 | 每时代结算。神明余牌 `×2`，黄金 `×3`。神明换取提示和实际操作区域对应。 |
| 文明 | 每时代结算。显示不同子型构成的一套，展开用规则规格的 0–5 类矩阵，能看懂空集扣分、1／2 类为 0 和重复类别不加档。 |
| 纪念物 | 仅第三时代结算。上半列逐行用紫色纪念物和同类徽记标 3／4／5 枚对应 5／10／15 分，中间用圈中的「&」连接。下半列用异类徽记标 1–6／7／8 类的对应分值。紧凑板用同类和异类图标提示，可展开同一套竖向图例。 |

## 实现与验收

1. 类别、去留、时代与得分符号由可缩放矢量图和布局绘制。以实物板的左右顺序、同异类计分以及洪水门槛作依据。手机的圆盘移到上方，牌池总数和中文规则可从图例展开。
2. 先做双端同一桌面的配色与 23 面检查。手机以 390×844 及项目支持的最窄竖屏检查，电脑以 1280×720、5 席满桌和短屏检查，同时核查键盘、触屏和缩放。审阅图包含清晰度不足的原尺寸对照，并记录对应版本。
3. 实际游戏验收覆盖拍卖到正确归位、纪念物两套计分、洪水从无到有与时代交接后重新归零、旱灾先清洪水、战争和地震确认弃置、各席本人结算与第三时代终局。对照保存结果及恢复后的界面。验收素材和画面以当前运行出处、版本及权限为准。
4. 用户要求每轮制作都由 agent 打开实际渲染截图，比对同一区域的实体板图。记录电脑缩略板、手机完整板和计分区近景。重点核对类别徽记、分值牌轮廓、每档的顺序、沙漏、字重和底色。纪念物的同类与异类分列在各自的竖向档位，正文式横排公式会在手机折行并改变实体图示的读法。目视结论随场景检查记录。

本轮独立视觉复核逐张打开手机和电脑的实际对局、玩家板与纪念物近景，对照第三印的整板图和两张官方局部照。验证纪念物两组共六行的竖排结构、计算徽记、沙漏、去留标识、河流条件和分值牌。第二轮对照确认比较徽记与冒号之间留有间隔，并检查了手机移到板顶的圆盘位。

本机回环源码服务使用 SQLite 保存和 Socket.IO 通信。Edge 在电脑 1280×720、手机 390×844 双端完成两席受控对局，覆盖真实出价和换盘、地震取消与确认、洪水激活、第一时代弃洪水保留尼罗河、页面重载后恢复个人河流计分，以及第三时代公开排名。五席管理端在 1280×720 可同屏查看，320×568 手机视口保留两列且无横向溢出。23 张石板均通过哈希和浏览器解码。证据位于 `artifacts/maintenance/ra-player-board-20261117/live-r5/result.json`，离线展示位于素材工作区的 `exports/ra/tablemax-player-board-demo.html`。
