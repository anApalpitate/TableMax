# 太阳神｜配色、石板与玩家板

2026-11-17 用户确认配色与玩家板方案，随后在源码接入。电脑端以暖灰石为主，手机竖屏用浅石灰岩。玩家板按普通版第三印的图示关系组织，石板保持无可见牌名。现行数值见[规则与开发规格](spec.md#计分与时代交接)，实体依据见[来源与核对表](sources.md#第三印玩家板)。

## 桌面配色

电脑端以暖灰石为主，拉轨与拍卖槽共用较亮的暖砂石板，空位保留清楚轮廓。桌面视口余区继续铺暖灰石底。手机端用低彩度浅石灰岩，公共板上沿用更浅的砂石色。玩家板的图例内页用暖纸底衬托实物板的紫、青绿与红色标记。保留石板本身的红、蓝、紫和灰沙色。青铜仅标时代、当前焦点和少量轮廓，选中／待弃／不可操作用边框、勾选或弃置符号共同表达。

| 用途 | 电脑管理端 | 手机竖屏玩家端 |
| --- | --- | --- |
| 外围与背景 | 暖炭灰 `#242522` | 浅灰砂岩 `#F0E6D3` |
| 公开摘要／本人板外框 | 暖灰石 `#36352F` | 浅石灰岩 `#E6DCC6` |
| 公共拉轨和拍卖展板 | 暖砂石 `#776650` 至 `#5E5143` | 浅砂石 `#F2E8D3` 至 `#DDD0B6` |
| 拍卖槽 | 青灰石 `#465E5D` | 浅灰绿 `#AEBDB2` |

| 时代、选中与行动 | 哑铜 `#DCB56B` | 深青 `#24595C` |

在两端用尼罗河／洪水、农业／书写及相近纪念物核对牌面。纹理停在留白和板边，石板保留原色和边角类别标记。弃置确认状态保留短动作词与选择计数。

中央盘在电脑端为 67 CSS px，手机为 54 CSS px。公共拉轨用空心与实心太阳标明未到和已到的格子，当前格上方有日轮托住太阳船。船随保存后的拉计数滑向新位置，减少动态模式即时定位，时代切换重置拉轨。

书本图标和齿轮同排，分别打开规则和游戏设置。齿轮提供本机音效及该身份有权限使用的牌桌管理。顶栏回执、进度、连接和失败消息遵循[通用视觉规范](../../reference/visual-design.md#保存结果与声画反馈)。

## 石板选材与精简

- 以 `work/ra/flat-review-v2/manifest.json` 的 23 个当前条目作逐面底稿。书写、天文、狮身人面像、陵墓、神庙、地震、旱灾优先使用经上一轮核对的 `-hd-v3` 增强图。其他 16 面目前是保真重采样和轻度锐化。资源验收以原画轮廓、角标、色带和最小实际尺寸为准，大文件尺寸本身不算清晰度证据。
- 优先补核农业、圣龛、阶梯金字塔、战争和葬礼的低分辨率原件，并排比对尼罗河和洪水。找到足够清晰的同版来源后优先使用，逐张核对类型、原图和图标。允许每面保留一份最高可用底稿和一份运行导出，所有引用同一面 ID。现有增强图经运行压缩后长边约 400 px，后续按实际显示尺寸、设备像素比和清晰度决定导出规格。
- 运行目录已精简。核对路径、大小、哈希、来源和运行引用后，退役了八张根目录旧占位图 `god.webp`、`nile.webp`、`obelisk.webp`、`pharaoh.webp`、`pyramid.webp`、`relief.webp`、`religion.webp`、`writing.webp` 和旧角饰 `table/player-board.webp`，共 118,052 字节。同步更新运行清单，保留外部底稿和已冻结发行文件。
- 七个旧重采样备选仍被审阅清单的 `previous` 和旧审阅页引用，待迁移引用后再复核可删除的衍生副本。保护出版方原件、馆藏原件、裁切溯源、当前选定底稿、现有审阅记录和旧版发行文件。清理不按目录、扩展名或文件尺寸批量删除。素材入口见[本地原件与审阅](sources.md#本地原件与审阅)。

## 玩家板布局

每席玩家查看自己的完整玩家板。电脑管理端按席展示公开摘要，包括可用圆盘正面、已用圆盘蓝色背面和分组持有石板，公共拍卖区和各席摘要同屏。玩家端的「其他玩家」复用公开摘要。分数、时代计分明细和已用圆盘沿用[现有权限](spec.md#tablemax-的公开与恢复约定)。

| 左侧保留区 | 中轴圆盘 | 右侧时代区 |
| --- | --- | --- |
| 纪念物、法老、尼罗河 | 2／3 人局每席 4 盘，4／5 人局每席 3 盘，区分可用与已用 | 神明、黄金、文明、洪水 |
| ∞ 保留图标，仍受相应灾难影响 | 只在第三时代计分的沙漏标记 | 弯箭头，时代结算后弃置 |

本人端常态显示所持圆盘、持有的石板和本时代预期收益。重复板块按牌面合并显示数量。长按或用键盘打开相应的放大计分图，图示取自原有实体版对照设计。「其他玩家」与拍卖记录在折叠时可并排。灾难取得后按现有流程处理，拉板块走公共轨。

预期收益表示按当前持有石板立即结算时的分数变动。预估和正式结算复用石板计分、法老比较及累计分下限。灾难待处理时暂停显示预估。第三时代公开持牌计算仅包含石板，圆盘单独结算，以保持其他席已用圆盘的秘密。收官后查看已保存的结算。

## 竞拍与结算

公共桌面为拉轨和状态提示预留空间。发起者、出价、最高价和跳过显示在对应座次。管理端卡片可悬停、聚焦或点按查看原尺寸比例的石板，密集持有区从卡片按需展开，上一场拍卖另有浮层。终局沿原座次显示排名、总分和同分决胜盘，前三使用金、青釉银和赤铜边框。

本人操作区提供抽取石板、立即拍卖及使用神迹。两个主动拍卖分支在按钮附近提示差异。神迹从拍卖行选定并确认具体槽，灾难沿用应弃石板确认。电脑管理端播放公共音效和桌面演出，玩家端采用轻量视觉反馈。声画根据已保存事件驱动，跟随对局、分支和修订。

原创封面沿用已审定的 WebP。23 张游戏石板保留现有文件与像素。8 段音效以 FLAC 储存，解码后的 PCM 与 WAV 母版逐采样一致。打包使用实际生产资源单元和项目 ZIP 编码器核对。封面和音频合计 87,442 字节，作为实际资源预算记录。[新版展示](../../../artifacts/maintenance/ra-table-polish-20261117/index.html)

## 实现与验收

1. 类别、去留、时代与得分符号由可缩放矢量图和布局绘制。以实物板的左右顺序、同异类计分以及洪水门槛作依据。手机的圆盘移到上方，牌池总数和中文规则可从图例展开。
2. 先做双端同一桌面的配色与 23 面检查。手机以 390×844 及项目支持的最窄竖屏检查，电脑以 1280×720、5 席满桌和短屏检查，同时核查键盘、触屏和缩放。审阅图包含清晰度不足的原尺寸对照，并记录对应版本。
3. 实际游戏验收覆盖拍卖到正确归位、纪念物两套计分、洪水从无到有与时代交接后重新归零、旱灾先清洪水、战争和地震确认弃置、各席本人结算与第三时代终局。对照保存结果及恢复后的界面。验收素材和画面以当前运行出处、版本及权限为准。
4. 用户要求每轮制作都由 agent 打开实际渲染截图，比对同一区域的实体板图。记录电脑缩略板、手机完整板和计分区近景。重点核对类别徽记、分值牌轮廓、每档的顺序、沙漏、字重和底色。纪念物的同类与异类分列在各自的竖向档位，正文式横排公式会在手机折行并改变实体图示的读法。目视结论随场景检查记录。

本轮独立视觉复核逐张打开手机和电脑的实际对局、玩家板与纪念物近景，对照第三印的整板图和两张官方局部照。验证纪念物两组共六行的竖排结构、计算徽记、沙漏、去留标识、河流条件和分值牌。第二轮对照确认比较徽记与冒号之间留有间隔，并检查了手机移到板顶的圆盘位。

本机回环源码服务使用 SQLite 保存和 Socket.IO 通信。Edge 实测在电脑 1280×720、手机 390×844 完成两席受控对局，覆盖出价换盘、地震弃置、洪水激活与时代清除、重载和第三时代终局。独立 agent 打开实际的管理端和手机截图，对照实物板核对了纪念物和河系图示。另实测拉板块推进时太阳船滑动、减少动态模式直接换位、长按和键盘打开计分图，以及预期分随灾难和时代更新。五席公开摘要同屏，320×568 无横向溢出。相同持牌状态下，390×844 手机本人区由约 771 压缩为 497 CSS 像素。证据在 `artifacts/maintenance/ra-tile-forecast-20261117/live-r1/result.json`，离线展示在素材工作区的 `exports/ra/tablemax-tile-forecast-demo.html`。
