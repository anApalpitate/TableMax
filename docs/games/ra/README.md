# 太阳神｜背景与接入调查

2026-11-16，用户确认《太阳神》（Ra）为 TableMax 下一款制作游戏。采用 25th Century Games 英文普通版第三印的 2–5 人基础游戏。开发入口见[规则与开发规格](spec.md)，原文、逐项对照和本地资料见[来源与核对表](sources.md)。

## 出版沿革

Reiner Knizia 设计，Franz Vohwinkel 绘制早期版本。1999 年《Ra》与《Chinatown》同为 Ravensburger 旗下 alea 的首批作品。《Ra》同年已有 Rio Grande 英文版，并在德国游戏大奖获得第二名。作者目录列有 2005 年 Uberplay、2009 年 Abacus／Rio Grande、2010 年新天鹅堡中文版、2016 年 Windrider 英文版。25th Century Games 2022 年发起重制众筹，由 Ian O’Toole 重绘，作者目录亦登记同系原石中文版。另有 Codito 2010 年 iOS 改编，可追溯发行，当前可用性未核定。[出版证据](sources.md#出版沿革与版次)

新版将拍卖行、太阳船和时代进度放在公共板上，玩家板用图标区分跨时代保留、时代后弃置和最终结算。豪华法老版的木板块和金属记分筹码可用于观察实物质感。Traders 扩展另加贸易板块，本规格覆盖基础游戏。[版本定位](sources.md#出版沿革与版次)

## 古埃及题材

拉（Ra／Re）的太阳每日重生，白日乘船过天，夜间穿越冥界。这个循环关联古埃及对宇宙秩序 *ma’at* 的理解。太阳神形象会随场合而变，拉－哈拉赫提可用鹰首识别，底比斯祭祀又有阿蒙－拉等合神形式。阿芬穆特木碑同时画出太阳船、东西方标志和祭祀者，适合核对主视觉中的太阳符号、色带与层级。太阳神题材可用于时代推进与开拍提示，规则判读依靠文字、形状和位置。[太阳神与木碑](sources.md#历史与视觉证据)

古王国的王权、太阳崇拜与金字塔建筑相互关联，中王国重新统一后发展出新的行政与艺术表达，新王国的底比斯神庙与王家墓葬则突出神庙祭祀和来世观。这三段是理解题材的史学坐标。基础规则三时代共用一袋板块，作品允许早晚不同时期的建筑和图像在同一时代出现。可给资料页中的具体器物标注年代，游戏界面保留规则书的第一、第二、第三时代。[三个王国](sources.md#历史与视觉证据)

尼罗河定期泛滥与耕作密切相关，粮仓模型还留下计量、记账、纸草和书写板的视觉线索。规则把这一关系压缩为洪水激活尼罗河计分、旱灾优先移除洪水。宗教、书写、农业、天文、艺术为五种文明套组；纪念物的八个品种造型差别较大，适合用阶梯轮廓、尖顶、方尖碑、神庙柱廊等剪影提升手机识别度。[尼罗河及文明证据](sources.md#历史与视觉证据)

## 机制与数字化判断

- **拍卖的两种价值**。抢到的是整行板块和中央太阳圆盘。赢家把自己的出价盘交给公共板，收到的盘在这一时代停用。因此一笔出价同时影响本次套组、本时代剩余出价次数，以及下一时代的竞价强度。手机端应同步预览板块与「付出／带入下时代」两枚盘。
- **时间压力**。抽到普通板块时拍品增加，拉板块则推进时代并可能马上开拍。同一列可因所有人跳过而保留或清空，取决于触发条件。最后一张有效拉板块直接进入计分；此时即使拍品丰厚也无法竞价。界面持续显示拍卖行、距结束还需几枚拉板块和当前行动席。
- **跨时代投资**。法老、尼罗河和纪念物累积，洪水、文明、黄金和神明等每时代重置。法老看全桌相对数量，文明看不同种类，纪念物在末时代同时计同种数量与不同种类。终局还要比较个人全部太阳圆盘的点值总和。因此同一批拍品在三个时代有不同边际价值。
- **状态与权限**。服务器保存随机袋序、拍卖发起席、顺时针游标、最高出价、临时出价盘、灾难处置和时代结算。公共区可以显示已揭板块、公开圆盘和持有状态。当前分数与计分明细按本人可见投影，终局揭示。管理员使用公开投影。
- **动作与恢复**。出价、跳过、逐次神明换取和有选择的灾难弃置都可能形成决策点。抽取与揭示同一权威动作提交，回退复原袋序和效果；出价历史及拍卖原因随存档恢复。只剩一名有盘玩家时仍让该席自行抽取、喊拍或换取。只有强制且唯一的机械步骤可自动推进。
- **人机切入**。三档策略按同一合法动作接口处理。先验证能否区分三种拍卖原因、识别强制出价和处理灾难；进阶再评估当前套组边际分、集中清场风险、中央圆盘未来价值和公开拉轨。策略只使用该席合法可见数据。

## 美术审阅与后续核验

外部素材工作区收录逐件透明 PNG、实物组件图、画师作品、规则图示和 The Met 开放馆藏。新版 HTML 支持离线浏览、逐图放大、单张下载、标记不合格、备注和导出。出版方与画师素材用于对照和审阅，运行素材采用另行确认。路径、原始地址、用途和 SHA-256 见[素材入口](sources.md#本地原件与审阅)。

实际游戏的电脑管理端使用暖灰石桌面和每席公开摘要，手机竖屏采用浅石灰岩。本人端显示持有石板与本时代预估，长按石板查看放大的第三印计分图示，见[配色、石板与玩家板](visual-design.md)。桌面、持有区和弃置选择以画面识别石板，牌名保留为无障碍名称。23 张石板、7 张配件和 17 枚太阳圆盘的源文件与授权状态见[运行清单](../../../assets/games/ra/manifest.json)。发行商衍生素材的分发授权待确认。

源代码验证和实际页面截图入口见[实现与验收](visual-design.md#实现与验收)。更广的规则边界见[验收矩阵](spec.md#最小验收矩阵)。取得第三印原始附件后仍需复核印刷图表和源文件哈希，实体设备与安装包验收另走相应入口。
