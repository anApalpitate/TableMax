## 规则原文

- **RA-R1** [25th Century Games《Pharaoh Edition》英文规则公开镜像](https://bghub.org/r/ra.pdf)。8 页，印刷署名为 Knizia 1999–2025，PDF 封装来自镜像。p1 配件，p2 设置，p3 行动及拉轨，p4 拍卖和灾难，p5 开始新纪元及终局太阳圆盘，p6–7 分类计分，末页速查。用作本轮已核正文。
- **RA-R2** [发行人上传的普通版第三印与豪华版第二印英文规则](https://boardgamegeek.com/filepage/256798/english-edition-rulebooks-25th-century-games)。发行人 Chad Elkins 在 2025-04-18 回复重印调整措辞，规则未改。已读文件页及回复；下载未取得，因此未把 RA-R1 的文件标成该第三印，也未以评论取代逐条印次比对。
- **RA-R3** [2016 Windrider KN27 英文规则（Asmodee）](https://images-cdn.asmodee.us/filer_public/4b/69/4b694353-dfc0-47c1-aca1-68c18597145a/kn27_ra_rulebook_eng.pdf)。用于对照公开拍卖、实体拉轨和分类计分。在 p6 法老条目第二句把最低并列误写为最高，并列扣分按其条目第一句、全等分支以及 RA-R1 的明确表述理解。此订正只记录到研究层。
- **RA-R4** [1999 alea 德文规则公开镜像](https://www.ggnf.de/spielanleitungen/ra/ra.pdf)。保留早期术语、太阳圆盘分配与时代对照，首版 3–5 人和后版 2–5 人设置分开核对。
- **RA-R5** [Hobby World 2023 俄文规则](https://media.lavkaigr.ru/uploads/ra_rules.pdf)。有 Ian O’Toole 版组件和流程图，p4 与末页可交叉核对三类开拍后的过牌结果。不同语言和印次的措辞以各自文件为准。

## 基础游戏数据与边界

RA-R1 p1 的基础袋为 180 枚。文明 25（5 种各 5）、纪念物 40（8 种各 5）、神明 8、黄金 5、拉 30、法老 25、尼罗河 25、洪水 12、灾难 10（战争 4、地震 2、葬礼 2、旱灾 2）。文明包括艺术、宗教、书写、农业和天文。纪念物包括狮身人面像、金字塔、方尖碑、雕像、陵墓、圣龛、神庙、阶梯金字塔。中文暂译以原版图像和同版英文核对。

中央起始圆盘为 1。每席起始两枚 5 分记分筹码，起始盘按玩家板随机分组，本时代由持有最高圆盘的席位先行动。以下按 RA-R1 p2 图表转写。

| 人数 | 起始太阳圆盘组 |
| --- | --- |
| 2 | 9／6／5／2，8／7／4／3 |
| 3 | 13／8／5／2，12／9／6／3，11／10／7／4 |
| 4 | 13／6／2，12／7／3，11／8／4，10／9／5 |
| 5 | 16／7／2，15／8／3，14／9／4，13／10／5，12／11／6 |

执行顺序按 RA-R1 p3–5。

| 状态 | 核对结论 |
| --- | --- |
| 普通抽取与拉轨 | 普通板块补最左空位，拍卖行满时不能抽取；抽中拉推进太阳船，抵终点立即结算，否则启动拍卖。新版支持另一面直接放拉板块。 |
| 抽中拉后开拍 | 全部可跳过。无人出价时拍卖行与中央盘保留。 |
| 主动喊拉、拍卖行已满 | 全部可跳过。无人出价时弃掉拍卖行，中央盘保留。 |
| 主动喊拉、拍卖行未满 | 前面无人出价时发起席须出价；已有出价时发起席也可跳过。原文没有另写空行禁令；空行主动换盘按字面推导，列入同印次复核。 |
| 拍卖与换盘 | 发起席左手第一位顺时针开始，每席出价或跳过一次，发起席最后。只有正面朝上的圆盘可出，报价须严格高于当前最高。赢家全收拍品及中央盘，收得的盘翻面，自己的中标盘成为中央盘；其他盘退回。其后从发起席左手续回合。 |
| 神明与灾难 | 使用一枚已有神明板块可取走一枚非神明拍品；可连做，每次独立结清。板块入手后才触发灾难，按类弃至多两枚；旱灾先洪水后尼罗河。多个灾难先后次序与同类可弃选择列入定案。 |
| 时代交接 | 全部圆盘用尽或拉轨走到底时结算。清公共拍卖行，中央盘留位。玩家保留法老、尼罗河、纪念物；弃洪水、黄金、神明、文明。翻开玩家圆盘，下一时代由最高盘持有者开始。 |

计分按 RA-R1 p5–7。每时代把本次各项对分数的净变化计入累计，结算后最低为 0。

| 项目 | 结算 |
| --- | --- |
| 法老 | 每时代最多 +5、最少 −2，并列同奖惩，全同数则都为 0。 |
| 神明／黄金 | 每时代未使用神明每枚 +2，黄金每枚 +3。 |
| 洪水／尼罗河 | 每时代洪水每枚 +1；至少一枚洪水时尼罗河也每枚 +1。 |
| 文明 | 每时代 0 种 −5，1／2 种 0，3／4／5 种 +5／+10／+15。 |
| 纪念物 | 第三时代，同一种 3／4／5 枚 +5／+10／+15，逐种累计；不同类型 0–6 种按种数计分，7／8 种 +10／+15。两部分叠加。 |
| 太阳圆盘与胜负 | 第三时代个人正反面圆盘合计，最高 +5、最低 −5，并列同奖惩，全同值则都为 0；中央盘无所属。最终总分并列时比较各并列者持有的最高单枚盘。 |

仍需核对的细节包括普通版印次中空拍卖行喊拉、多个灾难结算顺序、拉船/板块两面在各人数的终止格换算，以及弃置区公开程度。短版手册的流程图和现代图标作为校验副本，避免把旧版的说明句当成新版定稿。
