## 规则原文

- **RA-R1** [25th Century Games《Pharaoh Edition》英文规则公开镜像](https://bghub.org/r/ra.pdf)。8 页，印刷署名为 Knizia 1999–2025，PDF 封装来自镜像。p1 配件，p2 设置，p3 行动及拉轨，p4 拍卖和灾难，p5 开始新纪元及终局太阳圆盘，p6–7 分类计分，末页速查。用作本轮已核正文。
- **RA-R2** [发行人上传的规则文件页](https://boardgamegeek.com/filepage/256798/english-edition-rulebooks-25th-century-games)。其列普通版第三印 `Ra Rules RETAIL v17 ART`、豪华版第二印 `Ra Rules DELUXE v12 ART`。Chad Elkins 于 2025-04-18 回复，重印仅调整措辞。普通版第三印的实体身份为 2025 年英文 TFC20000，[版次档](https://boardgamegeek.com/boardgameversion/781044/25th-century-games-english-retail-edition-third-pr)抄录盒底 Third Printing。BGG 原始附件当前返回 403。
- **RA-R3** [2016 Windrider KN27 英文规则（Asmodee）](https://images-cdn.asmodee.us/filer_public/4b/69/4b694353-dfc0-47c1-aca1-68c18597145a/kn27_ra_rulebook_eng.pdf)。用于对照公开拍卖、实体拉轨和分类计分。在 p6 法老条目第二句把最低并列误写为最高，并列扣分按其条目第一句、全等分支以及 RA-R1 的明确表述理解。此订正只记录到研究层。
- **RA-R4** [1999 alea 德文规则公开镜像](https://www.ggnf.de/spielanleitungen/ra/ra.pdf)。保留早期术语、太阳圆盘分配与时代对照，首版 3–5 人和后版 2–5 人设置分开核对。
- **RA-R5** [Hobby World 2023 俄文规则](https://media.lavkaigr.ru/uploads/ra_rules.pdf)。有 Ian O’Toole 版组件和流程图，p4 与末页可交叉核对三类开拍后的过牌结果。不同语言和印次的措辞以各自文件为准。
- **RA-R6** [普通版 RETAIL v17 ART 公开阅读镜像](https://www.scribd.com/document/1007837203/Ra-Rules-RETAIL-v17-ART)。第三方转载的规则正文，题名与 RA-R2 一致，正文末页前有 1999–2025 版权及相同制作者署名。已读 p1–7 和速查页，分页图表的数字未完整转成文本；身份有交叉证据，原始附件 SHA 仍待取得。零售商标出的旧 [Google Drive 入口](https://morethanmeeples.com.au/product/ra-board-game-standard-edition/)返回 404。发行方普通版商品页只提供实物图和介绍。
- **RA-R7** [较早的英文实体规则镜像](https://fgbradleys.com/wp-content/uploads/rules/Ra%20-%20rules.pdf)。开局段与时代末段给出八个拍卖槽、各人数的拉板块阈值、空行成交和灾难类别对应。用作印刷图表与项目裁定的旁证。其早期组件名、展示和其他约定不覆盖新版。

## 普通版第三印与豪华法老版逐项对照

已逐项比对 RA-R6 的可读正文和本地 RA-R1。下表的「一致」指行为与数值口径，印刷图表和原始附件核验缺口分别标明。RA-R1 封面带 Pharaoh Edition，内文版权为 1999–2025。该文件来自镜像，RA-R2 的 DELUXE v12 身份仍待原附件核验。

| 页／条 | 普通版第三印与已收集豪华法老版 | 开发结论 |
| --- | --- | --- |
| 封面、p1 实物 | 组件类型与可读数量一致。普通版为纸板拍品，豪华法老版有木质拍品与金属记分筹码，外盒及配件视图有版别。 | 采用普通版身份，素材逐项标注实际来源。实体材质不影响玩法。 |
| p1 板块构成 | 文明、纪念物、神明、黄金、拉、法老、尼罗河、洪水及四类灾难名称和可读数量一致。记分面值与数量一致。 | 建立固定 180 枚袋数据与整数账本。 |
| p2 公共设置 | 中央盘 1、首时代标记、全部板块入袋、每席两个 5 分、太阳船从人数位出发、玩家板两面一致。 | 首版用太阳船，另一面只改变呈现。 |
| p2 人数与图表 | 镜像能读人数和 1–9／1–13 范围，普通版图内圆盘数字与轨格尚未逐格取得。豪华 p2 和 RA-R3 的分配表互证。豪华船面起点索引为 4／2／1／0，终点为 10，与 RA-R7 的 6／8／9／10 次及 8 个拍卖槽吻合。 | 取得原 PDF 后复验两组印刷图表。 |
| p3 轮次、首席和耗尽 | 三时代、最高盘首席、顺时针、无正面盘跳过、剩一有效席仍按三种行动继续，均一致。 | 封装统一的可用盘轮转。 |
| p3 普通抽取与拉 | 普通牌补最左空格，满格禁抽；拉推进，未到末格拍卖，到末格立即结算。主动喊拉不推进。 | 禁止把满第八格视作自动开拍。 |
| p3 神明 | 可逐枚花费，也可一次行动内重复；换得非神明，灾难立即处理，逐笔完整结清。 | 保留连用或结束的决策点。 |
| p4 竞拍顺序及价格 | 发起者左手开始，顺时针一轮，发起者最后；一人一次、后一价严格更高。 | 合法动作绑定竞拍游标、可用盘和阈值。 |
| p4 三种过牌与换盘 | 抽拉全过保留拍卖行；主动喊满全过弃行；主动喊未满，无他人出价则发起者必须出价。赢家取得整行和中央盘，旧中央盘翻面，赢家出价成为中央盘。 | 空行属于未满，赢标只交换盘，由 RA-R7 明文旁证。下轮从发起者左手续行。 |
| p4、p7 灾难 | 先得标再处分。每枚按类别弃至多两枚，旱灾优先洪水，随后弃灾难。原文未规定同批灾难精确排序。 | 从左到右逐枚处理，同类真实选择交玩家。RA-R3 对类别与选择权有明确示例。 |
| p5 两种时代结束和改朝 | 圆盘用尽或拉进末格，计分后清空规定区域，保留中央盘，翻开玩家盘并重置拉轨。 | 最后一拍的灾难在计分前处理。 |
| p5 筹码秘密、下限与胜负 | 记分筹码隐藏，累计分每时代最低 0。第三时代结算双方极值，盘总值全等为 0；终局平分用最高单盘。 | 每时代净额累加后截零，非终局分数按私人投影。 |
| p6 纪念物、法老、尼罗河 | 纪念物两套计分同取，法老同极值全奖／惩、全等不变，尼罗河需洪水。 | 实现独立快照计分。 |
| p7 神明、黄金、文明、洪水 | 各分值、不同文明种类与空文明罚分一致。灾难目标与板块视觉的映射由 RA-R1 图标及 RA-R3 补证。 | 计分数字转入规格与矩阵。 |
| 末页速查 | 抽取、喊拉、神明、三种开拍及过牌逻辑一致。 | 用作正文核对，无额外规则。 |

发行人声明与可取得的正文支持采用普通版第三印。原件取得后要补核封面印次、p2 画内起始盘及人数标记、p5–7 图中分类和部件肖像，并确认文件 SHA。TableMax 的灾难处理顺序、并发、持久化及私域输出见[规则规格](spec.md)，按项目约定标识。

## 本地原件与审阅

下列路径以 TableMaxMaterial 工作区为根。

- `exports/ra/art-review-components.html` 是本轮离线审阅页。原审阅页和它在本浏览器中的标记可继续通过 `exports/ra/art-review.html` 打开。
- `work/ra/component-review/manifest.json` 记录 48 张独立透明 PNG，包括 23 种板块、13 枚圆盘、4 种筹码和 8 项板件、配件及装饰。逐项记录规则页码、对象引用、实际尺寸、透明通道与 SHA-256。圆盘 14–16 在已取的 PDF 中只有图表数字，游戏开发可用圆盘底图与真实数字布局处理。第三时代标志印在公共板。
- `originals/ra/manifest.json` 记录原始规则、普通版实物图片和开放馆藏。`originals/ra/ian-otoole/manifest.json` 记录新增的画师作品集公开图。普通版产品盒背为 TFC20000，标注 1999–2022，作为普通版视觉旁证。第三印的官方单独美术包与明确印次照片尚未取得。
- 出版方、画师图及规则拆图为本地审阅参考。The Met 图片逐件标记 CC0。HTML 的每项下载为该条目清单所列文件的原字节。
