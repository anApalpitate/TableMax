# 太阳神｜规则与开发规格

采用 **25th Century Games 英文普通版第三印（2025，TFC20000）** 的 2–5 人基础游戏。游戏 ID `ra`，规则版本 ID `25cg-retail3-base-v1`。版次由发行人文件记录、零售版次目录和 RETAIL v17 可读正文确认。启动开发以本规格为基线，原始 PDF 取得后按[逐项对照](sources.md#普通版第三印与豪华法老版逐项对照)核对实际文件与排版。首版采用有太阳船的表达，两面棋盘映射到同一计数。Traders、骰子版和自订变体另列版本。

## 配件数据与设置

| 类型 ID | 子型及数量 | 时效 |
| --- | --- | --- |
| `ra` | 30 | 抽取时推进时代轨，从袋移出，永远不进拍卖行 |
| `god` | 8 | 可逐枚兑换。余下者每时代结算后弃 |
| `gold` | 5 | 每时代结算后弃 |
| `pharaoh` | 25 | 跨时代保留 |
| `nile` | 25 | 跨时代保留 |
| `flood` | 12 | 每时代结算后弃 |
| `civilization` | 艺术 `art`、宗教 `religion`、书写 `writing`、农业 `agriculture`、天文 `astronomy`，各 5 | 每时代结算后弃 |
| `monument` | 狮身人面像 `sphinx`、金字塔 `pyramid`、方尖碑 `obelisk`、雕像 `statue`、陵墓 `mortuary`、圣龛 `shrine`、神庙 `temple`、阶梯金字塔 `step-pyramid`，各 5 | 跨时代保留，第三时代结算 |
| `disaster` | 战争 `war` 4、地震 `earthquake` 2、葬礼 `funeral` 2、旱灾 `drought` 2 | 赢得或换得时处理 |

开局将 180 枚板块一次洗袋，三个时代共用余袋，弃置不回袋。服务器给每枚实体板块唯一内部 ID，以类型与子型标识规则，外观变体可以共用规则键。拍卖行固定 8 格，左到右编号 0–7。太阳圆盘面值即盘 ID，每个面值最多一个。中央第一个盘为 1。每人初始 10 分，仅在实体表现中对应两枚 5 分筹码。规则手册另列 1／2／5／10 分筹码各 15／25／25／15 枚，数字账本直接记录整数分。

| 2 | 9／6／5／2，8／7／4／3 | 6 |
| 3 | 13／8／5／2，12／9／6／3，11／10／7／4 | 8 |
| 4 | 13／6／2，12／7／3，11／8／4，10／9／5 | 9 |
| 5 | 16／7／2，15／8／3，14／9／4，13／10／5，12／11／6 | 10 |

按座顺固定顺时针环。把第 1 时代的圆盘组整体随机分给所有座位，圆盘全部可用。每个时代的 `raDrawn` 从 0 起；第 k 枚使其变为 k，达到表中阈值立即结束。最高值的**玩家持有**圆盘确定每时代首行动席，中央圆盘排除。初始化后记录开局检查点及固定的袋序和圆盘归属。

## 状态与命令

服务端持有规则版本、时代 1–3、座序、当前阶段、袋序、公共 8 格、拉计数与阈值、中央圆盘、各席的可用／已用圆盘和持有板块、分数、弃置、拍卖游标与出价、灾难队列和续行位置。持久化状态需可重建视图、合法动作及所有待决分支。命令名是模块接口建议，复用平台 SDK 的命令封装、座位与版本校验。

| 阶段 | 决策方 | 命令和合法条件 |
| --- | --- | --- |
| `turn` | 当前有可用盘的座位 | `draw` 需有空槽；`invokeRa` 可在空行、未满、已满时用；`spendGod(godId, slot, tileId)` 需本人神明和有效非神明拍品 |
| `auction` | 顺时针当前竞拍席 | `bid(disk)` 一枚本人可用且比当前最高盘严格大的圆盘；`pass` 受拍卖原因限制 |
| `godChain` | 本次发动神明的座位 | 可继续 `spendGod` 或 `finishGod`，无剩余合法兑换时自动结束 |
| `disaster` | 受到灾难的拍品获得者 | 有实质选择时 `discardForDisaster(disasterId, tileIds[])`，选足合法应弃数量 |
| `ended` | 无 | 终局只读。平台再玩按既有新局流程 |

### 行动与拍卖

1. 抽普通板块放入**最左空槽**。从行中间拿牌后保留空洞。填满第 8 槽仍完成普通行动，下一席可喊拉或使用神明。
2. 抽到「拉」时移出该板块，拉计数加一。达到阈值时直接进入时代结算，取消这一枚可能触发的拍卖。其他情况下以 `drawRa` 开拍，主动喊拉不开动拉轨。
3. 主动喊拉按开拍时拍卖行是否满标记 `invokeFull` 或 `invokeOpen`。拍卖对象恒为当时的全部拍品与中央圆盘，期间禁止抽取或神明兑换。未满包含零张，当规则允许成交时只交换中央圆盘。
4. 从发起席下一座开始，按顺时针遍历一轮，发起席最后一次参与。已无可用盘直接跳过。出价越过当前最高值，首价任意，不能加码第二次。非发起席始终可过。
5. `drawRa` 全过则行与中央圆盘原样保留。`invokeFull` 全过则弃整行并保留中央盘。`invokeOpen` 若轮到发起席仍无出价，该席必须任选合法盘出价。已有出价时发起席仍可过。
6. 最高者赢得整行板块。临时出价保留或标记为占用，确认赢标时只扣赢家该盘并把它翻为中央公开盘，旧中央盘归赢家并标记本时代已用，其他盘全部恢复可用。先给赢家全部非灾难拍品，再由赢家处理拍得的灾难。拍卖后从**发起席**下一座继续轮转，跳过无可用盘者，赢家位置不决定下轮。
7. 单一有效席可连续行动，也可发起并参与拍卖。若满行喊拉后本人选择过，清行后仍可行动。全部可用盘消耗，先结清当前拍得的灾难，再结算时代。无耗尽且无竞争时保留玩家的抽取、喊拉或神明选择。

### 神明与灾难

一次神明动作至少花一枚本人已有的神明，移出该板块并将选中的非神明拍品从原槽转入自己的区域。选中灾难立即处理。每次兑换完全结清才可继续，第二次起可主动结束，可用太阳圆盘数量不因兑换减少。命令中目标槽同时绑定预期板块 ID，避免页面过期时拿到后来填入的板块。

每枚灾难处理一个类别，按可用数量弃 0–2 枚，再移出灾难本身。战争弃文明、地震弃纪念物、葬礼弃法老、旱灾弃河流。旱灾先按 `min(2, floodCount)` 弃洪水，再用尼罗河补足；同类相同子型可以按稳定 ID 自动弃足。拍卖拿到灾难时整个中奖批次已入账，刚赢得的板块也是候选。多枚灾难按原拍卖槽号从左到右依次处理；同一类别多次检查剩余数量。这个顺序是数字化约定，各灾难的目标类别互斥或相同。

在战争、地震存在会改变持有子型数量的不同合法选择时，等待该玩家确认。所有选择得到相同子型组合时自动处理，弃置内部身份按稳定 ID 选取。竞拍席无合法出价且允许过牌时自动过牌，仍记录竞拍结果。强制出价只剩唯一面值时自动出价，其余强制出价由持盘者选择面值。

### 计分与时代交接

用时代结束时的公开资源快照计算所有席位的当时代分项，再一次性记入累计分。比较类取同一快照的极值，同值共享完整奖励或惩罚。每席 `nextScore = max(0, oldScore + sum(breakdown))`，分项顺序不改变结果。

| 类别 | 第 1／2／3 时代 |
| --- | --- |
| 法老 | 数量最多 +5、最少 −2；全等皆 0 |
| 神明 | 未花每枚 +2 |
| 黄金 | 每枚 +3 |
| 河流 | 每枚洪水 +1，有至少一枚洪水时每枚尼罗河 +1 |
| 文明 | 不同子型数 0／1／2／3／4／5 分别为 −5／0／0／5／10／15 |
| 纪念物 | 只在第三时代。每一子型数量 0／1／2／3／4／5 分别为 0／0／0／5／10／15；再加不同子型数 0–6 对应的种类数分，7／8 种 +10／+15 |
| 太阳圆盘 | 只在第三时代。本人正反两面盘面值合计，最大 +5、最小 −5；全等皆 0，中央盘排除 |

第 1、2 时代结束后弃去拍卖行和各席洪水、文明、黄金、神明，法老、尼罗河、纪念物保留。中央盘原位，所有玩家圆盘恢复可用，拉计数归零。时代加一，以玩家持有的最高盘选首行动席。第三时代结算后保留终局投影的持有区与计分快照，将未拍出的行标记为未获，不计分。总分相同者比较自己持有的最高单枚圆盘（两面均计），盘独一无二，产生唯一赢家。

## TableMax 的公开与恢复约定

- 公共投影含时代、拉进度、8 槽内容、中央盘、各席可用的公开面值和已用盘数量、公开持有板块、当前发起与行动席、出价与已发生的公共事件。已经公开的换盘可随公开历史回看。当前阵列以背面和数量表示对手已用盘。本人可查看自己的累计分、本人结算分项和已用盘。
- 每时代比分与逐席分项在终局公开。进行中不向其他席、管理端、机器人或匿名 SDK 投影追加独立的对手分数、牌袋顺序、余袋内容、内部弃置池或未来随机数。公开动作历史可回看当局原本能观察到的板块、过牌与换盘。扣分下限产生的实际变动也按本人权限返回。
- 抽取、揭示与拍卖启动或结算在一次权威提交中保存。每次有效行动、出价、过牌、神明连用和灾难选择先保存再广播。需选择则允许从中间状态恢复。自动跳过、唯一弃置、时代计分在触发动作同次提交或同一自动推进链完成，回执重放无二次加分。记录袋序、公开槽、出价、灾难队列、连续行动续行、第三时代分项与获胜裁定。
- 检查点对应玩家可做选择的动作、竞拍、继续神明或灾难选牌之前。回退恢复袋序、玩家资产、分数和待决动作，恢复同一抽取结果。按平台协议隔离房主、换机、凭证与暂停管理。新局与存档绑定精确规则发行。
- 三档人机只接收当前座位投影和合法动作。拍卖、连用、灾难均走同一命令，验证轮转跳过、面值门槛和结算优先级。UI 保持拍卖行、中央盘和拉轨可见，移动端在竞拍面板一并展示可用面值、已公开最高值、可以跳过与否。

| 抽到拉、主动满行和主动未满 | 三种全过／强制分支各自正确，中央盘在无成交时原样。覆盖空行有成交、满行中间被神明取走、填到第 8 槽 |
| 多人竞拍及最后活跃席 | 出价严格升序，每席一次，全部未赢盘返回，只消耗一个可用盘，从发起者下一座续行。最后活跃席仍可行动 |
| 神明和灾难 | 连用至少一次，续用需重新选择，禁止神明换神明。覆盖灾难连出、刚赢入库、旱灾先洪水、0／1／2 枚受影响、玩家选择与自动弃置 |
