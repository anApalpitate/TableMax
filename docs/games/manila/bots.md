# 马尼拉独立本地策略

策略 `manila-local` 版本 `1.0.0`，适用于 `manila-classic-2005-v1`，提供 `default/doubao/juewu`。只用本人安全投影、规则枚举的合法动作和平台独立策略随机源；不联网、不调用名称对应的云端模型、不读取别人秘密股份、不知道未来骰子。无跨回合记忆，格式只接受 `null`，恢复不引入额外观察知识。

## 三档算法

| 等级 | 实际分析                                                                                                                                            |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| 默认 | 轻量合法收益比较：有限竞拍预算、购股、本人股份影响装船、船位边际分红、港口／修船坞命中、保险、海盗及领航。                                          |
| 豆包 | 用剩余 1–3 颗公平骰的完整和分布计算入港和恰 13 概率；港／坞数量用独立概率卷积；加入后续船员稀释与现金风险，依组合股份控制竞拍预算。                 |
| 绝悟 | 在相同授权概率基础上考虑剩余行情档数的购股价值、流动性、全部 600 起航配置、实际完整领航参数与抢占岗位；用公开同伙和已赎回股份的影响作有限阻断估值。 |

三档分别维护 `default.ts/doubao.ts/juewu.ts`；概率与公共局势估值在 `evaluation.ts`，统一策略入口只组装等级和处理取消／同分选择。解空间是当前合法动作的完整有限枚举，没有假定未来对手必走某一步的全局博弈树，也不宣称最优或保证更高胜率。未来领航与海盗选择只作估值近似；股份信息只保留当前授权公开数据，因此不利用已购买股份的历史追踪。计算预算仍由平台限制为每次 2 秒／32MiB。

## 逐节点覆盖

| 节点       | 动作与策略依据                                               | 空选择／放弃                               |
| ---------- | ------------------------------------------------------------ | ------------------------------------------ |
| 港务长拍卖 | 比较本人可支付出价与该档控制权预算；不质押未赢者             | 超预算退出                                 |
| 买股       | 现金留存、当前市价和剩余上涨价值                             | 不值得则不买                               |
| 装货与起点 | 600 种配置逐一算本人股份与货物收益                           | 始终有配置                                 |
| 派遣       | 当前各岗位完整合法参数，计算船员边际收益与各风险岗期望净收益 | 非正净收益可放弃后续派遣                   |
| 登船       | 比较免费船员收入、失去海盗分红与公开对手影响                 | 可留海盗船                                 |
| 大小领航   | 枚举一船／两船所有合法正负移动，比较本人及公开对手影响       | 空移动放弃                                 |
| 掠夺去向   | 按本人股份上涨、港／坞岗位、保险责任比较港或坞               | 每条待掠夺船均须选                         |
| 强制融资   | 只从本人可抵押股份选具体股；绝悟先考虑已公开股               | 抵押到足够后规则自动续付，无跳过／借还循环 |
| 自愿融资   | 有其他游戏选择时不无故借还；债务不会增加终局净值             | 选择实际游戏动作                           |
| 航次结果   | 港务长合法下一航次动作                                       | 终局不决策                                 |

同分只消耗平台策略随机源，规则骰子源与之隔离；开始已取消或遍历中取消立即中止，不提交动作。所有输出由平台再次进行权威合法校验与保存，不能驱动管理员生命周期动作。

验证定义见 [规则测试](../../../games/manila/rules/rules.test.ts) 和真实服务／Worker用例。逐节点边界与固定种子整局证明的是可运行和信息边界，不将少量对局胜负当等级强弱或平衡统计。
