# 马尼拉交互

采用规则与秘密边界以[规则规格](rules.md)及[安全投影](../../../games/manila/rules/view.ts)为准。网页入口为 [web/index.tsx](../../../games/manila/web/index.tsx)，只接受宿主授权投影、合法动作和保存反馈，不读取权威状态或网络凭证。

## 三端

- 主机：公开港湾、行情、商人资料与航次结果。菜单内使用平台管理、倒计时和主机显示设置；不生成玩家行动按钮。
- 公共屏：同样只展示公开信息，拥有独立显示设置。没有本人股份或玩家行动。
- 玩家：同一公开沙盘加本人秘密股份、抵押状态与可用现金。手机与电脑拥有相同决策权限；手机不显示电脑显示设置。

现金、股份张数及已公开股份来自公开投影；未揭示股份种类仅本人可见。赎回股份会公开，因此本人资料与公开商人资料都明确标记。规则与账本浮层不改变身份、修订或决策。

## 操作

竞拍使用受合法动作范围限制的整数出价，显示包含可抵押额度的上下限；超过现金的报价明确提示获胜后需选择抵押股份。最高报价与领先商人在三端阶段区持续显示，等待玩家不必滚到最近记录寻找当前报价。退出竞拍和放弃本航次派遣为明确命名的直接操作。购买股份、选伙伴岗位、海盗登船和掠夺先选择具体对象，底部固定确认列出动作、费用与目标，可取消。

伙伴岗位可以在沙盘上直接点击，也可从本人操作区的具体岗位选择。占用者显示稳定座号与实体棋子；只给服务投影列出的合法空位提供按钮。货船分红明确为整船分红池，按伙伴数均分；保险行明确表示立即收入与后续赔付风险。盲乘费用以现金加可贷额度为限显示，不能以正常票价误导。

装船分两步：三条航道各选一种不同货物，然后选择三船 0–5 格起点；总和不是 9 时不能确认。货物改为已有货物时互换对应航道，避免重复货物。提交动作必须与服务给出的完整合法配置匹配。

领航用每船带方向的格数选择保留草稿，显示草稿结果格或靠港、已用格数和总额度，可清空调整；核对合法动作后确认，真实沙盘保持已保存位置。海盗登船与送往港口／修船坞使用货物名称和目的地，不显示 JSON 或内部字段。

抵押与赎回列出具体货物、公开状态和现金变化。`financing` 阶段仅向付款本人展示待付金额、用途、本人现金及缺口，并展开本人可抵押股份选择；其他玩家保持等待，不拿自己的现金计算他人的缺口。用户逐张指定抵押品，资金足够后由规则继续原动作；界面不会代选抵押品。

付款本人的短手机先显示待付／缺口与用途／现金，再直接显示全部可用抵押股份，贷款完整说明置于选项之后。该阶段隐藏上方重复持股卡，并为右侧浮球保留空隙，让首屏可以完整操作至少一个抵押按钮；其他阶段与主机／公共屏保持原布局。

终局总财富与共同赢家均来自服务投影，财富相同显示相同名次，不以座位次序制造额外胜负。界面定向回归覆盖公开最高报价、付款／非付款玩家和经存档校验的受控同分终局；受控同分场景不算自然整局证据。

草稿绑定实例、分支和决策 ID。同步后失效决策的选择清除；暂停、断线、机器人错误和提交锁定时禁用行动。所有游戏提交继续使用宿主统一动作管道。

## 布局与反馈

电脑使用主沙盘与操作／行情侧栏。手机竖屏独立设计自下向上的三条航道，横屏将港湾与操作左右排布；按实际宽高重排，不以横滚电脑沙盘代替手机适配。伙伴、货物、起点、领航、登船及掠夺支持图形拖放，所有操作保留点击／键盘替代。图形落点只对应服务投影的合法参数，船舱仅为最低空费位，掠夺去向只选择港／坞大区。

拖放只建立草稿，确认显示具体对象、费用和目标后才提交；越界或pointercancel不选择目标，Esc取消拿起状态并释放pointer capture。屏幕旋转结束手势并保留有效草稿，决策、分支和实例变化清除旧选择，暂停／断线／提交锁定立即停止拖动。仅当前指针命中的合法区域强调高亮，同一岗位在船体与操作列表中重复出现时也仅强调命中的那一处；移动与松手共用命中判断，离开和手势结束立即清除。仅拖动对象接管触摸，其他区域保持正常滚动；按需展开的图文操作列表提供等价的具体岗位、装船和领航选择。

确认固定在底部安全区并按实际高度避让；现金、必要费用、风险、额度与当前目标直接可读，股份、行情与商人详细资料通过小图标点击或长按打开半透明卡片。外部点击、关闭按钮与Esc可收起；卡片不覆盖必要目标或确认。页面保留唯一纵向滚动和焦点边框，岗位、按钮和选择框不少于44px热区，不缩小字号。

只在宿主报告新的已保存变化时允许船移动、骰子落定与回执强调。完整同步、刷新与旧记录不会触发保存动效；测试模式、减少动态与暂停关闭装饰。最新结果持续显示，详细行情、商人资料与最近航次分红在账本按需打开。

规则入口使用平台顶层图文浮层，按目标、航次、岗位、海盗／领航、抵押分章；七组图解表达完整流程、起点和9、分红与港坞、保险、13格海盗、领航及贷款，具体数字与先后关系由代码排版，不增加强制教程。
