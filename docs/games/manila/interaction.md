# 马尼拉交互

## 信息精简与行动引导（2026-10-21）

玩家端删除“操作列表”及重复选择控件，以现有棋盘点击／拖放／键盘操作和具体对象确认完成动作。持仓合并为一处“查看股票”：逐张货物图卡及持有／抵押、私密／公开标记；正文无说明文字，完整名称及状态保留在可访问说明与按需提示中。它是只读入口，不提交金融动作。现有“抵押可借”区域独立打开股份抵押与赎回，是否可进入按当前合法金融动作判断，额度为0但可赎回时仍可用。强制付款继续在行动区原位选择抵押。

竞拍、装船、购股、派遣、领航、登船、掠夺及付款定位入口只在本人有合法决策且连接、运行及提交状态允许时强调。点击入口或标题与首个主要控件进入既有滚动区视野后停止呼吸，维持静态高亮至本次行动结束；按实例／分支／决策在内存中识别，普通重绘与旋转不重新提醒。明确点击才滚动定位并聚焦操作标题，不自动弹窗、选择或提交；暂停、断线、锁定及他人回合不播放引导。它描述当前操作状态，不是保存结果演出，不使用保存事件或音频。

航次收支仅在展示层隐藏为0的收入、支出、借入和赎回分项；期初／期末现金、收入／支出总计和净变化即使为0也保留，原始账本、计算和旧记录缺失提示不变。

## 航次公开收支与调位（2026-10-18）

每航次从竞拍前现金开始累计收入、支出和融资。普通及最终航次的已保存结果在三端棋盘上方显示可收起的页内收支卡，玩家本人优先，其余按座位排序。分类详情按需展开；卡片不抢焦点、不要求确认，不遮挡顶部下一航次入口。收入包括货船、海盗、港口、修船坞和保险入场；支出包括竞拍、购股、派遣与保险实付；借款及赎回单列。期末减期初现金等于收入减支出加借款减赎回，现金变化不等于最终财富或利润。

新账只保存有界金额分类，不增加股份ID或秘密货种的公开范围。缺账旧形状仅显示原结算变动，不补造全航次账目；下一航次从当时现金开始建账。旧正式存档仍固定原发行，不因源码改造换用新规则。刷新／恢复静态呈现已保存结果，同一结果重渲染保留折叠状态；回退到结算前移除卡片，最终航次保留收支及独立财富排名。

玩家宽度≤620px用竖向航道、上下箭头，其余用横向航道、左右箭头；主机／公共屏为横向。左／下后退，右／上前进；船图、指针命中、按钮及范围采用同一方向。当前操作航道只高亮起点0–5或当前其他船草稿下的合法领航格，不强调整条航道；非法区域松手不吸附合法端点。方向切换取消手势、保留有效草稿，44px触控和显式确认不变。

采用规则与秘密边界以[规则规格](rules.md)及[安全投影](../../../games/manila/rules/view.ts)为准。网页入口为 [web/index.tsx](../../../games/manila/web/index.tsx)，只接受宿主授权投影、合法动作和保存反馈，不读取权威状态或网络凭证。

## 操作

竞拍使用受合法动作范围限制的整数出价，显示包含可抵押额度的上下限；超过现金的报价明确提示获胜后需选择抵押股份。最高报价与领先商人在三端阶段区持续显示，等待玩家不必滚到最近记录寻找当前报价。退出竞拍和放弃本航次派遣为明确命名的直接操作。购买股份、选伙伴岗位、海盗登船和掠夺先选择具体对象，棋盘下沿内嵌行动位列出动作、费用与目标，可取消。

竞拍区按三行排列：标题与出价范围同行，带标签的金额输入单独一行，末行“出价／退出竞拍／股份操作”同高居中。股份入口仅在存在合法抵押或赎回动作时显示，不留下占位；金额、范围及超现金风险不因按钮缩短而省略。

伙伴岗位可以在沙盘上直接点击，也可从本人操作区的具体岗位选择。占用者显示稳定座号与实体棋子；只给服务投影列出的合法空位提供按钮。货船分红明确为整船分红池，按伙伴数均分；保险行明确表示立即收入与后续赔付风险。盲乘费用以现金加可贷额度为限显示，不能以正常票价误导。

装船分两步：三条航道各选一种不同货物，然后选择三船 0–5 格起点；总和不是 9 时不能确认。货物改为已有货物时互换对应航道，避免重复货物。提交动作必须与服务给出的完整合法配置匹配。

手机装船起点与领航均使用各航道固定位置的方向箭头调位（竖向上下、横向左右），每次一格；触控区为44px，不能移动的方向禁用。起点限0–5，允许调整过程暂时不合计9，只有完整合法配置才能确认。领航按合法动作检查总额度，显示草稿结果格或靠港、已用格数和总额度，可清空调整；核对后确认；调位中的船图显示唯一草稿位置，确认前不改变服务端位置。手机不再要求拖动起点或木船；电脑精确指针保留拖动及操作列表，键盘可操作箭头与选择框。海盗登船与送往港口／修船坞使用货物名称和目的地，不显示 JSON 或内部字段。

手机航道的空舱／在航／靠港／进坞／被掠夺状态集中到货舱清单牌，不再输出“等待装船”或“船员 N”整句；合法空位仍使用具体岗位和44px目标。玩家端以航道13刻度与海盗设施详情表达拦截条件，不显示旧浮动旗帜；点击船或岗位、确认领航、盗掠去向的原有规则不变。终局公开股份以货物图标、张数徽章和抵押蜡封显示，文本不再写“（抵押）”；秘密股份详情仍保留完整文字状态。

抵押与赎回列出具体货物、公开状态和现金变化。`financing` 阶段仅向付款本人展示待付金额、用途、本人现金及缺口，并展开本人可抵押股份选择；其他玩家保持等待，不拿自己的现金计算他人的缺口。用户逐张指定抵押品，资金足够后由规则继续原动作；界面不会代选抵押品。

强制付款保留棋盘和原滚动位置；顶部显示“需要付款／去处理”，只有点击才定位到内嵌付款区。付款区显示用途、待付、现金、缺口及本人抵押股份；抵押成功的股份原位更新为已抵押，不立即删除，长列表沿主滚动区展开。

终局总财富与共同赢家均来自服务投影，财富相同显示相同名次，不以座位次序制造额外胜负。界面定向回归覆盖公开最高报价、付款／非付款玩家和经存档校验的受控同分终局；受控同分场景不算自然整局证据。

草稿绑定实例、分支和决策 ID。同步后失效决策的选择清除；暂停、断线、机器人错误和提交锁定时禁用行动。所有游戏提交继续使用宿主统一动作管道。

拖放只建立草稿，确认显示具体对象、费用和目标后才提交；越界或pointercancel不选择目标，Esc取消拿起状态并释放pointer capture。屏幕旋转结束手势并保留有效草稿，决策、分支和实例变化清除旧选择，暂停／断线／提交锁定立即停止拖动。仅当前指针命中的合法区域强调高亮，同一岗位在船体与操作列表中重复出现时也仅强调命中的那一处；移动与松手共用命中判断，离开和手势结束立即清除。仅拖动对象接管触摸，其他区域保持正常滚动；按需展开的图文操作列表提供等价的具体岗位、装船和领航选择。

只在宿主报告新的已保存变化时允许船移动、骰子落定与回执强调。完整同步、刷新与旧记录不会触发保存动效；测试模式、减少动态与暂停关闭装饰。最新结果持续显示，详细行情、商人资料与最近航次分红在账本按需打开。

## 图文信息与操作定位（2026-10-20）

岸上岗位首行费用不带负号，次行直接显示正号收益或保险“即收”，取消入账／风险图标；费用与风险继续由可访问名称、按需详情及图例说明。船上费用保留原表达。领航岗位称小／大领航，货船整船分红池与船员个人收入分开，失航／被掠夺的船员收益明确为0；港口、修船坞及掠夺图形只描述已保存投影，不生成额外动作。

竞拍最高者明确标注“领先”，本人只能退出竞拍时不会显示“等待其他商人”。玩家顶部“装船／领航／派遣／购股／竞拍”入口只把既有滚动区定位到本人操作，资金不足的“去处理”沿用相同定位；无合法动作或主机／公共屏不显示该玩家入口。减少动态时直接定位。选货、箭头、草稿、具体对象确认、动作校验与保存边界不变。

结算去除上一行动者的活动标记，优先展示收支；主机／公共屏的棋盘仅在结算时允许自身滚动。短横屏商人条保留头像、座号及公开资产，完整姓名／角色继续由同一商人详情提供，秘密股份仍只本人可见。
