# 蟑螂沙拉

经典 Schmidt Spiele 40839 基础牌组及经用户确认的数字改编，2–6人；不混合蟑螂汤。规则标识 `classic-40839-digital-v1`，状态版本1。模块见 [清单](../../../games/cockroach-salad/game-module.json)，实现入口见 [规则](../../../games/cockroach-salad/rules/index.ts)。

## 出牌与命名

128张牌：番茄／生菜／花椰菜／甜椒各28张普通牌和4张禁忌牌。洗牌后平均发给玩家，余数移出。个人牌堆面朝下，连本人也不能预览。第一座位先手，随后按座位顺序；数字系统不收集年龄，故不实施纸面版最年轻者先手。

轮到某人即自动翻开其顶牌。通常必须如实命名；若当前蔬菜等于上一张蔬菜、上一实际回答或当前有效禁忌，则必须改答另一个蔬菜。替代名称仍不得是上述任何禁止名称。禁忌牌一律回答蟑螂。按钮始终按番茄、生菜、花椰菜、甜椒、蟑螂排列，允许错误选择；不展示合法答案。

打出禁忌牌，下张换至另一堆。第一张覆盖旧禁忌的普通牌仍同时受两堆覆盖前禁忌影响；之后仅可见禁忌有效。新打出的若又是禁忌牌，回答蟑螂优先；UI只标记新可见禁忌，不将被覆盖牌继续保留。

## 数字改编与补充裁定

官方原规则直接判每个错误、口吃和超过三秒的迟疑。本平台采用固定按钮及玩家质疑：

- 默认思考6500ms，每次无处罚过关减少100ms，最低1800ms；可选固定6500／3000／1800ms。错误漏抓也算无处罚过关。处罚后不重置全局节奏。这些均为项目参数。
- 思考截止自动进入额外3000ms拖延阶段。此时其他人可质疑／放过，作答者仍可回答；回答不能擦除拖延事实。额外阶段无人回答截止直接自动收全部桌面牌。
- 任意答案保存后进入1800ms共同窗口，暂停下一轮。若拖延阶段已提交质疑／放过，同一回合保留该选择，不能在看到答案后改票。提交动作按服务端保存顺序线性化：旧阶段截止或回答先保存则后续旧动作由平台重新校验；过期计时不能再次处罚。
- 多席独立选择使用同一并发组，统一等截止结算，首位不会揭晓结果。任何席位的选择均不公开给其他玩家，只有本人看见自己已提交的选择；公开反馈仅报告通用收据。所有人已提交也不提前关闭窗口。
- 有质疑且错误／拖延成立：作答者收全部桌面牌一次。否则全部错误质疑者均分。顺序固定为第一堆从底到顶、再第二堆从底到顶，按全局座位顺序轮流发给误判者；余数由排序靠前者多收一张，零张也允许。
- 罚牌加至个人堆底；犯错者或座位顺序首位误判者起新轮，清空历史蔬菜和回答。无人质疑则不公开系统判断，直接过关。
- 最后一张等待窗口结束；罚给作答者则不获胜，质疑不成立罚给其他人时作答者获胜。

## 保存、秘密与人机

规则纯变换，不读时钟。`automaticAction`以独立递增step与阶段生成唯一key，`applyAutomatic`拒绝过期step或阶段，客户端`validateAction`拒绝deadline。平台负责保存剩余计时、暂停、恢复和动作确认；回退重开所回到阶段的完整时限，暂停及重启从最后保存剩余时间恢复，规则测试不替代平台集成证据。

状态严格核对字段、座位顺序、128张唯一分区、移出牌数、阶段／答案／拖延关系、有效禁忌和胜者。公开及本人投影都不包含个人堆、移出牌、未来顺序或他人质疑选择；人机只收到该投影和合法动作。

三档本地策略参数（项目实现）：默认反应650–1350ms／答错18%／漏抓35%／误抓3.5%；豆包380–850ms／8%／16%／1.5%；绝悟180–550ms／2.5%／6%／0.5%。随机只走平台策略随机源。参数为可玩性设计，非实测胜率。测试即时执行并不证明真实计时体感。
