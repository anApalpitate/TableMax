## 模块交付与旧局恢复

源码目录、本地完整安装器和公开发行分别核对：本地已验收current及待验收候选的构建、SHA和适用证明统一见[当前源码与本地交付](../reference/acceptance.md#当前源码与本地交付)；公开发行仍按原六款／七玩法的实际发布附件与记录判断，不能因源码已加入马尼拉或本地installer已预装而宣称公开发行已更新，见[Release流程与历史](../reference/release.md)。本页不另维护可漂移的应用版本或本地current编号。

Windows只交付预装全部正式游戏的唯一完整installer EXE。游戏库与玩法浮窗负责筛选和选择；游戏下载、离线ZIP导入、单游戏更新／卸载／回退已退役。规则、策略、网页、样式和资源继续按游戏独立维护与增量构建；签名、哈希和内部模块仓库用于预装核验及旧局恢复。

新局只使用本 EXE 经验证的预装映射，旧安装索引及缓存目录不能覆盖它。旧局按原 `releaseRef` 恢复规则、策略、网页和资源；无引用旧档按精确版本匹配，不替换为最新规则。非当前发行显示“正在继续旧版本对局”，原局内下一轮／小局继续原发行，旧大厅开局或终局“再玩一局”切换当前发行。阿瓦隆退役 `classic`／`court` 仅供恢复原局。

原版本缺失、匹配不唯一或接口不兼容时保留存档、身份、checkpoint 和历史，并提示所需版本及包含它且支持存档格式的旧完整 EXE；不重新下载或导入游戏包。当前模块损坏只从本地载荷修复。实际程序、兼容及验证边界见[当前完整EXE验收](../reference/acceptance.md#当前源码与本地交付)，较早交付保留[历史验收](../archive/acceptance-2026-10-01-to-04.md)的原日期、构建与哈希边界。

中文互联网的人气线索、跨品类候选和适配判断见[候选与接入评估](candidates.md)。已接入游戏不列为候选；用户确认制作、研究建议、观察池和明确排除分别呈现，均不由卡片展示推断排期。

## 来源编号与复核

每款游戏的 `sources.md` 是采用版次、原始定位、核验范围、冲突与解释的唯一来源正文。保留已有S／MA-S／U／M等编号；没有编号的来源只在本游戏内补充，引用以“游戏目录＋编号＋适用章节”消歧，不建立全库手工注册表。素材仍由已有资源manifest与外部素材工作区维护。

来源身份、变更触发与定向复核统一按[维护规则](../reference/maintenance.md#来源身份与变化复核)执行。各游戏就近区分出版方原文、社区支持、用户采用与数字解释；规则测试通过不能替代出版认证，资料修订不能自动改变原局固定发行。

新游戏只创建已有实际内容的文件；返回[总索引](../README.md)。
