# 现代艺术

TableMax 的第二款独立游戏，采用经典 3–5 人拍卖玩法；画家总量和核心流程核对出版规则，版本差异及自主采用项见 [规则来源](sources.md)。规则版本为 `tablemax-modern-art-classic-v1`，状态版本 1，独立本地策略 `modern-art-local`／1.0.0。应用版本为 1.0.2，游戏规则、状态和策略版本保持上述值。

## 模块边界

规则、数据、投影、计分、电脑策略和界面集中在 [games/modern-art](../../../games/modern-art/index.ts)。它们不导入其他游戏的规则、类型、声音、素材或 UI；运行规则只使用游戏 SDK 的座位和可恢复随机源。普通数据存档与短生命周期 `AuctionFlow`／`MatchFlow` 分开，纯计分放在 [scoring.ts](../../../games/modern-art/rules/scoring.ts)。平台注册、通信、身份、保存、回退、暂停和游戏切换继续由平台负责。

UI 与策略只读 [view.ts](../../../games/modern-art/ui/view.ts) 投影契约及 [catalog.ts](../../../games/modern-art/data/catalog.ts) 公开目录。美术资源使用 `assets/games/modern-art/`；生成原图、替换资源、提示词和实际核验由资源清单维护。卡牌 `artIndex` 为画家内 1-based 序号，标题“作品 01”等为项目演绎。原创插画不能标为出版卡面或真实画家作品。

界面以五列行情板、中央拍品及各家博物馆组成公共桌面，手机保留本人现金、手牌和拍卖操作。行情板明确标注本轮“已上拍 n / 5”与“每幅预估收益（千元）”，说明第五幅立即结束本轮及数量前三名画家的收藏兑钱。行情板按内容收束高度，四人／五人、短窗口分别安排收藏与拍卖操作。手机手牌、本人收藏及电脑公开收藏纵向滚动，每行至少两幅并自适应宽度；手机可展开各家博物馆。画家使用深色 6px 边框和色块标题，画家／拍卖角标随画作宽度放大并放在独立顶部栏，保留完整画面。最新保存动作显示行动者、画家／作品及公开收藏人。

用户 2026-10-04 明确要求现代艺术增加游戏内规则帮助，覆盖此前本游戏线下教学约定。三端工具栏的“规则”按钮打开顶层 modal 图文卡片，分为回合、行情、五种竞拍、结算；手牌、行情、拍卖台和收藏四张配图来自隔离示例对局的实际新版界面，并本地打包。金额、数字化公开确认和出版版本差异以本页采用规格为准。配图不使用正式玩家数据，规则浮层不授予操作或秘密信息权限。

普通拍卖中若所有公开收藏均为空，电脑将剩余桌面高度用于当前拍品，按可用宽高分别安排单幅与双幅，并在下方保留玩家身份、参与状态和最新记录。短桌面双幅与报价保持在独立拍卖台，行情、拍卖台、身份行互不覆盖；收束重复记录，完整姓名与作品信息保留在 DOM 和提示中，行情历史入口仍可操作。获得收藏后恢复收藏布局；选画、暂停、策略故障与终局使用各自独立布局，不展示任何私密手牌。

选画台、领拍与保存动作允许长昵称换行，保持完整名称可见；选画不显示倒计时。公共博物馆、拍卖人、领拍者、最新行动者和拍卖参与状态使用同一稳定座位编号，缩略昵称相同也能对应身份；完整名字保留在 DOM 和提示中。手机不重复选画台已经说明的行动者，多人等待使用人数。暂停、管理员提前结束或策略故障时，活动提示遵循平台会话状态，停止标示玩家“可行动”或“正在行动”；已经保存的暗标提交与不参与状态仍如实保留。手机暂停选画将提示与恢复按钮合并。这些显示调整不改游戏阶段、合法动作或存档格式。

终局结果集中展示每位玩家的最终总资产与冠军标记，使用已公开的 `finalCash`，不把最后一轮收入当作最终成绩。每轮结算仍显示本轮收入。终局完整昵称直接换行显示，至少 18px；电脑按单列排列身份与对应资产，冠军另有文字徽章，手机将资产放在姓名下方，保留原冠军星标。终局不重复已清空的收藏列表、最新动作和轮次排行，市场估值与历史继续可查看，为原班再玩按钮保留首屏完整 44px 操作区域。

### 文字与画作辨识标准（2026-10-04）

承载玩法、状态、金额、牌名、标签或操作含义的可见文字，最小 **16 CSS px**；主要操作与关键状态至少 **18 CSS px**，电脑段标题至少 **20 CSS px**。这些是排版下限，不是把所有信息设成一样大。不能用短屏媒体查询、`transform: scale` 或局部 `zoom` 将信息文字缩到下限以下；电脑整体显示缩放仍按平台规格与空间保护处理。字号是本项目的可读性约定，不属于出版规则。

空间不足时先删重复描述、缩短信息层级，将次要历史和记录按需展开，使用可辨认的图标、布局重排及局部滚动；不通过缩小文字或操作热区塞进一屏。按钮仍满足至少 44px 触控，完整画家名、牌名与金额保留可访问名称。真正无信息的装饰纹样不按正文计，但不能将小数字称为装饰规避要求。

画家的深色边框与独立几何标记共同表达归属，拍卖方式由明显的类型图标和文字表达，不只靠浅色边线区分。手机本人手牌／收藏及电脑公开收藏默认按画家分组；改变展示顺序仅作用于本地排序，不改牌 ID、合法动作、物理分区或秘密权限。

竞拍决定倒计时在盒子设置：默认 20 秒、5–120 秒非线性滑动挡位，仅作决定时间提醒；现代艺术选画阶段不展示倒计时，包括暂停选画与双拍征集补画。归零仍允许原合法操作，不能自动出价、截标、确认或代离线真人行动；暂停、恢复、并发暗标和存档行为由平台负责。

## 采用玩法

每人初始资金 100，游戏币整数单位对应出版规则的千位金额。共四轮，未拍出的手牌保留，每轮已买收藏全部结算后移出游戏；不洗回牌库。开局先手为稳定座位首席，不采集年龄。第二、三轮补牌，第四轮不补牌。

| 人数 | 初始 | 第二轮补牌 | 第三轮补牌 | 第四轮 |
| ---- | ---- | ---------- | ---------- | ------ |
| 3    | 10   | 6          | 6          | 0      |
| 4    | 9    | 4          | 4          | 0      |
| 5    | 8    | 3          | 3          | 0      |

公开、一轮、暗标、定价和双拍卖由出牌符号决定。普通出价必须为正整数、不超过本人现金；公开与一轮必须高于当前价。得标者付给实际拍卖师，拍卖师自购付银行。定价从拍卖师左侧顺时针询问，没人买则其按原价自购。

手机金额加减按钮从小数输入走向相邻整数，并限制到当前合法范围；越界输入也能通过向内步进恢复。手动输入的非法金额仍禁止提交，调整输入本身不保存动作。

双拍卖先问原拍卖师是否提供同画家非双拍卖牌，再顺时针问各席；没人加入则原拍卖师免费取画。第二张由别人提供时，该玩家接任拍卖师并取得全部货款，下一次出画从其左侧继续，中间席位的出画机会跳过。

任何画家第五张出现即结算，该张无主不成交。第五张是双拍卖首牌时不允许第二张；第二张是第五张时最后两张都不成交，两张都计热度。只给本轮出过牌的画家排名，数量相同按板序优先。前三本轮增加 30／20／10，实际兑付累计历史价值；本轮跌出前三则兑付为零，旧价值仍保留。空手席不能出画，仍参与竞拍。全员手牌耗尽时，最后待拍的单张或组合不成交，结算并结束。最终资金最高者共同获胜。

## 数字决策与信息权限

公开拍卖允许当前未确认且未领先的席位自由加价或确认当前价不加价。每次加价清空旧确认，领先者视为确认；其他人都确认即成交。无出价时须全员确认才免费归拍卖师。确认只针对当前价，下一次加价后恢复选择；不自动计时截标、不代离线真人确认。公开决策按拍卖与当前报价代分组，同价多人确认或同价时产生的出价可在独立保存后继续提交；加价换组，迟到的旧价确认不能影响新价。旧逐席倒计时存档仅在字段完整匹配时合并为新组的最早剩余时间，损坏数据仍拒绝。金额输入按同场拍卖、实例和分支保持控件，别人报价或确认不会重挂载；失效草稿保留并提示新最低价，不能自动出价。

暗标每人一次，0 表示不投标。提交后锁定，所有席位提交才一起公开。相同最高价优先实际拍卖师；其未同价时从左侧顺时针选最近者。独立决策采用稳定 `${auctionId}:sealed:${seatId}`，同组 `${auctionId}:sealed`，别人的提交不更换尚未提交者的决策 ID。恢复后保留已提交金额、提交状态和剩余选择；离线席位不自动交给 bot。

公共屏及电脑管理员只看到公开画作、手牌数量、当前热度、历史估值、公开出价和暗标提交状态。真人与 bot 只增加本人手牌、本人现金和本人已提交暗标；其他现金直到游戏结束仍为 `null`。未齐暗标的公共记录不带金额，齐后完整出价作为公开成交记录保留。每轮收入可由公开收藏与价格计算，所以轮次收入公开；资金总额仍隐藏。

`offer → double／auction → offer` 完成拍卖；第五张或全手耗尽进入 `round-result／ended`。第 1–3 轮结算后的 `next-round` 是平台授权生命周期动作；最终再玩使用平台 replay。所有确定性支付、收藏转移、顺序推进和结算在一次规则 apply 内完成，UI 动效不参与权威状态推进。投影 `artists.currentValue` 在未结算时仅为按当前公开张数计算的估值。

## 声音

16 个 v2 原创音效独立保存在 `assets/games/modern-art/audio/`，由 `scripts/generate-modern-art-audio.mjs` 可复现生成；采用木质敲击、玻璃泛音与短和声，表达出画、各类拍卖、竞价／封存、成交及结算。版本、参数、哈希和电平核验在 [资源清单](../../../assets/games/modern-art/manifest.json)，试听与运行核验见 [验收记录](../../reference/acceptance.md)。电脑公共屏优先、管理员回退承接，统一沿用桌面声音归属和静音设置。现代艺术手机按最新用户要求提供独立本地声音与静音偏好：默认开启，首次或刷新后通过“启用声音”取得浏览器手势授权；同文档返回盒子再进入保留已解锁播放器。解锁前的旧事件不补播，解锁进行中的新事件仅在授权成功后播放。

声音只根据已保存的公开结果选择，最多保留短队列；金额与未公开暗标不参与声音分类。暂停、断线、测试模式、换归属及组件退出停止播放；首次载入、刷新和回退不重播历史动作。倒计时只显示视觉提醒，不叠加每秒提示音。

五类上拍分别使用约一秒的艺术主题入场声与 1.6 秒全屏开场：公开上行、一次节拍、暗标低音封存、一口价价签、双拍双重冲击。图标、主题色、光束、横幅按已保存上拍触发，双拍追加确定实际方式后再表达对应方式。初次载入、刷新、重进、同步与回退不补播；测试模式禁声画，减少动态改为短静态徽章。全屏特效不阻断合法操作，规则 modal 保持顶层。盒子返回游戏的原生声音连接采用可取消短重试，仍严格核验角色／来源和游戏路由。

## 状态与验证

`validateState` 核对座位完全一致、全部 70 张唯一物理分区、资金合法且总量不超过初始资金与历史收入、阶段与拍卖队列及加价次数匹配，重算每轮排名、历史加价、最终估值和收入。第五张结束时未成交画作必须属于第五张画家。历史结果的牌引用用于审计，不再当作额外物理卡牌。已成交与结束轮次的所有牌保持在弃置分区，历史结果与该分区一致。非法、越权、过期或格式错误的动作拒绝，原输入对象不变。

[风险测试](../../../games/modern-art/rules/rules.test.ts) 的 15 个用例覆盖第五张两种双拍卖边界、接牌顺序与收款、银行支付、公开确认重置、暗标保密与平手、零定价、左侧平手、历史价值、空手与耗尽、第五张同时耗尽、非法输入与损坏恢复。先通过该组，再执行 [策略整局测试](../../../games/modern-art/bot/strategy.test.ts) 的 8 个用例：3／4／5 人 × 三档 × 三个固定种子，共 27 局，每步检查输入不变、合法选择、序列化恢复和身份投影；另核对秘密信息独立性、终轮候选后的整体排名收益和取消处理。

三档都是本地独立策略：默认保守随机、有限记忆与当前轮估值；豆包保留较多近期公开见牌并轻量预测下一轮；绝悟保留实际观察记录，比较全部剩余轮次供给情景及本人手牌、收藏与主动结束轮次。公开拍卖按估值跳价，每场本人最多三次加价，避免反复只加一。算法、记忆容量／换轮衰减、恢复及局限见 [独立人机策略](bot.md)。品牌标签不表示联网调用服务，也不授予其他席位的秘密。策略输入对手隐藏现金和手牌顺序变化时，选择保持相同。

真实服务、原生窗口与手机模拟、回退、重启、两游戏切换和最终便携 ZIP 的范围及证据见 [当前 debug 验收](../../reference/acceptance.md#102现代艺术-debug-修复2026-10-04)，最初接入记录保留在 [历史验收](../../reference/acceptance.md#100现代艺术独立接入2026-10-03)。局部测试与投影 fixture 的证明范围分别保留，操作入口统一见 [开发环境](../../reference/development.md)。
