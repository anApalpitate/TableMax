## 项目明确采用

| 编号   | 项目采用项与理由                                                                                                                         |
| ------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| MA-P01 | 稳定座位首席为首拍，不采集年龄；其余顺序按公开座位顺时针。                                                                               |
| MA-P02 | 公开拍卖用当前价确认完成机制；每次有效加价重置确认，以可保存动作表达实体桌面的停止加价。确认后等待新的出价；不自行超时或强制离线弃权。   |
| MA-P03 | 暗标提交即锁定，0 为不投标，全员后一起公开；网络送达顺序不改变平手优先权。                                                               |
| MA-P04 | 定价允许 0，仍受本人资金上限限制，以保证资金为 0 且只剩定价牌时可合法推进。普通加价保持最小 1。出版规则未明确最低定价为 0。              |
| MA-P05 | 最终资金平手共同获胜；出版规则只指定最高资金获胜，未给额外终局裁决。                                                                     |
| MA-P06 | 最后两张组成双拍卖且全手耗尽时，两张均不成交；它们构成尚未成交的最后一批，沿用第五张组合与末张不成交边界。此组合缺口未获独立出版例示。   |
| MA-P07 | 不启用三人炒作玩家、两人或六人变体；默认完整经典 3–5 人。                                                                                |
| MA-P08 | 70 张采用原创演绎插画，保留出版画家标签用于识别，但不冒充真实画家作品。标题为“作品 01”等，具体资源来源、提示词与核验见 assets 游戏清单。 |

已核验出版流程与这些自主采用项构成 `tablemax-modern-art-classic-v1`；完整工程实现与验证入口见 [当前规格](README.md)。
