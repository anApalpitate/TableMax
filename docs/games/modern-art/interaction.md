## 牌桌、行情与玩家布局

320–600px行情浮窗将标题／详情入口完整换行，上拍数量按“名称＋完整数字”分组，避免“艺术市／场”或单个数字挤入孤立行；主桌行情摘要与拍卖控件保持原有结构、字号和秘密隔离。

电脑真人首次采用竖屏，可在外框切换横屏；960px 起建立拍卖工作台。顶部五画家摘要显示总量、上拍数量与现有估值，历史拆分、供给和详细提醒进入既有行情浮窗。普通拍卖以约62%拍品／公开价格／本人现金与唯一操作区，配38%私有手牌；本人上拍与双拍扩大手牌至60%，左侧拍品与追加提示并排、现金和操作紧随其后。手牌宽140–190px并保持完整比例，短屏使用页面纵向滚动；结算主区展示结果及授权继续入口。五类拍卖的信息与暗标隔离保留，同一组件和报价／排序／选牌草稿保留。共用显示偏好和滚动条规范见[通用视觉](../../reference/visual-design.md#电脑浏览器玩家的手机区域2026-10-08)。

界面以五列行情板、中央拍品及各家博物馆组成公共桌面，手机保留本人现金、手牌和拍卖操作。艺术市场显示“已上拍 n / 5”和每幅预估兑现（千元），拆分“历史＋本轮”；本轮跌出前三时兑现为 0，同时保留历史值和未入前三状态，结算页按刚结束轮次拆分而不重复累计。历轮浮窗区分各轮增值与累计价值。画家名旁以色底白数字方形徽章标明全套总量 12／13／14／15／16，不推断牌库内各画家剩余张数；Daniel 使用梅紫 `#7b3f82`，Rafael 保留焦橙，各端和图解统一标记。市场常驻规则小字改为紧凑单行辅助轮播，7 秒切换、250ms 淡入与轻微位移；减少动态直接切换，错误、当前条件和连接状态仍即时显示。

2026-10-08 用户纠正后，电脑浏览器真人参赛保持原手机界面，在中央手机区域显示本人资金、报价、手牌和拍卖操作，周围使用背景置景；不再按 1024px 铺开玩家侧栏。布局由[通用玩家外框](../../reference/visual-design.md#电脑浏览器玩家的手机区域2026-10-08)承载，调整外部窗口不重建会话或报价草稿。服务器机管理与公共屏继续使用完整桌面行情和公共拍卖布局。

电脑参赛仍使用本人玩家投影，只展示本人手牌、现金和已提交暗标；其他人的手牌内容、终局前现金及未揭示暗标金额继续隐藏。屏幕宽度不授予管理员权限，也不改变合法动作。上述内容记录当前源码行为；真实 GUI、跨断点及同版本交付包检查见[验收](../../reference/acceptance.md)。

电脑公开收藏采用 140–188px 紧凑画卡，宽栏自动增加列数，突出画家／颜色／几何标记和拍卖方式，保留缩略画作与完整可访问名称。博物馆区域负责唯一纵向滚动，收藏内层取消限高和独立滚动。手机本人收藏改为按“画家＋拍卖方式”分组的摘要、数量与色标，本人可操作手牌继续展示完整画卡；手机页面与收藏浮窗分别只保留自身的滚动层。玩家身份使用稳定座位顺序的圆形数字徽章，覆盖博物馆、拍卖人、领拍者、参与状态和最新保存动作；完整姓名保留在 DOM 和提示中。这些卡宽、色值与动效时长是实施参数，不作为用户偏好原话。

用户 2026-10-04 明确要求现代艺术增加游戏内规则帮助，2026-10-05 进一步要求重写内容并重新制作原创逻辑图解。三端“规则”按钮打开顶层 modal，保留回合、行情、五种竞拍、结算四章导航；九张原创 AI 场景分别解释回合流程、第五幅结束、历史兑现、五种拍卖和最终结算，不再将游戏截图用于当前规则配图。准确数字、座号、箭头及规则文字由代码排版，生成图只承担场景和组件。人数发牌表、暗标平手、自购支付、双拍交接、第五幅不成交及手牌耗尽均在正文说明，出版规则与数字化项目约定分开。新图本地打包，提示词、来源、版本、尺寸、哈希及导入状态见 [资源清单](../../../assets/games/modern-art/manifest.json)；素材原图及规则参考配图保留；历史运行截图按用户授权退役，文字证据保留，配图不含正式玩家秘密。

本次继续改为可直接定位并聚焦章节标题的按钮导航，开头先概述目标、回合与胜负，加入轮间价值累计示例；正文 18 px、图注及来源 16 px、标题至少 20 px、触控至少 44 px。章节内容与主题样式独立维护于 [规则界面](../../../games/modern-art/ui/RulesGuide.tsx) 及同目录 `rules-guide.css`，平台仅共用导航及文字／图片排版。窄屏保持纵向阅读；关闭或 Escape 恢复原入口焦点，查看说明不改变游戏状态、倒计时或报价草稿。

普通拍卖中若所有公开收藏均为空，电脑将剩余桌面高度用于当前拍品，按可用宽高分别安排单幅与双幅，并在下方保留玩家身份、参与状态和最新记录。短桌面双幅与报价保持在独立拍卖台，行情、拍卖台、身份行互不覆盖；收束重复记录，完整姓名与作品信息保留在 DOM 和提示中，行情历史入口仍可操作。获得收藏后恢复收藏布局；选画、暂停、策略故障与终局使用各自独立布局，不展示任何私密手牌。

选画台、领拍与保存动作允许长昵称换行，保持完整名称可见；选画不显示倒计时。公共博物馆、拍卖人、领拍者、最新行动者和拍卖参与状态使用同一稳定座位编号，缩略昵称相同也能对应身份；完整名字保留在 DOM 和提示中。手机不重复选画台已经说明的行动者，多人等待使用人数。暂停、管理员提前结束或策略故障时，活动提示遵循平台会话状态，停止标示玩家“可行动”或“正在行动”；已经保存的暗标提交与不参与状态仍如实保留。手机暂停选画将提示与恢复按钮合并。这些显示调整不改游戏阶段、合法动作或存档格式。

终局结果集中展示每位玩家的最终总资产与冠军标记，使用已公开的 `finalCash`，不把最后一轮收入当作最终成绩。每轮结算仍显示本轮收入。终局完整昵称直接换行显示，至少 18px；电脑按单列排列身份与对应资产，冠军另有文字徽章，手机将资产放在姓名下方，保留原冠军星标。终局不重复已清空的收藏列表、最新动作和轮次排行，市场估值与历史继续可查看，为原班再玩按钮保留首屏完整 44px 操作区域。

短电脑结算移除已清空的博物馆和与艺术市场重复的排行，将本轮收入与下一轮按钮同排；市场仍保留该轮兑现与历史拆分。短屏终局保留完整姓名和资产，两列汇总、单一牌桌滚动面及始终可见的再玩按钮；不嵌套收藏滚动。结算／终局暂时隐藏非紧急轮播，不隐藏操作或连接状态。

## 文字与画作辨识标准（2026-10-04）

承载玩法、状态、金额、牌名、标签或操作含义的可见文字，最小 **16 CSS px**；主要操作与关键状态至少 **18 CSS px**，电脑段标题至少 **20 CSS px**。这些是排版下限，不是把所有信息设成一样大。不能用短屏媒体查询、`transform: scale` 或局部 `zoom` 将信息文字缩到下限以下；电脑整体显示缩放仍按平台规格与空间保护处理。字号是本项目的可读性约定，不属于出版规则。

空间不足时先删重复描述、缩短信息层级，将次要历史和记录按需展开，使用可辨认的图标、布局重排及局部滚动；不通过缩小文字或操作热区塞进一屏。按钮仍满足至少 44px 触控，完整画家名、牌名与金额保留可访问名称。真正无信息的装饰纹样不按正文计，但不能将小数字称为装饰规避要求。

画家的深色边框与独立几何标记共同表达归属，拍卖方式由明显的类型图标和文字表达，不只靠浅色边线区分。手机本人手牌／收藏及电脑公开收藏默认按画家分组；改变展示顺序仅作用于本地排序，不改牌 ID、合法动作、物理分区或秘密权限。

竞拍决定时间在盒子设置：默认 20 秒、5–120 秒非线性滑动挡位，仅作提醒。拍卖台上方使用横向进度条，不显示剩余秒数；归零停在零并只播放一次短提示音。现代艺术选画阶段不展示倒计时，包括暂停选画与双拍征集补画。归零仍允许原合法操作，不能自动出价、截标、确认或代离线真人行动；暂停、恢复、并发暗标和存档行为由平台负责。

五种拍卖分别以竞价阶梯、顺时针席位环、封存信封队列、悬挂价签和同画家配对画框呈现公开状态；暗标揭示前只显示提交状态和数量，不显示金额。双拍征集期间仅合法 `add-double` 手牌显示 3px 虚线、1.8 秒平缓呼吸描边，暂停、断线、提交锁定或动作失效时停止；减少动态使用静态虚线。状态主题由代码／SVG 绘制，不改变决策或秘密投影。

## 金额输入

手机金额加减按钮从小数输入走向相邻整数，并限制到当前合法范围；越界输入也能通过向内步进恢复。手动输入的非法金额仍禁止提交，调整输入本身不保存动作。

## 声音

17 个原创音效（16 个 v2 保存结果音效及新增决定到时提示）独立保存在 `assets/games/modern-art/audio/`，由 `tools/assets/games/modern-art/generate-modern-art-audio.mjs` 可复现生成；采用木质敲击、玻璃泛音与短和声，表达出画、各类拍卖、竞价／封存、成交及结算。版本、参数、哈希和电平核验在 [资源清单](../../../assets/games/modern-art/manifest.json)，试听与运行核验见 [验收记录](../../reference/acceptance.md)。电脑公共屏优先、管理员回退承接，统一沿用桌面声音归属和静音设置。现代艺术手机按最新用户要求提供独立本地声音与静音偏好：默认开启，首次或刷新后通过“启用声音”取得浏览器手势授权；同文档返回盒子再进入保留已解锁播放器。解锁前的旧事件不补播，解锁进行中的新事件仅在授权成功后播放。

动作声音根据已保存的公开结果选择，最多保留短队列；金额与未公开暗标不参与声音分类。暂停、断线、测试模式、换归属及组件退出停止播放；首次载入、刷新和回退不重播历史动作。进度条归零仅播放一次决定到时提示，不叠加每秒提示音。提示依据已保存计时基准，沿用本地静音、手机手势解锁与电脑单声源；以实例、分支和 clock ID 去重，重复同步与其他席暗标提交不重响，首次载入、刷新或重进不补播已经到时的提示。提示音不产生动作、罚则或自动成交。

五类上拍分别使用约一秒的艺术主题入场声与 1.6 秒全屏开场：公开上行、一次节拍、暗标低音封存、一口价价签、双拍双重冲击。图标、主题色、光束、横幅按已保存上拍触发，双拍追加确定实际方式后再表达对应方式。初次载入、刷新、重进、同步与回退不补播；测试模式禁声画，减少动态改为短静态徽章。全屏特效不阻断合法操作，规则 modal 保持顶层。盒子返回游戏的原生声音连接采用可取消短重试，仍严格核验角色／来源和游戏路由。
