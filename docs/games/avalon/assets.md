上述四张运行图片总计 1,245,020 字节。复古蚀刻水彩、羊皮纸／旧铜／青绿／酒红为本次实施方向。身份图不包含文字或玩家信息，角色名、阵营、票、数字与任务牌文字均由代码控制。功能王冠与表决标记采用原创 SVG；任务／人数图解、五次否决印章、箭头由 React／CSS 排版。

图片由本次已授权 imagegen 子 agent 生成，原图、提示词与深浅底联系表保留在 [图片证据](../../../artifacts/avalon-art/)。图集经过按角色逐格裁切、居中缩放和精确等格重排，没有改写绘画内容；透明遗物已经在羊皮纸和深青底检查。通过解码、实际尺寸和哈希验证后导入 [角色卡](../../../games/avalon/ui/RoleCard.tsx)、[遗物](../../../games/avalon/ui/Relic.tsx) 及 [样式](../../../games/avalon/ui/style.css)。真实运行使用状态和证据由清单维护，不能将生成预览当作产品验收。

## 原创离线音频

[生成脚本](../../../tools/assets/games/avalon/prepare-avalon-audio.mjs) 使用固定随机种子和原创建模，合成类鲁特琴拨弦、铜钟泛音、框鼓、纸蜡和剑鸣。没有下载采样、连续背景音乐或网络播放。固定 ffmpeg 工具的二进制哈希在音频清单中记录，原始 PCM 保留在 [音频原素材](../../../artifacts/avalon/audio/source-originals/)。

| 事件资源（后缀 `-v1.flac`） | 时长 | 内容 |
| --- | ---: | --- |
| `pledge` | 0.65s | 纸蜡与安静拨弦宣誓 |
| `team` | 1.4s | 圆桌召集的低鼓与上行拨弦 |
| `ballot` | 0.48s | 所有秘密投票／任务提交共用的中性纸蜡 |
| `approved`／`rejected` | 1.25／1.2s | 铜印与明亮开放五度／双鼓与下降音型 |
| `quest-success`／`quest-fail` | 1.85／1.8s | 圣杯铜钟与上行音型／乌鸦扫声、低鼓与下降音型 |
| `assassination` | 1.15s | 宝剑扫声与铜质落点 |
| `good-win`／`evil-win` | 2.3s | 忠诚／邪恶的不同模态终句 |
| `assassination-good`／`assassination-evil` | 2.6s | 剑鸣后约1.1s接胜方终句，配合复合全屏演出 |

12 条运行 FLAC 共 676,088 字节，32kHz、16bit、立体声。每条都与原始 WAV 逐 PCM 字节回环一致，峰值不超过0.66，RMS为0.115；播放层音量0.56。尺寸、实际峰值、RMS、源／运行字节和 SHA-256 逐条记录在音频清单。

播放器只消费新保存的公开反馈，秘密提交无论选哪一张牌都使用 `ballot`。桌面指定输出去重，手机手势解锁与本机偏好、后台／禁播清理在 [交互与声画](interaction.md) 说明。测试默认静音，峰值与解码自动检查不表示人耳听感已验收。
