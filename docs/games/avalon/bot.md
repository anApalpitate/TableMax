# 阿瓦隆独立电脑策略

入口为 [bot/index.ts](../../../games/avalon/bot/index.ts)，策略 avalon-local／1.0.0；botsByVariant 对应经典基础和宫廷迷局各自规则版本。仅用本人 AvalonView、完整合法动作、决策、策略随机和取消信号；不导入权威状态、读档、网络或他人秘密。

| 等级 | 已实现决策差异                                                                                                                         |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 默认 | 查看身份；简单偏好本人出征，参考最近一次任务筛选阵营；邪恶任务直接失败；刺杀在合法目标中随机                                           |
| 豆包 | 最近两次公开任务的失败数更新阵营假设，比较干净队伍概率；已知邪恶同伴同时出征时依固定座位仅一人破坏；刺杀参考最近5次提案                |
| 绝悟 | 全部任务、逐人投票和队长提名软证据；至多15组双邪恶假设的有界概率比较；善良成功记录仍允许邪恶隐藏；首任务单邪恶可隐藏；刺杀综合全局信息 |

三档均处理确认、提名、赞成／反对、成功／失败和最后刺杀，必须从平台给出的合法动作中选择。善良第5次投票赞成，避免否决直接败局；邪恶可继续争取第五次否决。已知坏人不会进高档梅林的理想队伍，但未知身份与对话心理仍有不确定性。

任务失败张数构成硬证据，成功只提供概率线索；绝悟的投票证据是弱权重，没有把“反对某队”当作确定身份。派西维尔的两个候选只约束一善一恶，未获得角色真假。概率参数与一级隐藏策略属于项目技术方案，不是官方玩法，也不宣称必胜或严格胜率递增。

策略无额外记忆，memory 必须为 null。公开历史随权威状态保存，因此回退和重启后重新计算相同授权信息；等级差异通过选择使用的历史范围实现。策略随机用于同评分选择，服务端拥有独立可恢复随机源。取消、非null记忆、错误本人座位与版本均拒绝。

固定测试包括18个六人自然整局（2配置×3等级×3种子），每步合法动作与存档校验，覆盖全部决策；另核验梅林合法知识、任务成功不强制忠诚、失败交集的高档排险、邪恶单人破坏和取消／身份边界。测试记录从[游戏入口](README.md#规则与策略验证)进入。机器人不生成说服性口头讨论，不能替代真人社交推理，也不会接管掉线真人。
