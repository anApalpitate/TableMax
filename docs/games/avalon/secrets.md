# 阿瓦隆秘密投影与恢复

[规则](spec.md)只在服务端保存完整角色、暂存投票与任务牌；客户端与策略均消费[本人投影](../../../games/avalon/rules/project.ts)。管理员与公屏使用 public，手机房主仍为本人玩家权限。

## 权限矩阵

| 观察者                 | 游戏中获准秘密                                         |
| ---------------------- | ------------------------------------------------------ |
| 公屏／管理员／陌生座位 | 无；没有 self，没有角色表、本人知识或已提交牌值        |
| 梅林                   | 本人角色和所有当前配置邪恶的座位；不知谁是刺客／莫甘娜 |
| 普通忠臣               | 本人角色；无他人初始知识                               |
| 刺客／爪牙／莫甘娜     | 本人角色与另一位邪恶座位；不知对方具体角色             |
| 派西维尔（court）      | 本人角色与梅林／莫甘娜的两位候选座位，不标注真假       |
| 任意本人玩家           | 本人这次已保存投票或任务牌；别人只能看到提交状态       |
| 终局所有端             | 公开全部角色、胜利阵营、共同赢家和刺杀结果             |

角色工具的原版边界：莫德雷德不向梅林显现，奥伯伦不与其他邪恶互认但会被梅林看到。工具测试不代表当前库已启用对应配置。

## 独立提交与反馈

身份确认、全员投票、队员任务分别使用稳定 concurrencyGroup；决策编号包含阶段、任务号、提案号与本人座位。别人的提交不会改写剩余玩家的决策编号。提名和刺杀只有一位行动者，不声明并发。

中途保存投票无论赞成／反对，公开投影、反馈和 before checkpoint 标签完全相同；任务成功／失败同理。公开消息只写“座位N已密封投票／任务牌”，不输出选择值、角色、牌类别、额外目标或策略记忆。最后提交才触发原子结算：全员票值公开，任务只公开匿名失败张数。界面声画不能从中途提交猜测结果。

## 不变量与回退

[状态校验](../../../games/avalon/rules/state.ts)拒绝陌生／乱序座位、错误角色构成、跨配置存档、非法任务牌、善良失败牌、提前全量暂存提交、错误任务人数、票数与批准状态不一致、任务历史不一致、错误轮转队长、连续否决／任务胜负篡改、虚假刺杀及动作计数不一致。历史最多25个提案和5次任务。

JSON往返保留部分提交与未提交者的决策。规则变换不修改输入或 checkpoint；相同 before 与同意图重演相同结果，投影返回独立数据。投票与任务结算不等待界面播放；后续完整同步不补播结果。

身份凭证、手机房主管理授权、换机与分支水位由平台管理。回退不恢复旧授权，重启保持暂停后由授权房主恢复；游戏不保存、不解释凭证。真实 Socket／SQLite 并发、事务、重启与 Worker 取消的结论由主任务记录，不能由本游戏 JSON 单测代替。
