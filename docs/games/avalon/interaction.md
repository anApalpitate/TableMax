# 阿瓦隆交互与声画

## 主题与工作区

2026-10-24已确认[管理兼展示与公共屏退役](../../reference/phase-02-platform-spec.md#管理兼展示与公共屏退役2026-10-24)，当前源码待实施。后续管理界面继续使用本游戏相同的`public`公开投影，玩家权限及操作不变；下文旧public界面参数、三端截图与报告仅在原实现及输入范围内适用。

2026-10-10 用户要求“经典桌游阿瓦隆”、复古画面、符合阿瓦隆背景，并采用局部动效、参考现代艺术的精致全屏特效及吸睛音频。本次据 [用户美术偏好](../../reference/art-preferences.md) G01／G02／G04／G09／G10／G11／G13／G14／G17／G18 选择明亮羊皮纸、旧金铜、深青绿与酒红；亚瑟王背景通过原创蚀刻水彩角色、圆桌、城堡、圣杯、乌鸦和封蜡表达。这些具体色值、构图与工艺是实施判断，不补写为用户固定偏好。

核心圆桌保持稳定，顶部五张任务牌显示每次人数、成功／失败和匿名失败牌数。右侧或手机下一行显示成功／失败累计与连续否决印章。队长王冠、已选队员绿蜡封、本人提交状态和公开表决图标分别表达，颜色之外保留形状与文字。管理、规则和历史按需打开顶层浮窗。

目标中的电脑管理兼展示界面使用大圆桌与席位头像，角色秘密和本人选择均不进入展示，不再另设独立公共屏。电脑浏览器玩家只有本人权限；横屏将圆桌和当前决策并列。手机重排为紧凑三列席位、任务轨道和下方当前操作，不等比缩小电脑画面。信息文字至少 16px，主要行动至少 18px，电脑分区标题至少 20px。短屏主要操作以粘附面板保留在易达区域，规则和记录采用单一纵向滚动。

## 各阶段操作

| 阶段     | 玩家操作与提交                                                     | 主机／公共显示                                         |
| -------- | ------------------------------------------------------------------ | ------------------------------------------------------ |
| 圆桌宣誓 | 主动“查看身份”，阅读本人角色与知识，再“确认身份并入席”             | 已确认席位与人数，其他角色保持隐藏                     |
| 队长提名 | 直接点选圆桌成员，选满合法人数后“提名队伍”；再点选可取消           | 当前队长、已保存远征名单，草稿只在本人端               |
| 有序讨论 | 从队长逆时针下一席起，当前本人“发言完成”，队长最后                 | 公开当前席位和进度；仅电脑管理员可跳过；全部完成后密投 |
| 队伍表决 | 全员同时选赞成或反对，点卡立即提交；提交后不得改                   | 仅显示提交席位；全员完成后公开每人的票与结果           |
| 秘密任务 | 只有队员有任务牌；忠诚只显示成功，邪恶可选成功／失败               | 仅显示谁已封存；所有牌完成后只公开失败牌数和任务结果   |
| 最后刺杀 | 刺客点选合法目标，再“刺杀＋目标名”明确确认                         | 当前刺客行动席位与最后目标；其他角色到终局揭示         |
| 终局     | 本人端与公开端一致展示全员身份、阵营胜负和原因；授权房主可再玩一局 | 同左，电脑管理员仍不占座位                             |

本人角色图像和秘密知识只在主动打开的身份浮窗挂载。关闭、窗口失焦或转入后台立即收起；未打开时正文、圆桌和动效均不渲染角色。320px 短宽屏通过菜单保留身份入口。首次宣誓后仍可按需查看本人卡；这不是自动揭示或强制教程。

玩家动作只使用授权 `actions`、当前 `decisionId` 和统一 `GameHost.command`。组队人数与目标不靠本地猜测合法性；只有所选成员集合与服务器合法组队完全一致时才能确认。本地选择按实例／分支／提案／阶段复位，其他人同时提交不会重置本人选择。保存、恢复、倒计时及授权边界遵循 [平台规格](../../reference/phase-02-platform-spec.md)。

手机房主可执行已授权开局、暂停／恢复、再玩一局；checkpoint 回退仅属于电脑管理员。计时只提醒，不代人提交，不改变角色、票或任务牌。

## 保存后演出

[UI 演出](../../../games/avalon/ui/Effects.tsx) 只消费与当前实例／分支／修订一致的 `room:feedback`，首次快照、完整同步、重复消息、恢复和回退不重播。静音、禁播和后台消息也记为已消费，重新开启不能补播。演出层透明且不接收指针，不等待演出完成才允许下一决策。

| 事件               | 局部与全屏                                                                     | 音频                                                     |
| ------------------ | ------------------------------------------------------------------------------ | -------------------------------------------------------- |
| 宣誓／秘密提交     | 本人或行动席位短促蜡封落点，最新已保存动作明确行动者                           | 宣誓短鲁特琴；所有秘密票／任务牌使用完全相同的中性纸蜡音 |
| 提名               | 相关头像印章、圆桌纹样展开、封蜡与扫光                                         | 低框鼓与上行拨弦                                         |
| 队伍通过／否决     | 印章确认或斜落否决，纹章射线与主题横幅                                         | 铜印／明亮拨弦，或双鼓／下降拨弦                         |
| 任务成功／失败     | 圣杯辉光或乌鸦暗影，纸刻线纹、金屑／暗羽；不展示牌的来源                       | 铜钟泛音与上行拨弦，或软翅扫声／低鼓／下降拨弦           |
| 刺杀               | 宝剑自上落下、刀光，约 1.1s 后接圣杯或乌鸦结算；横幅明确梅林生还／被识破及胜方 | 同一音轨的剑鸣接阵营和声                                 |
| 三失败／五否决结束 | 胜方遗物与阵营横幅、完整角色结算                                               | 2.3s 模态拨弦与铜钟／低鼓终句                            |

常规全屏演出 1.9s，刺杀复合演出 2.6s。减少动态时去掉射线、扫光、粒子、旋转与位移，保留 550ms 静态图像和结果横幅。测试模式、暂停、断线和策略错误停止本端演出与声音。切后台或组件卸载释放媒体，迟到播放授权不得复活旧声音。

声音入口采用有可访问名称的图标；桌面遵循平台指定声音输出窗口和 `claimAudioEvent` 去重，手机声音需手势启用并保留独立本机静音偏好。未设置手机偏好时继承平台静音。身份、赞成／反对、成功／失败秘密选择不改变中性提交音，避免声画泄密。所有正式素材本地打包，见 [资源清单](assets.md)。

## 顶层图文规则

“规则”入口使用共享顶层规则框，提供阵营胜负、角色秘密、组队表决、匿名任务、最后刺杀和数字平台六组逻辑图。准确文字、人数、任务表、箭头与标记由代码排版；原创图像仅辅助主题辨识。显示六种人数完整角色表并突出本局人数，角色图组可换行、窄手机按纵向条目展示；旧局显示实际旧配置说明与官方同版链接，不引入其他人数规则，详见 [采用规则](spec.md)及[来源](sources.md)。

## 验证边界

定向 UI 单测覆盖保存后去重、初始消息消费、刺杀优先及秘密提交中性音；授权控件检查忠诚无失败牌、精确组队确认和公共圆桌只读。素材已完成解码、尺寸、透明度及哈希检查，音频已完成峰值／RMS与 FLAC 无损回环。三端实际渲染、短屏、4K、交互流程与演出证据由本次主验证统一记录；自动验证不代替真人听感与真实手机性能。

5–10人均使用同一圆桌与手机布局；7人以上第四任务标注“双失败”，结果同时显示实际失败牌数。一张失败仍成功时，演出读取已保存的成功结果，不依据失败牌是否非零猜测。

## 有序讨论（v1.0.6，2026-10-11）

逆时针顺序、队长最后及管理员跳过见[采用规格](spec.md#有序讨论v1062026-10-11)。当前发言人与进度公开，本人标记、远征队员封蜡和发言边框可并存；手机重排不改变顺序。身份浮窗关闭按钮融入羊皮纸边框，保留44px目标；终局按实际内容宽度至少360px采用三列，否则两列，姓名可换行。

发言区精简为“发言进度 n/N”和下一位姓名／最后发言提示，进度包含正常完成与管理员跳过；当前发言人仍由顶部文字与圆桌高亮表达。主机按钮显示“跳过当前发言”，可访问名称保留当前姓名；不再列出全员姓名、箭头与完成串。此处仅调整公开呈现，发言顺序、身份、管理员权限及原动作命令不变。

现行新局采用唯一“经典配置”，标签使用对称内边距、加粗文字并水平／垂直居中；手机沿用原隐藏处理。身份提示解释莫德雷德与奥伯伦的知识边界；两种密投均独立封票，全员保存后揭示，任务牌匿名。规则浮窗只读取公开局面，不改变对局或挂载他人的身份；莫德雷德与奥伯伦使用各自专属画像，其他六种角色沿用原画卷。

2026-10-12选队微调：圆桌座位的悬停与按下反馈保持原位置，只改变外观，不套用通用按钮位移动效。提名操作区只显示已选人数，具体成员由圆桌的选中封蜡与姓名表达，避免名单换行导致操作区高度跳动。本次仅修改源码与资源，不导出新版本。

## 主机首屏布局（2026-10-18）

桌面主机在至少1000 CSS px宽时，顶部保留工具、当前阶段和五次任务轨道；圆桌与讨论顺序、最新表决、保存反馈和记录入口并排。7–10人座位沿四列三行的外圈排列，窄短窗口将头像和姓名横向组合；终局身份通栏展示，再玩一局保留在底部。按可用高度调整图像和间距，状态文字至少16px、席位姓名至少18px，不隐藏溢出内容来消除滚动。更窄窗口沿用纵向布局；浮窗仍独立按内容滚动。

本次仅更新阿瓦隆主机源码样式，公共屏和玩家端不应用这些主机选择器。源码视口验证与实际EXE边界见[验证记录](validation-scenarios.md#主机首屏布局2026-10-18)。
