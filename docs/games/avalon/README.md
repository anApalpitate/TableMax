# 阿瓦隆

本地角色画卷、圆桌场景、透明演出图集和十二条离线声音见 [资源与核验](assets.md)。

采用 Indie Boards & Cards 2012 年 **The Resistance: Avalon** 经典原版。官方游戏为 5–10 人，TableMax 当前提供 5–6 人，规则没有缩编或改用其他人数表。游戏库的“经典基础”与“宫廷迷局”均采用同版原有角色；前者含梅林、刺客，后者加入派西维尔、莫甘娜。不混入 Big Box、新角色扩展、兰斯洛特、湖中仙女或任务顺序变体。
