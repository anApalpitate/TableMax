# 阿瓦隆

采用 Indie Boards & Cards 2012 年 **The Resistance: Avalon** 经典原版。官方游戏为 5–10 人，TableMax 当前提供 5–10 人，规则没有缩编或改用其他人数表。新局仅提供用户图片指定的按人数配置：梅林、派西维尔、莫甘娜与刺客固定，按人数加入爪牙、莫德雷德或奥伯伦；完整表见[经典规格](spec.md)。旧经典基础／宫廷迷局仅支持原局恢复。不混入 Big Box、新角色扩展、兰斯洛特、湖中仙女或任务顺序变体。
