# 手写改动单

## v1.0.7

1. 盒子内更新支持(留待v1.0.7))
2. 道具背包计划（留待v1.0.7）
   - 互动道具、语音大扩充，可以在盒子页面可以自己装配（装配机制见下）
   - 机制：
     - 可以装配的包括：表情、语音背包（可以装配更多语音，即现在的语音界面）、表情背包（可以装配更多表情）
       - 即可以选择装配语音背包+表情背包+4个快捷表情，也可以选择直接装6个快捷表情。
       - 表情背包、语音背包中内容不可修改，以简化逻辑。
     - 语音背包、表情背包中的顺序均可以切换：（默认排序，即音序排列；频率排序，高使用率考前）;背包中支持翻页，表情背包中为格子形式，一格一个表情，语音背包中为条目形式，一条一个语音（一行）。
