## 后续开发接续入口

- **太阳神（待验收）**：取得普通版第三印原始规则附件后，复核印刷图表和源文件哈希。[核验入口](../games/ra/README.md#美术审阅与后续核验)
- **宝可梦梦幻重复发动（待核对）**：确认反馈所涉原版／扩展版、实际发行、是否回洗，以及同一实例的动作记录。[反馈记录](bug-assessment-2026-10-19.md#宝可梦弃牌中的梦幻反复发动)
- **全部游戏布局（待验收）**：补 SQLite 保存失败和旧局继续的服务验证。[验证范围](all-games-layout-rollout.md#仍需独立接续)
- **工作区深度瘦身（待接续）**：核实剩余未分类文件的来源和用途。最近一次审计在现行清理范围和保护要求下测得容量下界为 6.577 GB，高于 6 GB 目标。[容量下界与剩余范围](../reference/project-slimming.md#两周期大项净回收排序与保护下界2026-11-22)

## 后续独立范围

- **后续游戏（未排期）**：奥地利大饭店、沙丘·帝国、SCOUT、Flip 7 已确认制作，版次、扩展和人数待确定。[制作计划](../games/candidates.md#用户确认的未来制作计划)
- **初始 10 款游戏与扩展包（未开始）**：确定初始包剩余名单，先验证可复用架构和接口，再实现独立扩展包下载与接入。[扩展包计划](base-games-and-expansion-packs.md)
- **人机崛起（未开始）**：建立统一快速评估，逐游戏升级策略，并规划捣蛋王。[人机任务](bot-rise.md)
- **macOS 服务端运行包（未开始导出）**：收敛导出输入和范围，收集最小运行目录并验证运行。[macOS 任务](macos-adaptation.md)
- **跨游戏调试与纠错（未规划）**：待确定调试能力、秘密权限、修改可见性和保存恢复策略。外部插件和多房间分别按独立需求安排。[需求基线](../requirements.md#65-跨游戏调试与纠错后续独立规划)
- **宝可梦奇遇扩展版（待接续）**：补剩余插图，设计 Mega／羁绊效果，核对真人对局时长与平衡。[扩展版任务](pokemon-encounters-expansion.md#后续素材玩法与真人待验收)
