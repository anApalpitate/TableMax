## 首版维护

2026-10-08本轮增加扫码及二维码下方直接打开网站两种入口，原生电脑窗口经可信点击交给系统浏览器，普通浏览器新页按真人玩家权限加入。按各游戏实际阶段和浮窗复核并修正窄屏行情、空电厂占位及归零标记，沿用v1.0.4；本轮用户已明确授权更新运行包、源码提交／推送、标签及GitHub Release，发布范围和实际包证据统一见[当前验收](../reference/acceptance.md)，安全深度瘦身见[容量记录](../reference/project-slimming.md)。此前各轮“不发布”仅描述当轮授权。

2026-10-08已完成v1.0.4玩家比例与游戏工作区修订：桌面竖屏宽度优先、框外模式按钮、紧凑座位与居中换机入口，电力公司四页真实横屏布局、地图角色边界和0.64缩放，现代艺术拍卖工作台与私有手牌分区。最终同包及独立视觉复核见[当前验收](../reference/acceptance.md#104玩家比例与游戏工作区修订2026-10-08)，安全清理保留近期保护和未测实体设备边界。

2026-10-08 后续需求将默认分享网址改为根入口，保留旧 `/player` 路由；宝可梦扩展版全研究与移动端操作重设计、单弃牌、缓冲和四神各一张的范围及检查状态见 [当前任务](pokemon-encounters-expansion.md#研究与玩家操作重设计2026-10-08)。用户明确授权完成后 commit 与 push，仍不创建 Release 或新标签。
