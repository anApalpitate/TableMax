# 开发阶段与任务索引

第一至四阶段已完成并归档。正式平台已有真实大厅、身份投影、电脑座位、可靠动作、存档与恢复，并用独立最小游戏模板完成实际验证。首版宝可梦规则引擎、计分与策略尚未实现；下一阶段为第五阶段完整游戏。

产品范围和验收标准以 [需求基线](../requirements/TableMax_需求文档_v1.0.md) 为准。原文第 14 节保留初始阶段建议；根据当前要求调整后的开发顺序以本索引为准，采用粗粒度划分，暂不拆成逐项功能工单或排定日期。

已完成的阶段任务移入 archive，本索引保留阶段顺序、完成状态及归档入口；tasks 维护进行中阶段和待执行范围。第二阶段长期来源与规则已合并到游戏主题，长期通用行为仍由 reference 维护。

2026-10-01 新增基础人机与适度面向对象封装要求，见 [人机规格](../reference/bot-players.md) 和 [工程结构](../reference/architecture.md#面向对象与适度封装)。第一阶段历史完成状态保持；第二至六阶段吸收新增设计、实现和验证，平台与模板已实现，首版宝可梦 bot 留给第五阶段。
