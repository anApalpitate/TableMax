## 首版维护

### 1.0.1：独立牌桌与游戏体验维护

2026-10-01 用户提出的五项持续完善已落地：盒子／游戏独立页面和占屏布局、直接操作牌堆与单步意图、会话／页面／平台控件／游戏场景职责整理、花园牌桌与保存动效／胜局展示，以及当前文档维护。正文分别见 [通用交互](../reference/phase-02-platform-spec.md#盒子与独立牌桌)、[游戏交互](../games/pokemon-encounters/interaction.md)、[目录职责](../reference/project-structure.md)、[验收记录](../reference/acceptance.md#首版维护独立牌桌与操作简化)。本轮已完成工程、UI 和新版便携验证，证据集中在验收页；后续新增功能继续按实际需求维护，不重开历史六阶段。

### 1.0.2：视觉纠错与场景打磨

2026-10-02 完成，工程检查、真实 UI／完整整局与最终便携包验证通过。范围为卡面分区、桌面 2–5 人排布、手机短屏／横屏、梦幻目标选择、弃牌查看以及保存动效。完成标准为实际渲染的名称／数值／能力不相互遮挡、插画有独立区域、合法操作和秘密投影保持、不同人数与尺寸能操作，并通过工程、真实能力和完整混合局／便携验证。持久行为与资源归入 [游戏交互](../games/pokemon-encounters/interaction.md)、[资源](../games/pokemon-encounters/assets.md)，执行范围和实测结果归入 [维护验收](../reference/acceptance.md#首版维护视觉纠错与场景打磨)。

### 1.1.0：原版角色、简约盒子与管理员维护

2026-10-02 范围：电脑房主仅管理、默认唯一牌桌和简约盒子；16 类角色卡面／统一角标；关键保存动画；资源统一可替换、后台验证和当前文档维护。管理员与对应需求已分阶段提交并通过 48 项测试；卡面、资源迁移、十四组 UI／关键节点补查、整局和新版便携验证均已完成。16 次独立生成只有百变怪成功，其余明确失败；当前角色采用核验后的官方原图，生成与导入来源分开。完成标准为身份边界、窄卡清晰、保存后动画／恢复不补播、工程／能力多尺寸／整局与便携验证通过并维护入口。验收与接续见 [维护验收](../reference/acceptance.md#首版维护角色卡面与管理员体验)。长期行为见 [交互](../games/pokemon-encounters/interaction.md)、[资源](../games/pokemon-encounters/assets.md)、[工程结构](../reference/architecture.md)。

### 1.2.0：聚会可靠性与连续游玩

2026-10-02 完成。用户要求深入优化高优先级连接／身份问题、连续游玩和运行保障，明确无需新增游戏内教程或帮助。完成标准为：加入／换绑在丢回复、刷新与重启后仍能确认同一次请求，保存失败不重复占座／消耗码；实时网卡名称、刷新与选择保持，具体中文启动诊断；保留原班真人身份和电脑、重新准备并开新大局，另有清空牌桌；服务／公共屏防自动休眠、重复启动保护、管理窗口恢复与带上下文的回退。工程 58 项测试、14 组真实 UI、开发完整混合局与聚会专项、最终 1.2.0 ZIP 隔离 PATH 的完整三胜／原班续局及十组聚会专项均通过。长期正文见 [聚会规格](../reference/phase-02-platform-spec.md#聚会连接连续游玩与运行保障)、[工程结构](../reference/architecture.md) 与 [验收](../reference/acceptance.md#首版维护聚会可靠性与连续游玩)。本机 IPv4 与后台网络／触控模拟不扩展为真实手机、Safari 或 Wi-Fi 验收。

### 1.3.0：手机聚会、围桌房间与三档人机

2026-10-02 完成。所有真人使用各自手机扫码操作，电脑只担任房主管理与公共展示；盒子房间采用游戏大厅式围桌入座，可添加或调整“默认／豆包／绝悟”三档本地人机。三档覆盖全部选择，从简单决策到局势分析、授权信息下的有界推演；等级／记忆支持保存、回退、重启与续局。75 项工程测试、十二个固定种子完整大局、14 组能力 UI、七种房间布局、实际 Worker 混合小局、完整三胜与十组聚会回归，以及最终 1.3.0 ZIP 的独立便携验证全部通过，见 [本轮验收](../reference/acceptance.md#首版维护手机围桌与三档人机)。规格分别维护在 [人机](../reference/bot-players.md)、[通用房间](../reference/phase-02-platform-spec.md) 与 [游戏人机](../games/pokemon-encounters/bot.md)。教学保持线下，不接入外部模型服务；绝悟给出当前评估模型中的优选，不保证全局数学最优。设备边界保持本机 Windows／Chromium 模拟。

### 1.4.0：游玩节奏、行动提示与六人布局

2026-10-02 完成。落实隐蔽测试模式与正式游玩、浮窗式连接／游戏信息／管理／菜单、直接结束确认、包含行动者／卡图／能力／目标的最新操作、较大字号和星标，并把首版人数上限扩到六人。88 项工程测试、十五组能力 UI、十三组正式卡面布局、25 个默认规则种子大局和三档十五个种子大局通过；六真人自然小局、实际三档时序、六席三端多尺寸与嵌套浮窗焦点通过；最终 1.4.0 ZIP 完整三胜／恢复／续局、呈现、围桌／三档和聚会保障四组独立便携验证通过，见 [本轮验收](../reference/acceptance.md#首版维护游玩节奏与六人提示)。长期行为归入 [通用规格](../reference/phase-02-platform-spec.md#实际游玩与测试模式140)、[游戏交互](../games/pokemon-encounters/interaction.md#游玩节奏行动播报与六人布局140)，六人依据在 [S21](../games/pokemon-encounters/sources.md#s21六人项目扩展2026-10-02)，不能标为出版原文。玩法教学仍线下，实际游戏保持独立全屏；验证仍为本机 Windows／Chromium 设备模拟，证据与原图保留，旧版本程序包已按用户要求清除。

### 1.5.0：电脑多分辨率显示

2026-10-02 完成。按用户要求适配 3840×2160，增加仅电脑端的显示设置浮窗、自动／四档分辨率预设、界面大小、Windows DPI 与每窗独立缩放、刷新／重启配置恢复，并优化六席房间、六人对局和暂停／读档恢复的短屏布局。98 项工程测试、六人／硬币／传递三组真实 UI、开发与最终 1.5.0 ZIP 的隐藏多分辨率专项通过；两套显示专项均覆盖 35 组布局、47 次浮窗操作，包含实际暂停／恢复、4K 三档大小、手机隔离、原生窗口关闭及重启。含 preload 的新版便携包已解压、仅系统 PATH 运行，哈希与最终 ZIP 一致，见 [本轮验收](../reference/acceptance.md#首版维护电脑多分辨率显示)。长期行为见 [电脑显示规格](../reference/phase-02-platform-spec.md#电脑多分辨率显示150)，实现见 [工程结构](../reference/architecture.md#电脑显示控制)；仍为本机 Windows／Chromium 尺寸和 DPI 模拟，不扩展为实体 4K 电视验收。

本地维护补充（2026-10-02 已完成）：按用户要求清理历史版本及已结束的中间物，根目录增加两类独立清理入口，默认预览并保留当前已验证 ZIP；操作与 Agent 接续约定见 [清理说明](../reference/development.md#清理本地中间物)。20 项隔离工具检查通过，实际清理释放约 15.62 GiB；范围与记录见 [使用与维护](../reference/acceptance.md#使用与维护)，版本仍为 1.5.0。

### 1.6.0：盒子、对局体验与可靠性

2026-10-02 完成用户确认的范围：管理员／手机房主分权、删除换手机、游戏目录与按需加载、首翻及准备并发、行动与进度／待处理牌、全部能力声画／零分列／共同赢家、复制开销与 5 GiB 安全维护。保持规则、秘密投影、保存后表现和回退历史。127 项工程测试、十五场游戏 UI、十三种卡面布局、六组声画指定场景、开发完整对局、最终 1.6.0 ZIP 四组便携验证及 54 项维护隔离测试通过；实际主工作区约 2.840 GiB，无需清理。长期行为见 [通用规格](../reference/phase-02-platform-spec.md#160游戏选择手机房主与独立提交)、[游戏交互](../games/pokemon-encounters/interaction.md#160行动面板与声画反馈)、[采用决策](../decisions/007-library-owner-and-concurrency.md)，验证边界、内存测量与最终交付见 [1.6.0 验收](../reference/acceptance.md#160盒子对局体验与可靠性)。
