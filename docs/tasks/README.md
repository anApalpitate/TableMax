### 宝可梦火箭队配图缺口

2026-10-05 用户要求把火箭队换成经典武藏／小次郎／喵喵三人组、透明竖构图并用于卡面和短能力入场。内置 imagegen 一次参考生成在输出阶段返回 `moderation_blocked / other`，未生成或导入，当前保留旧官方四人横图。实际提示词、拒绝响应和原图哈希见 `artifacts/maintenance/v1.0.2/pokemon-polish-20261005/imagegen/rocket/`，状态在 [资源记录](../games/pokemon-encounters/assets.md#权限动画和声音)。不改写提示绕过拒绝、不把未产出的 v2 接入 UI；后续可使用用户提供或明确授权且可核验的替代素材。其他本轮声画与手机改动的实际验证见 [验收](../reference/acceptance.md)。

### 独立游戏包与按需安装（宏伟大计，进行中）

2026-10-11 用户批准，沿用v1.0.6。公共契约、独立资源构建、签名发行、本机安装、热接入与原包固定已形成实现；独立作者两工程接入、八玩法实际离线整局、最终基础ZIP／EXE、实际旧原生存档迁移和安装界面定向验收通过，结果只维护在[当前验收](../reference/acceptance.md#106独立游戏包与公共作者契约2026-10-11)。

剩余验收为实体手机LAN及Safari解码、可见作者浏览器启动、真实磁盘满和全部下载／解压写入点的故障矩阵。已通过三个事务边界真实进程终止／重启，以及同步ENOSPC异常、取消与断流检查；不替代后两项。原[手写改动单](手写改动单.md)“宏伟大计”保留至全部完成，其他盒子修复、Mac与人机算法计划独立处理。

实现与门禁入口见[工程结构](../reference/architecture.md#独立发行与公共契约2026-10-11)、[开发与接入](../reference/game-development.md#独立作者工具包2026-10-11)、[发行流程](../reference/release.md#游戏包发行2026-10-11)。后续保持发行不可变、存档引用保护、管理员安装权限及游戏玩法／策略版本不变，不将未验证设备写成通过。

### macOS 适配（未来计划，未实现）

2026-10-10 用户确认纳入未来计划，状态为未开始：支持 Mac 运行盒子、本地服务、管理和公共屏，真人继续通过手机或电脑浏览器入座。尚未确定技术路线或开发日期；原生外壳、最低系统版本、处理器架构覆盖及分发方式在实施前评估确定，不能将技术建议写成已采用方案。

剩余工作范围包括原生外壳与窗口／显示行为、浏览器桥接及身份权限核验、配置／存档／日志／缓存的存储路径与迁移、服务进程启动和异常退出清理，以及运行时打包、应用签名与公证。复用范围与跨平台边界按现有[工程结构](../reference/architecture.md)核对。
