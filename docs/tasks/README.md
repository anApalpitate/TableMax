# 开发阶段与任务索引

项目基础结构、阶段规划与第一阶段工程基础已完成。当前已有可运行的工程验证程序，尚未实现平台业务或具体游戏；第二阶段已开展来源检索，交付通用规格与独立可点击原型，目标版本完整原文尚未取得，具体游戏规格不能冻结。

产品范围和验收标准以 [需求基线](../requirements/TableMax_需求文档_v1.0.md) 为准。原文第 14 节保留初始阶段建议；根据当前要求调整后的开发顺序以本索引为准，采用粗粒度划分，暂不拆成逐项功能工单或排定日期。

已完成的阶段任务移入 archive，本索引保留阶段顺序、完成状态及归档入口；tasks 维护进行中阶段和待执行范围。第二阶段来源记录已合并到阶段任务，长期通用行为仍由 reference 维护。

每个阶段开始前补齐本阶段的执行范围和完成标准，再按实际结果更新状态。制定任务文档不代表研究、设计或实现已经完成；第三至六阶段暂时仅保留上表的粗粒度边界，不提前创建空阶段文档。首版需完成完整游戏并通过需求中的关键恢复与交付验收，不能以某一阶段完成替代产品完成。
