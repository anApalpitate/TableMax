阶段可适度交叉：第二阶段规则检索可以与不依赖具体玩法的通用平台设计并行；未经核验的规则不能进入游戏实现。恢复、信息隔离和模块边界应从平台设计开始考虑，按第三、四阶段逐步交付。第一阶段已验证打包可行性，第六阶段完成无开发环境 Windows 电脑上的正式便携验收。

每个阶段开始前补齐本阶段的执行范围和完成标准，再按实际结果更新状态。制定任务文档不代表研究、设计或实现已经完成；第三至六阶段暂时仅保留上表的粗粒度边界，不提前创建空阶段文档。首版需完成完整游戏并通过需求中的关键恢复与交付验收，不能以某一阶段完成替代产品完成。
