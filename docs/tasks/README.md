## 后续独立范围

### 多游戏按需安装（未来计划，未实现）

2026-10-03 用户确认：游戏数量增加时再拆分游戏包，首版继续随便携包提供完整游戏；语言精简已先完成，当前桌面按用户后续授权迁移共享 WebView2。未来盒子保留目录、小封面及管理功能，由电脑按需下载并本地安装对应游戏包，手机继续从电脑的局域网服务获取资源；安装后正式游玩不依赖互联网，并支持离线包导入。

实施前明确游戏包覆盖规则、UI、策略及资源的边界、下载来源和分发方式；完成标准包括包完整性与版本兼容校验、失败安装不破坏已有游戏、保留存档所需版本、已安装游戏离线完整对局及手机无互联网使用。当前只有内置游戏懒加载，没有下载／安装机制；未确定拆包实施日期。需求入口见 [资源工作流](../requirements/TableMax_需求文档_v1.0.md#93-艺术资源工作流)。

经典版《电力公司》德国地图已按 2026-10-04 用户指示，在“宝可梦奇遇”完成并提交后独立完成；长期规格见 [游戏入口](../games/power-grid/README.md)，同 ZIP 便携交付见 [验收](../reference/acceptance.md#101电力公司经典德国版2026-10-04)，等待、研究、分工和关键耗时见 [接入归档](../archive/power-grid-2026-10-04.md)。外部插件、多房间仍按独立需求安排。跨游戏调试与纠错目标见 [需求第 6.5 节](../requirements/TableMax_需求文档_v1.0.md#65-跨游戏调试与纠错后续独立规划)，尚未独立规划／实现；它不替代已经完成的首版决策点回退。
