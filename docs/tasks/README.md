## 首版维护

### 1.0.1：独立牌桌与游戏体验维护

2026-10-01 用户提出的五项持续完善已落地：盒子／游戏独立页面和占屏布局、直接操作牌堆与单步意图、会话／页面／平台控件／游戏场景职责整理、花园牌桌与保存动效／胜局展示，以及当前文档维护。正文分别见 [通用交互](../reference/phase-02-platform-spec.md#盒子与独立牌桌)、[游戏交互](../games/pokemon-encounters/interaction.md)、[目录职责](../reference/project-structure.md)、[验收记录](../reference/acceptance.md#首版维护独立牌桌与操作简化)。本轮已完成工程、UI 和新版便携验证，证据集中在验收页；后续新增功能继续按实际需求维护，不重开历史六阶段。

### 1.0.2：视觉纠错与场景打磨

2026-10-02 完成，工程检查、真实 UI／完整整局与最终便携包验证通过。范围为卡面分区、桌面 2–5 人排布、手机短屏／横屏、梦幻目标选择、弃牌查看以及保存动效。完成标准为实际渲染的名称／数值／能力不相互遮挡、插画有独立区域、合法操作和秘密投影保持、不同人数与尺寸能操作，并通过工程、真实能力和完整混合局／便携验证。持久行为与资源归入 [游戏交互](../games/pokemon-encounters/interaction.md)、[资源](../games/pokemon-encounters/assets.md)，执行范围和实测结果归入 [维护验收](../reference/acceptance.md#首版维护视觉纠错与场景打磨)。
