## 剩余试点验收

后续5个可比任务的读取输出减少50%以上、工具往返减少25%以上；暖构建或单游戏打包耗时减少25%以上。均为试点目标，未达时记录实际数据与原因，不把调用相关性、单个夹具或源码进程首次启动换算成额度节省与EXE冷启动收益。

### 实际任务采样（0／5）

每次在已有任务报告记录日期、任务和基线版本／SHA、实际入口及路径。以同一问题和范围比较首次定位是否命中权威章节、漏读了哪些适用例外、实际返回的 UTF-8 字节（含续读）、工具往返次数，以及改动的正文与入口处数。可取得真实 token 时另记缓存输入、未缓存输入和输出；构建用同一环境记录命令、缓存状态及耗时，仅在该任务本来需要构建时采样。记录可比性与偏差原因。
