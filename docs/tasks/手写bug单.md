## 改动单

1. 盒子页面
	- 盒子中进行少部分操作时（如删除人机）画面会跳动 [中]
	- 盒子页面的视频设置里需要补充显示模式的切换：全屏、无边框窗口、窗口。
		- 游戏里的全屏按钮可以通通移入视频设置，和上述保持一致
2. 宏伟大计
	- 游戏资源下载隔离+编码构建分离（支持分游戏的并发开发）+ 按需下载资源
	- 盒子侧提供公共接口供游戏侧使用，游戏侧在部分方面维护一套公共的开发契约，便于与盒子侧对接(最终目标是便于其他开发者开发新的游戏接入),可能需要对现有的逻辑进行较大的兼容性改造。 [重]
3. mac系统服务端兼容
4. 宝可梦奇遇扩展详细设计计划
5. 电脑操作快捷键补齐（仅电脑玩家端+服务端）
