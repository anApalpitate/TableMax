1. 后续可比任务记录目标问题、适用正文、前提与例外、实际读取输出、工具往返及整合／审计成本；有真实token时与字节分别记录，不推算订阅额度。
2. 缩小查找路径并按准确标题／SHA补读，避免减少调用却批量通读更多正文；固定8题输出反增与6题小幅下降均保留，不改基线凑目标。
3. 新会话受限环境只证明声明的窄路径检索回退；默认全库枚举不可用时明确报告，不伪装完整结果。
4. 5个样本采满后报告实际值、正确性与维护成本，未达时记录原因并定向调整；所有剩余项闭合后归档本页并修复入口。
