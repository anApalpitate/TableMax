# 全部游戏布局接续

2026-10-29已按用户授权完成8款游戏、9个玩法的源码布局调整和逐游戏浏览器验证，实施前方案归[计划快照](../archive/all-games-layout-rollout-plan-2026-10-29.md)。共享净区、手机门禁、控件去重的长期设计见[界面复用](../reference/ui-composition.md)和[架构](../reference/architecture.md)，各游戏布局参数归自身主题。本页只保留证明边界和后续事项，不再作为待实施清单。

已完成的编译快照、失败原因、逐游戏证据及原字节保护归[完成记录](../archive/all-games-layout-rollout-completed-20261029.md)。本页不重复历史统计。

## 仍需独立接续

- 实体Android／iPhone：浏览器工具栏、安全区、软键盘与真实旋转；手机横向仅门禁，恢复后有效草稿保留。390×844是代表尺寸，不是新的最低设备承诺。
- Windows真实DPI、页面倍率、外接屏和4K电视：CSS／DPR模拟只证明布局及输出，尚未证明物理观看距离和原生设备组合。
- 真实网络、SQLite保存失败、重连恢复和旧局继续：本轮规则未变，仅复用受控投影／命令与适用兼容测试；不将源码点击命中记作真实服务已保存。
- 新安装器仅在用户明确要求导出时实施，按当前完整EXE规则执行；现有安装器不会因源码构建自动更新。
- 构建保留德国小强payload既有1MiB预算告警，最终1,545,089字节；未自动提高预算。应独立核查运行载荷／已有素材分块，不为消除告警附带修改素材。
- 项目逻辑文件长度采样约10.45GiB；本轮临时构建与审阅材料仍受当前任务／近期文件保护，已配精确清理入口，未自动Apply。继续清理须预览核对，保护正式证据、原件、旧模块和实际交付。

本轮不再要求360×640／640×360完整矩阵，也未建立全平台固定比例画布。若真实设备发现新布局分支，按实际结构补例；不得静默缩字、降低热区或扩大共享层的游戏知识。
