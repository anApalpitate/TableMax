## 完成标准与验证顺序

1. 取得并记录经典基础规则、完整电厂、地图、资源价格／库存／补充和收入数据；各来源、差异及项目采用项明确可追溯。
2. 实现 2–6 人相邻区域选择、五阶段与三步转换、顺时针竞拍及首轮必购／每轮至多一厂、弃旧厂和资源重分配、逆序采购／建城、最短连接路径和跨过满城、选择发电、补充与市场更新、完整建造轮后终局实际供电排名。
3. 环境与少量素材预检后，首先打通真实消息→规则→SQLite→投影的高风险路径，覆盖越权、隐藏现金、重复确认、保存失败、迟到分支、暂停、回退、重启和手机房主授权不倒退。
4. 多人数×三档×固定种子完整局逐动作验证合法性、资源／资金和状态不变量、输入不变、JSON 恢复；有明确策略差异与不读取对手秘密的验证，不能以合法动作通过代替策略质量。
5. 真实后台渲染覆盖管理员／公共／手机，先六人、720p、125%／150% DPI、短窗口及短手机，再完成 720p—4K 矩阵；地图缩放／选城／费用预览、竞价、购买／仓储、发电和浮窗可操作。三款游戏在同一 SPA 的 CSS 与 Portal 共存切换通过，退出释放资源。
6. `pnpm check` 与真实构建通过；源码稳定后只生成一次最终同版本 ZIP，保留旧包及验收，用同一 ZIP 哈希的实际解压目录和仅系统 PATH 完成真实服务＋手机身份＋Worker 混合整局、保存恢复、游戏切换及既有游戏相关回归。运行外网请求为零；ZIP 与解压文件总字节均严格小于 100,000,000，以 95 MB 为工程预算。
7. 实际关键耗时、证据与模拟边界进入验收；全部构建／验证进程结束后执行 `Maintain-Project.ps1 -Apply`，合并长期文档、同步索引和 AGENTS 路由，自动 commit 仅本次明确改动，默认不 push。全部完成后归档本任务并暂停自动接续。
