# 手机与局域网分层同步

2026-10-09，v1.0.5：分层同步实现及本机交付检查完成，真实手机局域网验收待接续。

`room:view`及完整同步使用外层stamp（serverSessionId／instanceId／branch／viewSeq）、syncHint、interactionWatermark和权限view；领域RoomView、游戏revision及存档格式保持原职责。`room:probe`相同stamp仅返回元数据，不生成完整投影；只有实际视图变化推进序号。重启更换服务会话。

客户端统一调度probe、完整同步与只读动作查询，连接／凭证代次及票据隔离迟到回复。前台活跃500ms、其他2秒探测，15秒完整校验并错峰；探测初始1500ms，至少五样本后采用clamp(4×EWMA_RTT+250,1000,3000)，权重0.2。完整同步5秒、入座8秒；有效期min(8000,2×探测超时+间隔)。首次探测超时先全量校验，校验仍失败才重连，退避500／1000／2000／4000ms并±20%；过期保留画面但锁定操作，后台暂停，恢复必须授权确认。

动作800ms未确认查询`room:command:status`，复用持久成功receipt，运行期拒绝结果256条／60秒；查询不执行或保存动作。处理中1／2／4秒查询，未知待确认，显式重试保留原编号与内容。恢复先查询，旧动作结果仅确认其自身。较旧恢复快照不能解除锁定；查询完整投影合并全量校验需求。

互动通过稳定订阅接收，服务序号及水位隔离恢复前事件；真正断线、身份失效、后台和实例／分支变化清场，健康完整校验保持播放。有限诊断只记录时间／字节，不记录凭证或秘密内容。

定向产品单测66项、范围检查8项及实际菜单／互动渲染通过，包大小和哈希见[当前验收](../reference/acceptance.md)。本机六Socket模拟分别测量polling／WebSocket，不等同手机、LAN或关键画面渲染。真实设备仍须记录机型、浏览器、连接方式、传输、样本和失败，验证保存至关键画面P95≤300ms、漏推送约1秒恢复，以及音频就绪后接收至启动P95≤100ms。
