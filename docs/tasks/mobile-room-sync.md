# 手机与局域网：真实设备验收

记录日期：2026-10-10。分层同步源码、定向检查、本机六端模拟及同版v1.0.5交付已完成；真实手机局域网基线、公共竞价画面性能与实测调参尚未验收。当前协议见[平台规格](../reference/phase-02-platform-spec.md#浏览器入座换机与外部连接2026-10-07)，已完成实现、初始参数、原失败及本机检查见[实施归档](../archive/completed-tasks-2026-10-10.md#手机与局域网分层同步已完成实施2026-10-09)。

## 后续验收与完成标准

1. **真实设备基线**：记录手机首次打开、入座及竞价的分段耗时、消息字节数、同步次数和传输方式，确认最慢环节。现有运行诊断仅保留有限时间／字节样本，不记录凭证、动作内容或秘密投影。
2. **真实设备验收**：记录设备、浏览器和网络条件，验证公共竞价并据测量调参；完成后同步平台规格与当前验收。真实手机与局域网尚未执行，不预先声称消除了延迟。

建议性能目标：在记录清楚的稳定局域网条件、六个客户端同时连接时，保存成功至其他前台设备完成关键画面更新的 **P95 ≤ 300 ms**；活跃决策期间人为漏掉一次应用层更新、连接仍健康时，**约 1 秒内恢复**最新状态。必须记录设备、浏览器、网络条件、样本数及失败次数；目标未达到时报告瓶颈，不能以本机通过代替。

测量包括提交、服务端收到、保存完成、广播、客户端收到与渲染完成。各段优先使用同一进程单调时钟；跨设备延迟使用有误差说明的时钟校准或往返测量，不能直接相减未经校准的时间戳。

验证范围按共享协议、服务与会话层实际依赖筛选，竞价重点覆盖现代艺术与电力公司的受影响场景；其他游戏只验证实际受影响的通用同步契约，不机械重跑全部规则或整局矩阵。执行入口、历史通过率排序及累计失败 3 项停止规则沿用 [开发环境](../reference/development.md#按变更范围选择检查)。测试默认静音，真实局域网验证按 [Node 与防火墙规则](../reference/development.md#node-运行与防火墙规则)执行。

必须覆盖：漏更新、迟到／交错回复、完整同步与推送并发、确认丢失与重复查询、同编号重试、弱网、锁屏恢复、身份撤销、换机、回退、新房间及服务重启。确保不重复出价、不回退画面、不泄露秘密、不产生请求积压，普通周期校验不阻断健康操作。

## 当前接续

真实手机后台唤醒、弱网完整链路与公共竞价仍需设备验收。首次资源加载、入座连接、动作同步和声画启动分别测量；本机接收延迟不代表手机关键画面更新延迟。音频就绪后接收至启动P95≤100ms仍为真实设备待测目标，不认证听感。完成后依据实测调参，同步平台规格和当前验收，未达标时记录瓶颈与后续措施。
