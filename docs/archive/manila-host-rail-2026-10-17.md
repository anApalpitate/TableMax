# 马尼拉主机展板与手机航道改动汇总

1. 主机／公共屏从“上中下三段”改为实体展板构图：顶部只保留控制带；左侧为三条水平航道与五行岸线岗位；右侧为账房栏，行情四行纵向排列在上，五张商人账册行在下。底部商人横条和顶部行情横带不再渲染为独立区域。
2. 右侧账房栏使用连续纸张、铜线和席位色带；商人行显示现金、股份、伙伴与结算名次／财富，当前行动者同时有头像、席位色带和短状态。1280×720、1920×1080、3840×2160及125%／150%逻辑视口下，主机页面不依赖纵向滚动展示行情、商人和完整展板。
3. 手机航道把“等待装船／船员 N”整句改为货舱清单牌：空舱显示虚线货舱与“待装货”，在航显示“船员”短签、伙伴棋子和合法空位，靠港／进坞／被掠夺使用对应图形与去向短签。13格边界增加海盗拦截线、海盗旗和一处短签，船停13格、登船或掠夺时强化。
4. 手机终局和账本终局的公开股份改为货物图标、张数徽章和抵押蜡封，不再渲染“（抵押）”；图标保留可访问的名称、张数与抵押状态。秘密股份详情继续使用原有完整文字说明。
5. 规则、安全投影、动作协议、SQLite／Socket、checkpoint、回退、暂停、计时、版本号和安装器均未改。本期只更新源码界面、测试和文档。
6. 源码验证：设计检查10个角色／尺寸布局及10个详情通过；完整手机港湾60项检查、394次实际点击通过；组合检查8项通过；手机触控20项通过；马尼拉范围单测通过；完整源码构建快照为 `89d6c04a764547488aed482ab916f0dd0b4ea075841696634de4bf5601fdbc05`。证据见[验证场景](../games/manila/validation-scenarios.md#主机展板与手机航道2026-10-17)。
7. 失败与边界：5人原生页面布局检查在本机开发构建上因 `missing-preinstalled-games` 服务启动失败，未取得原生通过证据；5人源码夹具只作为界面检查。853×480本轮不作为可读性通过尺寸，1280×720起为主机视觉验收范围。模拟手机、DPR、4K和触控不代表实体设备、物理显示器、真实LAN或安装后运行。
8. 本轮未生成安装器、未更新版本、未发布；下一步的正式设备／安装链验收仍需独立证据。
