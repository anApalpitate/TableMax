# 第三、四阶段：平台与恢复基础

2026-10-01 开始并完成。范围：独立服务生命周期与主机公共屏、单房间大厅、真实手机身份／换绑、电脑座位、身份投影和游戏／策略契约；串行动作、去重、事务确认、决策点历史分支、暂停／回退／重启恢复、受限 bot 调度及可运行最小游戏模板。

完成标准：真实 HTTP／Socket.IO 验证加入、人数、准备、排序、越权与秘密隔离；验证并发重复提交、保存失败、旧分支、身份不回退、固定随机重演、重启与损坏／不兼容存档保留、bot 取消／异常／策略替换；模板包含独立规则、计分、投影、策略及接入指南；正式网页提供上述入口，桌面与工程检查通过。宝可梦 D01–D13 的具体规则、完整人机整局和产品实机 AC 留给第五、六阶段。
