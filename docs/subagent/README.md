# 子 agent 职责索引

本目录单独维护可复用的子 agent 职责与派工约定。角色说明保存在这里，具体任务进度仍进入 [阶段任务](../tasks/README.md)，美术与产品规格仍以对应主题页为准。

| 角色     | 职责入口                          | 使用场景                                                                 |
| -------- | --------------------------------- | ------------------------------------------------------------------------ |
| imagegen | [图像生成与编辑职责](imagegen.md) | 已授权的平台或游戏位图制作、参考图变体、既有图片编辑及素材质量／来源核验 |

## 创建与派工

- 主 agent 根据用户要求和项目约定创建或复用子 agent，派工时明确职责文档、任务目标、完成标准、参考输入和允许写入的路径。职责文档不自动执行任务，也不扩大用户授权范围。
- imagegen 角色使用当前可用的 imagegen 技能和内置图像工具；具体工具参数以当次能力为准。只建立角色或职责文档时，不顺带生产图片。
- 同一文件同一时段只交给一个 agent 修改。尤其明确素材清单、共享规格和 UI 引用的负责人；需要扩大范围时先向主 agent 报告。
- 主 agent 负责协调、复核交付、同步长期文档和创建 Git 提交；子 agent 默认不自行提交、推送或向其他聊天发送消息。
- 子 agent 的本次执行实例由会话工具管理；文档是可跨任务复用的职责说明，不是常驻进程、自动化或已安装的 agent 配置。后续会话需要重新创建实例并传入职责入口。

## imagegen 派工输入

任务简要写清以下信息即可，不要求额外元数据格式：

- 目标：素材用途、素材清单或稳定 ID，生成新图还是编辑旧图。
- 依据：[当前美术规格](../reference/phase-02-platform-spec.md#已确认的美术方向与三端布局)、参考图及各自用途；涉及游戏组件时给出已核验数据入口。
- 约束：比例、目标显示尺寸、透明背景、需保留／避免的内容及允许的迭代范围。
- 文件边界：原图、候选、最终资源与清单位置，是否授权替换现有文件；需导入 UI 时明确由谁修改代码。
- 完成标准：需要的预览、实际测量项、视觉检查及交接结果。

关键未知项影响用途、文件替换或规则依据时，子 agent 向主 agent 汇总；主 agent 结合现有授权判断并向用户询问必要信息。

## 职责文档维护

- 每个角色只维护一份当前职责文件；新增、改名或移除角色时，同步本索引、[文档总索引](../README.md) 和必要的 [Agent 入口](../../AGENTS.md)。
- 职责包含目标、职责边界、阅读入口、输入、交付与完成标准；具体提示词、图片来源和版本留在素材清单，任务过程留在任务页或对应证据目录。
- 工具能力、职责或交接方式发生实际变化时修订已有文件；不将运行中的实例 ID、一次任务进度或临时工具输出作为长期角色配置。
- 角色停用后，先修复派工入口；仅有历史价值的职责与过程才按 [维护规则](../reference/maintenance.md) 归档。职责文档始终不能覆盖产品需求、项目规则或最新用户指示。
