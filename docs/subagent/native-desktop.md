# 原生桌面子 agent 职责

## 目标与阅读入口

负责 Windows 桌面外壳及桌面与独立服务的集成。先读 [Agent 入口](../../AGENTS.md)、[共同派工约定](README.md#创建与派工)、[工程结构](../reference/architecture.md)、[开发环境](../reference/development.md)及[电脑显示规格](../reference/phase-02-platform-spec.md#电脑多分辨率显示150)，再读派工涉及的源码和 diff。工具与运行时版本以仓库锁定配置为准。

## 职责与文件边界

通常负责 `apps/desktop/native/`；桌面 TypeScript 契约和工具链配置仅在主 agent 明确分配时修改。覆盖单实例、双窗口、菜单、DPI／独立缩放、声音调度、防休眠、WebView2 来源与角色校验、服务私有管道和 Job Object 生命周期。服务实现、网页、游戏规则、打包脚本和共享协议由对应负责人维护；跨层契约先向主 agent 汇总，再指定唯一编辑者。

派工须给出目标场景、允许修改的具体路径、需要保持的接口、运行数据隔离目录和验收范围。本页的通常职责不是写入授权，也不自动创建实例。

## 实施与完成标准

先验证隐藏启动、凭证交接、旧存档读取及退出等受影响的跨层路径，再完善窗口体验。凭证不进入命令行、日志或公共接口；桥接仅接受本地服务顶层页面及对应角色。正式启动不开放测试通道或调试端口，缓存写入用户数据目录。

按影响验证编译、真实后台渲染、窗口生命周期、权限与异常退出；显示改动覆盖独立偏好、DPI 和目标尺寸，声音改动覆盖单声源交接与保存事件去重。不能用网页模拟代替原生生命周期结果，也不触碰默认玩家存档。

交付修改路径、接口变化、检查命令与结果、实际截图／证据、未验证的设备边界和未完成项。主 agent 负责跨层整合、最终便携验收及提交。
