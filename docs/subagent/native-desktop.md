# 原生桌面子 agent 职责

## 目标与阅读入口

负责Windows桌面外壳及桌面与独立服务、受管理安装的集成。先读[Agent入口](../../AGENTS.md)、[共同派工约定](README.md#创建与派工)、[工程结构](../reference/architecture.md)、[构建与运行](../reference/build-and-run.md)及[电脑显示规格](../reference/phase-02-platform-spec.md#电脑多分辨率显示150)，再读派工涉及的源码和diff。安装／更新任务另读[Release门禁](../reference/release.md#完整安装器与免费应用签名2026-10-15)与[验证分层](../reference/installation-validation.md#保存关闭与安装隔离底座2026-10-15)。工具与运行时版本以仓库锁定配置为准。

## 职责与文件边界

通常负责 `apps/desktop/native/`，覆盖单实例、窗口、菜单、DPI／缩放、声音、防休眠、WebView2来源与角色、私有管道、原生应用更新控制和Job生命周期。`apps/desktop/installation-runtime/`的身份／验签／helper事务、`apps/desktop/installation/`的稳定入口与Inno框架、桌面TypeScript契约及工具链仅在主agent明确分配时修改。服务实现、React网页、游戏规则、封包／推广／发布脚本和共享协议由对应负责人维护；跨层契约先汇总，逐文件指定唯一编辑者，不另造第二套程序切换算法。

派工须给出目标场景、允许修改的具体路径、需要保持的接口、运行数据隔离目录和验收范围。本页的通常职责不是写入授权，也不自动创建实例。

## 实施与完成标准

先验证隐藏启动、凭证交接、旧存档读取及退出等受影响的跨层路径，再完善窗口体验。凭证不进入命令行、日志或公共接口；桥接仅接受本地服务顶层页面及对应角色。正式启动不开放测试通道或调试端口，缓存写入用户数据目录。

现行Windows只交付预装全部游戏的完整EXE。原生游戏包文件选择与离线导入桥接已退役，不重新提供独立游戏安装入口；整个TableMax的installer、uninstaller和主机盒子程序更新已实现。保留按精确发行读取网页、详情、样式和媒体的只读路径及旧局数据保护。当前指针仍为便携1.0.6.10，已封候选1.0.6.13未推广；真实干净Windows安装／Apply／卸载待账户授权，不能以历史full／box、helper-only或向导取消结果代替。

安装集成保持I/B/app/G/D契约、用户SID及精确实例身份，默认卸载保留D/G/config，旧便携源与未知内容不删除。`window.tablemaxUpdate`只允许本源顶层host；public、player、frame和普通浏览器拒绝。检查／下载不自动应用、不允许在线降级，应用验签不依赖Node，凭证与私钥不进入桥接、参数、日志或包。项目免费RSA签名不等同Authenticode，也不要求关闭系统安全提示。

应用更新必须取得无playing对局的原子prepare-update保存屏障、真实Stop确认及旧父退出码0，失败或超时明确停止并安全退出，不启动installer。新目标健康确认绑定实际Native／Node、四位版本、映射SHA和I/B/D；正式确认后保持新版主机运行，工程checking须硬静音后台且不能作为普通启动／隔离账户证明。数据库已变化时不自动启动旧程序；pending载荷损坏在身份及卸载协调器可核验前提下，按保留数据卸载再装同一或更高完整包的恢复边界处理。

按影响验证编译、真实后台渲染、窗口生命周期、权限与异常退出；显示改动覆盖独立偏好、DPI 和目标尺寸，声音改动覆盖单声源交接与保存事件去重。不能用网页模拟代替原生生命周期结果，也不触碰默认玩家存档。

交付修改路径、接口变化、检查命令与结果、实际截图／证据、输入与产物SHA、原失败、证据复用范围和未完成项。临时HTTP handler／公钥仅用于managed夹具，不向网页、CLI或环境变量开放任意网络入口；不触碰正式存档、实际账户／UAC或系统策略。主agent负责跨层整合、最终安装／current门禁及提交，发布另需明确授权。
