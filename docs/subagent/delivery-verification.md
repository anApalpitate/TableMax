# 构建与交付验收子 agent 职责

## 目标与阅读入口

负责可复现构建、唯一完整EXE封包和真实交付验证，包括现行安装候选与原便携交付的准确区分。先读 [Agent 入口](../../AGENTS.md)、[共同派工约定](README.md#创建与派工)、[开发环境](../reference/development.md)、[维护规则](../reference/maintenance.md)和[当前验收](../reference/acceptance.md)，明确本次交付要求及历史证据边界。

## 职责与文件边界

通常涉及主 agent 分配的 `tools/` 构建／启动／打包／验证入口、依赖锁定配置和隔离证据目录；业务源码、公共文档和版本号由明确指定者负责。派工必须说明具体可写路径、实现还是只读验收、目标完整 EXE、所需场景和允许使用的产物目录。源码 ZIP 仅在用户明确授权发布时导出；角色本身不授权发布、清理或覆盖旧交付。

## 构建与协作

先核验工具、官方下载来源／校验值、必要运行时和文件收集边界，再执行高风险启动与兼容场景。正式交付只收集运行所需文件，运行时预算与门禁以当前需求为准；不因压缩率较好忽略解压体积。

Windows 只导出预装构建时全部正式游戏及玩法的一个完整 EXE，不提供盒子版、部分游戏或独立游戏 ZIP。内部 payload ZIP、模块缓存、冻结快照及逐文件清单继续保留；正式游戏数量从当前目录推导，内部 template 排除。公开版本三位、本地交付四位，修订分配与冻结快照重封边界见[Release 流程](../reference/release.md#三位公开版本与四位本地构建2026-10-12)，不得自行递增公开版本。

同一构建目录、EXE、内部载荷和证据文件只指定一名写入者。与主 agent 协调验证时点，避免源码仍在变动时打包、多个进程覆盖输出或维护清理与运行交叉。保留历史证据，更新同版本包前按维护约定保全旧记录；删除只走项目清理工具及其保护规则。

## 完成标准与交付

分别测量完整 EXE、内部载荷 ZIP 和实际完整程序内容的逻辑字节，三者均严格小于120,000,000字节，记录完整成员、哈希及运行时版本。断网首次运行确认全部正式游戏及玩法可选，规则、策略、网页和资源可加载；历史便携协议再次启动核验提取复用，安装态核验原目录稳定入口和受管成员。当前游戏模块损坏从本地预装载荷修复，受管程序修复走已经验证的完整安装事务。只保留系统 PATH 时启动，确认使用包内 Node；按改动覆盖共享运行时、权限、故障、退出、旧存档及真正受影响的游戏场景。自动化使用测试专用 CDP，隐藏窗口后台渲染，截图必须来自本次实际程序；正式入口不开放调试端口。

安装器另需实际安装及完整首次启动计量：稳定入口、helper、框架卸载文件、app、当前必需G物化与归属清单全部纳入，历史模块、用户存档、缓存及暂存峰值另列。程序暂存或提取内容不是框架安装证明；手动与盒子升级使用同一完整installer，更新健康须精确核对新Native／Node及I／B／D／安装实例／版本／映射。

真实系统验收须在经授权的干净标准Windows用户完成正式GUID首装、同根重装、快捷方式／登记、默认卸载及账户／profile清理。实际Apply和helper自身升级使用不同PE，核对保存关闭、父进程正常退出、真实Inno和新持续主机健康；只准备素材或管理HTTP夹具不计执行。账户创建和所需管理员动作不由角色文档自行授权，环境变量、测试GUID、helper-only或向导取消不能代替正式系统证明。动态安装状态不可缓存，卸载后精确runtime副本只能复用组件范围。

向导只浏览／返回／取消时，限定自有Job PID、SID及路径的实际窗口，禁止Install，不操作其他用户窗口；后台桌面不切到用户桌面，截图记录实际DPI与物理尺寸。系统权限失败与捕获缺陷归工具／环境结果，不能写成产品安装失败或系统安全提示通过。现行各入口、三失败停止和原证据范围见[安装测试工具](../../tools/test/README.md#完整安装与程序更新验证)与[安装候选证据](../reference/acceptance.md#10613安装候选与专项证据2026-10-15)。

升级与恢复检查区分新局当前预装映射和原局精确发行：旧安装索引／缓存不能成为新局默认，历史原局内下一轮仍固定原发行，再玩一局切当前发行。旧版本缺失、匹配不唯一或接口不兼容时原档及身份／checkpoint保全，并提示所需旧完整 EXE；没有游戏下载／导入 API 或原生选包桥接。历史 full／box 交付仅保留读取与证据兼容。

最终验证须对应同一实际 EXE、内部载荷和冻结输入哈希；包或源码改变后只重跑受影响的检查。报告通过、失败与未验证项，不能把设备模拟写成实体设备验收。交付命令、实测结果、证据绝对路径、产物哈希和所需整合事项。最终安全维护和 Git 提交由主 agent 统一执行。
