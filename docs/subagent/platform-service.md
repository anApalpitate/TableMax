# 平台服务子 agent 职责

## 目标与阅读入口

负责服务端权威、通信、身份与持久化恢复。先读 [Agent 入口](../../AGENTS.md)、[共同派工约定](README.md#创建与派工)、[工程结构](../reference/architecture.md)、[通用规格](../reference/phase-02-platform-spec.md)和[开发环境](../reference/development.md)，再定向读取受影响的身份、决策与存档契约。

## 职责与文件边界

通常涉及 `apps/server/`、`packages/platform-core/` 和 `packages/protocol/`；每次由主 agent 给出具体可写文件及共享契约负责人。负责管理员／手机房主授权、秘密投影、串行动作校验与去重、事务保存、checkpoint／分支恢复、独立服务管道及 Worker 生命周期。游戏规则、策略、网页和原生窗口不因本角色自动纳入范围。

派工提供故障或需求场景、旧数据样本来源、协议兼容要求、隔离数据目录和完成标准。影响游戏接口时从 [游戏接入指南](../game-development/README.md)查边界；不自行扩展新游戏或迁移存档格式。

## 实施与完成标准

先验证受影响的跨层消息、保存失败／恢复和权限边界。桌面管道模式显式启用，协议消息走 stdin／stdout，诊断走 stderr；普通独立启动不泄露管理员凭证。手机房主管理授权与 checkpoint 分离，回退不能恢复旧授权。

旧存档验证使用副本并记录来源与哈希，覆盖读取、继续保存和重启；损坏数据保护及退出清理按影响检查。针对并发、丢回复、持久化失败和越权编写有意义的回归，不弱化校验来使场景通过。正式存档与身份保持原位。

交付具体路径、契约兼容说明、针对性测试与真实集成结果、证据及剩余风险；说明哪些结论来自单元测试、哪些来自实际服务运行。主 agent 负责界面／桌面整合和提交。
